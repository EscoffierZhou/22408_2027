# 考研数学笔记与例题自动化生成规范 (Math Notes Creator)

本 Skill 旨在将考研数学复习过程中的板书截图、讲义、手写笔记及习题集，高保真、体系化地转化为“甚至可以丢掉教科书”的高品质 Markdown 知识库。全面适配 **Typora** 沉浸式阅读与所见即所得原生导出，零依赖外部复杂编译环境。

--------------------------------------------------------------------------------

## 一、四位一体标准文档体系 (Markdown 知识库)

对于每一章数学知识，标准产出由四个相互呼应、结构严谨的 Markdown 文件组成：

| Markdown 文件 | 文档定位 | 核心收录内容 |
| :--- | :--- | :--- |
| `chapX[章节名].md` | **体系化理论精讲笔记** | 知识框架、基本概念、定理公式推导、模型准则、几何意义与历史背景 |
| `例题.md` | **核心精讲大例题集** | 课堂精选大例题(例X.1~X.N)，题干定位、思路分析、分步解答(`[1]`,`[2]`)、辅助三角形回代、多解法对比 |
| `Homework.md` | **基础/课后习题精练** | 课后精选题，题干、考点聚焦、完整推导、常数连续性拼接、极限与积分方程逆运算 |
| `[强化][章节名].md` | **考研高阶冲刺与深水区** | 欧拉代换、配对积分法、古鲁金定理、牟合方盖相交体、托里拆利小号、高阶微元模型 |

## 二、排版与格式六大红线 (Markdown 源码编写铁律)

为了确保文档在 Typora、Obsidian、GitHub 等主流编辑器中排版赏心悦目、公式渲染完美无错，必须严格遵守以下排版铁律：

### 铁律[1]: 全文严禁制表符 (Tab)
- 全文禁止出现任何 `\t` 字符，制表符出现次数必须严格为 0。

### 铁律[2]: 全文严禁 Markdown 默认有序列表
- 严禁使用形如 `1. `、`2. `、`3. ` 的 Markdown 默认有序列表语法(正则匹配 `^\s*\d+\.\s` 必须为 0)。
- 违规原因: 默认有序列表在 Typora 等编辑器中会自动触发首行悬挂缩进和强制换行空距，破坏数学公式的引用块结构。各级标题直接书写（如 `## 1. 导数的概念`）。

### 铁律[3]: 缩进体系唯一规范
- 所有缩进必须且仅能使用引用符号：
  - 一级缩进使用 `>`
  - 二级缩进使用 `>>`
  - 三级缩进使用 `>>>`
- 引用块内部的换行与公式之间，空行必须使用带前缀的空引用(如 `>` 单独占一行)以保留呼吸感。

### 铁律[4]: 标号与分项唯一规范 (严禁裸破折号 `-`)
- **一级/大分项标号**: 统一使用方括号数字：`[1]`、`[2]`、`[3]`...
- **二级/子分项及公式序号**: 统一使用半角圆括号数字：`(1)`、`(2)`、`(3)`...
- **绝对禁止使用汉字圈号**: 全文不得出现圆圈序号(如圈1至圈13)、“圈一”、“圈二”等符号，一律替换为半角圆括号序号 `(1)`、`(2)`。
- **严禁使用 Markdown 减号列表 (`- `) 作为分项**: 正文中严禁使用 `- ` 或 `* ` 充当数学分项序号，必须使用 `(1)`、`(2)` 标号，且每项之间保留呼吸空行。
- **定理与方法标题规范**: 统一采用六级标题：`###### **定理[1]:[标题]**`、`###### **方法[1]:[标题]**`、`###### **公式[1]:[标题]**`、`###### **模型[1]:[标题]**`、`###### **辨析[1]:[标题]**`。

### 铁律[5]: 行内多行公式双换行规范
- 在行内公式 `$ ... $` 内部使用多行环境(如 `\begin{cases} ... \end{cases}` 或矩阵环境)时，两行之间**必须使用两次换行符 `\\ \\`**，获得两次换行的宽松间距效果。
- 目的: 彻底消除 LaTeX 行内分式在预览时与上下两行符号粘连重叠的视觉瑕疵。

### 铁律[6]: 重点高亮色彩标签规范 (<font color>)
- Markdown 笔记中用于重点提醒、避坑指南的强调文字，统一使用：
  - 醒目亮粉: `<font color=deeppink>...</font>`
  - 警示重点红: `<font color=red>...</font>`
- Typora 原生完美支持 `<font>` 颜色渲染，公式与文本均能直接显示醒目高亮，层次鲜明。

## 三、数学内容与题解结构三步法

[1]公式排版规范：
- 独立的定理公式、长推导过程，一律使用独立块级公式 `$$` 并独占单行：
  ```markdown
  $$F(x) = \int_a^x f(t)\,\mathrm{d}t$$
  ```
- 微分算子建议使用正体：`\mathrm{d}x`、`\mathrm{d}t`。
- 极限表达式规范书写：`\lim_{x \to x_0}`，在行内如需上下标置顶底可使用 `\lim\limits_{x \to x_0}`。
- 等号多行对齐推导使用：`\begin{aligned} ... \end{aligned}`。

[2]题解结构三步法：
每道例题与作业题的解答按照统一三步法展开：
```markdown
**例题[9.1]:[题目标题与考点定位]**

[题目完整题干]

主要思路:[一句话提炼本质核心考点与破题钥匙]

>[1][第一步操作与分析]：
>
>[公式推导与分析过程]
>
>[2][第二步计算与公式套用]：
>
>[公式推导与分析过程]
>
>[3][结论与辅助三角形回代]：
>
>[最终结果]
```

## 四、Typora 阅览与一键导出指南 (Typora-Native Workflow)

- **日常学习与阅读**:
  直接在 Typora 中打开各章 `.md` 文件，即可享受极简沉浸式排版、实时数学公式渲染及左侧大纲目录树跳转。
- **一键导出 PDF / HTML**:
  - 点击 Typora 顶部菜单：`文件 (File)` -> `导出 (Export)` -> `PDF`；
  - 也可选择导出为 `HTML`，随时随地在手机或平板浏览器中温习；
  - 纯前端与本地渲染，无需配置 Python 编译脚本或庞大的 TeXLive 依赖环境，秒级导出。
