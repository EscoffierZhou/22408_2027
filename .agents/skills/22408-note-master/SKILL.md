## 一、笔记体系与文件命名规范

### 1. 目录结构与章节组织
每门学科在科目目录下按章节独立建档，并配备配套资源：
```text
科目目录 (如: 11408计算机网络/)

```

### 2. 小节文件三位一体内容结构
每个小节 Markdown 文件必须具备极强的**自包含性**与**应试深度**，标准结构划分为三大模块：
1. **宏观体系与核心概念精解**：定义本质、三要素、逻辑 vs 物理、分类与拓扑结构。
2. **机制对比与性能计算模型**：横向对比表格（如三种交换方式、协议对比）、带推导与单位换算的性能公式。
3. **考研真题与辨析专栏 (`> [!NOTE]`)**：收录王道及历年 408 经典选择题与大题辨析，透视命题陷阱。

## 二、排版与层级六大铁律 (Markdown 核心红线)

为保证在 Typora、Obsidian、GitHub 等主流工具中拥有无可挑剔的阅读体验，杜绝渲染错乱与公式塌陷，必须严格执行以下六大铁律：

### 铁律[1]: 全文严禁制表符 (Tab)
- 全文禁止出现任何 `\t` 字符，制表符数量必须严格为 0。缩进一律采用引用符号或空格。

### 铁律[2]: 全文严禁 Markdown 默认有序列表
- **严禁**使用形如 `1. `、`2. `、`3. ` 的默认有序列表语法（正则 `^\s*\d+\.\s` 必须为 0）。
- **原因**：默认有序列表会在 Typora 中触发首行悬挂缩进和强制换行间距，破坏代码块、公式块与引用块的紧凑层级。
- **替代方案**：
  - 核心大节：使用各级标题（如 `## 1. 计算机网络的组成`、`## 2. 性能指标`）。
  - 微观知识点：使用六级标题加粗（如 `###### 1. 按分布范围分类`、`###### a. 逻辑结构`、`###### **定理[1]: 考点提炼**`）。

### 铁律[3]: 缩进体系唯一规范 (层级穿透哲学)
- 所有内容缩进与解释说明，必须且仅能使用 Markdown 引用符号：
  - 一级缩进：`>`
  - 二级缩进：`>>`
  - 三级缩进：`>>>`
- 引用块内部遇到空行时，**必须保留空引用前缀**（如单占一行的 `>` 或 `>>`），维持视觉呼吸感，防止引用链断裂。

### 铁律[4]: 标号与分项唯一规范 (严禁裸减号 `-`)
- **大分项 / 核心要素标签**：统一使用方括号包覆：`[硬件]`、`[软件]`、`[协议]`，或编号 `[1]`、`[2]`、`[3]`...
- **子分项 / 步骤序号**：统一使用半角圆括号数字：`(1)`、`(2)`、`(3)`...
- **绝对禁止裸减号列表**：正文中**严禁使用 `- ` 或 `* ` 充当无序列表**，必须使用带有明确语义的 `[标签]` 或 `(1)(2)` 分项，每一分项前后保持合理间距。
- **绝对禁止汉字圈号**：不得使用 `①`、`②` 或 `圈1`，全部规范化为半角 `(1)`、`(2)`。

### 铁律[5]: 逻辑推导与因果流线
- 描述因果转化、数据流动、协议封装时，统一使用数学推导箭头：`$\to$` 或 `->`。
- 示例：`数据传输 $\to$ 共享软硬件数据 $\to$ 降低系统成本`。
- 逻辑因果、层级映射必须形成单向闭环流动。

### 铁律[6]: 视觉强化与警示配色体系
- **定义与核心考点双等号高亮**：`==数据结构是关系的集合==`、`==分组交换是当前计算机网络的主流==`。
- **致命陷阱 / 易错避坑警示**：使用红色字体 `<font color=red>注意:... / 致命易错点:...</font>`。
- **关键突破 / 技巧归纳**：使用亮粉色字体 `<font color=deeppink>技巧提炼:... / 本质核心:...</font>`。
- **关键术语加粗**：重要专业名词必须加粗：`**电路交换**`、`**发送时延**`。

## 三、408 专业课特色板块构建规范

### 1. 机制横向对比表 (Matrix Comparison)
凡涉及易混淆机制（如：电路交换 vs 报文交换 vs 分组交换；OSI 七层 vs TCP/IP 四层；单工/半双工/全双工），必须绘制横向对比表格：
```markdown
| 交换方式 | 建立连接 | 线路利用率 | 传输时延与抖动 | 节点存储开销 | 适用场景 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **电路交换** | 必须建立物理连接 | 较低(独占信道) | 传输时延小、无抖动 | 极小(无存储转发) | 连续实时通话 |
| **报文交换** | 无需建立连接 | 较高(动态共享) | 大(需完整接收后转发) | 极大(需大缓存) | 早期低速报文传输 |
| **分组交换** | 虚电路需/数据报无需 | 高(统计多路复用) | 较小(流水线并行传输) | 小(固定大小分组) | 现代计算机互联网 |
```

### 2. 性能公式与计算推导 (Math & Metrics)
涉及计算题目（发送时延、传播时延、时延带宽积、往返时间 RTT、利用率、时间复杂度），必须给出标准数学公式与**单位换算警示**：
```markdown
###### **公式[1]: 总时延计算模型**

$$总时延 = 发送时延 + 传播时延 + 处理时延 + 排队时延$$

>$$t_{\text{trans}} = \frac{\text{数据帧长度 (bit)}}{\text{发送速率 (b/s)}} \quad (\text{网卡处理速率，推向信道的时间})$$
>
>$$t_{\text{prop}} = \frac{\text{信道长度 (m)}}{\text{电磁波传播速率 (m/s)}} \quad (\text{信号在线路上传播的时间})$$
>
><font color=red>【避坑提醒】注意速率单位换算！通信领域：1 kb/s = $10^3$ b/s，1 Mb/s = $10^6$ b/s；而存储领域：1 KB = 1024 B = $2^{10}$ B。</font>
```

### 3. 考研真题与陷阱辨析专栏 (`> [!NOTE]`)
在每个小节末尾，必须设置 `## 题目` 或 `## 核心考点与真题辨析` 模块，采用 GitHub 风格 Alert `> [!NOTE]` 封装，提供精炼的选择题剖析与深度辨析：
```markdown
## 题目

>   [!NOTE]
>
>   ***
>
>   ###### **1. 下列关于网络性能指标的说法中，正确的是：(C)**
>
>   | A. 带宽越高，信号在信道中的传播速度越快 | B. 发送时延仅取决于信道物理长度 |
>   | :--- | :--- |
>   | C. 增大发送速率可有效减小发送时延 | D. 传播时延可通过增加路由器缓存消除 |
>
>   **【解析与陷阱剖析】**：
>
>   > A选项错误：带宽是数据发送速率(b/s)，电磁波在光纤/铜缆中的传播速率(约 $2\times 10^8$ m/s)由物理介质决定，与带宽无关！
>   >
>   > B选项错误：发送时延 = 数据长度 / 信道带宽，与物理距离无关；物理距离决定的是传播时延。
>   >
>   > C选项错误：发送速率越高，推入信道耗时越短。
>   >
>   > D选项错误：增加路由器缓存可以减少丢包，但会增加排队时延，且无法改变物理线路上的传播时延。
>
>   ***
>
>   ###### **2. 广域网与局域网的本质区分特征**
>
>   局域网与广域网的核心划分标准是**所采用的技术与协议体系**（局域网采用以太网、广播技术，广域网采用交换技术与路由选择），而不仅是物理覆盖范围！
```
