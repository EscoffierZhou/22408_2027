# 线性代数1000a基础篇 - 第3章 向量组

**题目[1]**
$n$ 维向量组 $\alpha_1, \alpha_2, \cdots, \alpha_r$ ($3 \le r \le n$) 线性相关的充分必要条件是 $(\qquad)$.

[A] 对于任意一组不全为零的数 $k_1, k_2, \cdots, k_r$，都有 $k_1\alpha_1 + k_2\alpha_2 + \cdots + k_r\alpha_r = 0$

[B] $\alpha_1, \alpha_2, \cdots, \alpha_r$ 中任意两个向量都线性相关

[C] $\alpha_1, \alpha_2, \cdots, \alpha_r$ 中任何一个向量都能由其余向量线性表示

[D] $\alpha_1, \alpha_2, \cdots, \alpha_r$ 中至少有一个向量能由其余向量线性表示

[A] 向量组 $\mathrm{I}$ 线性相关

[B] 向量组 $\mathrm{II}$ 线性相关

[C] 向量组 $\mathrm{I}$ 与 $\mathrm{II}$ 都线性相关

[D] 向量组 $\mathrm{I}$ 与 $\mathrm{II}$ 至少有一个线性相关

① $\alpha_2, \alpha_3, \cdots, \alpha_{n+1}$ 线性相关；
② $\alpha_1, \alpha_3, \cdots, \alpha_{n+1}$ 线性相关；
③ $\alpha_1, \alpha_2, \alpha_4, \cdots, \alpha_{n+1}$ 线性相关.
正确的个数为 $(\qquad)$.

[A] 0

[B] 1

[C] 2

[D] 3

① $r(A) = 2$；
② $\alpha_2, \alpha_4$ 线性无关；
③ $\beta_1, \beta_2, \beta_3$ 线性相关；
④ $\alpha_1, \alpha_2, \alpha_3$ 线性相关.

[A] ①③

[B] ②③

[C] ①④

[D] ②④
