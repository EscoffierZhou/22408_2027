# 线性代数1000b强化篇 - 向量组

## 第6章 向量组

**题目[1]**
设 $\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2, \cdots, \boldsymbol{\alpha}_s$ 是 $n$ 维列向量，$\boldsymbol{A}$ 是 $m\times n$ 矩阵，记向量组 (Ⅰ) 为 $\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2, \cdots, \boldsymbol{\alpha}_s$，向量组 (Ⅱ) 为 $\boldsymbol{A}\boldsymbol{\alpha}_1, \boldsymbol{A}\boldsymbol{\alpha}_2, \cdots, \boldsymbol{A}\boldsymbol{\alpha}_s$，则下列命题正确的是 $(\qquad)$.

[A] 若向量组 (Ⅰ) 线性无关，则向量组 (Ⅱ) 线性无关

[B] 若向量组 (Ⅱ) 线性无关，则向量组 (Ⅰ) 线性无关

[C] 若向量组 (Ⅱ) 线性相关，则向量组 (Ⅰ) 线性相关

[D] 向量组 (Ⅰ) 与向量组 (Ⅱ) 具有不同的线性相关性

**题目[2]**

[A] $\{a \mid a \in \mathbf{R}, a \ne -2\}$

[B] $\{a \mid a \in \mathbf{R}, a \ne -2, a \ne -1\}$

[C] $\{a \mid a \in \mathbf{R}, a \ne 1, a \ne -1\}$

[D] $\{a \mid a \in \mathbf{R}, a \ne -1\}$

(2) 若 $\boldsymbol{\alpha}_1 = [1, -2, 3]^\mathrm{T}, \boldsymbol{\alpha}_2 = [2, 1, 1]^\mathrm{T}, \boldsymbol{\beta}_1 = [-2, 1, 4]^\mathrm{T}, \boldsymbol{\beta}_2 = [-5, -3, 5]^\mathrm{T}$，求既可由 $\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2$ 线性表示，也可由 $\boldsymbol{\beta}_1, \boldsymbol{\beta}_2$ 线性表示的所有非零列向量 $\boldsymbol{\xi}$.
