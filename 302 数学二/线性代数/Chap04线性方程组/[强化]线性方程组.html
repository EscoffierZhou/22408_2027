第四章 线性方程组 · 考研高阶冲刺与深水区强化

1. 公共解与同解的高阶判准与四大求解模型

1.1 两方程组解空间的交集几何本质

设齐次线性方程组 (I) 为 $A_{m \times n}x = 0$，其解空间为 $V_1 = N(A)$；方程组 (II) 为 $B_{s \times n}x = 0$，其解空间为 $V_2 = N(B)$。

两方程组的公共解集即为解空间的交集：
$$V_{\text{common}} = V_1 \cap V_2 = N(A) \cap N(B) = N\left(\begin{bmatrix} A \\ B \end{bmatrix}\right)$$

由解空间维数公式及子空间交维数定理：
$$\dim(V_1 \cap V_2) = n - r\begin{bmatrix} A \\ B \end{bmatrix}$$

当且仅当 $r\begin{bmatrix} A \\ B \end{bmatrix} < n$ 时，两方程组存在非零公共解。

1.2 四大求解模型全景对比

模型[1]:联立矩阵行阶梯形法 (通用硬算首选)

适用场景：两方程组均为具体数值方程组，且方程个数较少。

求解流程：
(1) 将两组系数矩阵纵向拼接为大矩阵 $C = \begin{bmatrix} A \\ B \end{bmatrix}$；

(2) 仅用初等行变换将 $C$ 化为行最简阶梯形；

(3) 确定主元未知量与自由未知量，写出交空间 $V_1 \cap V_2$ 的基础解系与通解。

模型[2]:解代入法 (含参问题最高效)

适用场景：方程组 (I) 或 (II) 其中一方容易求出通解，且方程中含有未知待定参数。

求解流程：
(1) 先求出方程简单一侧 (I) 的通解 $x = k_1\xi_1 + \dots + k_p\xi_p$；

(2) 将该通解的各未知量分量整体代入方程组 (II) 的各方程中；

(3) 得到关于自由常数 $k_1, \dots, k_p$ 的齐次线性方程组，求解系数 $k_i$ 之间的依赖关系，回代求出公共解。

模型[3]:并行通解参数配对法 (双抽象解系相遇)

适用场景：已知两方程组各自的基础解系 $\{\xi_1, \dots, \xi_p\}$ 与 $\{\eta_1, \dots, \eta_q\}$。

求解流程：
(1) 设公共解 $x$ 分别在两组基下展开：
$$x = k_1\xi_1 + \cdots + k_p\xi_p = l_1\eta_1 + \cdots + l_q\eta_q$$

(2) 移项整理为：
$$k_1\xi_1 + \cdots + k_p\xi_p - l_1\eta_1 - \cdots - l_q\eta_q = 0$$

(3) 构成关于待定常数 $[k_1, \dots, k_p, l_1, \dots, l_q]^T$ 的齐次线性方程组，求出非零解，代入任意一侧得到公共解。

模型[4]:交并空间维数公式法 (抽象证明与选择题秒杀)

适用场景：考研真题中关于解空间维数、公共解向量个数的抽象判断题。

核心定理：
$$\dim(V_1 + V_2) = \dim V_1 + \dim V_2 - \dim(V_1 \cap V_2)$$
代入维数公式：
$$n - r(A \cap B) = [n - r(A)] + [n - r(B)] - \dim(V_1 + V_2)$$
整理即得公共解空间维数极值不等式：
$$n - r\begin{bmatrix} A \\ B \end{bmatrix} \ge [n - r(A)] + [n - r(B)] - n = n - [r(A) + r(B)]$$
故必有：
$$\dim(V_1 \cap V_2) \ge n - r(A) - r(B)$$

2. 矩阵方程 $AB=0$ 的几何本质与解空间包含定理

2.1 列向量视角与解空间包含

定理[1]:乘积为零与解空间的等价刻画

设 $A$ 为 $m \times n$ 矩阵，$B$ 为 $n \times s$ 矩阵：
记 $B = [\beta_1, \beta_2, \dots, \beta_s]$，则：
$$AB = 0 \iff A[\beta_1, \beta_2, \dots, \beta_s] = [A\beta_1, A\beta_2, \dots, A\beta_s] = [0, 0, \dots, 0]$$
几何本质：

(1) 矩阵 $B$ 的每一个列向量 $\beta_j$ ($j=1,\dots,s$) 都是齐次线性方程组 $Ax = 0$ 的解；

(2) 矩阵 $B$ 的列空间（值域 $R(B)$）完全包含于矩阵 $A$ 的零空间（解空间 $N(A)$）：
$$R(B) \subseteq N(A)$$

2.2 秩不等式与极限充要条件

定理[2]:$AB=0$ 的秩不等式推导

由 $R(B) \subseteq N(A)$，子空间维数必满足包含不等式：
$$\dim R(B) \le \dim N(A)$$
根据矩阵的秩的几何定义 $\dim R(B) = r(B)$，以及解空间维数公式 $\dim N(A) = n - r(A)$：
$$r(B) \le n - r(A) \iff r(A) + r(B) \le n$$
此即著名的 Sylvester 零乘积秩不等式。

定理[3]:基础解系充要匹配定理

若 $AB = 0$，且满足等号极值条件：
$$r(A) + r(B) = n$$
则：

(1) 矩阵 $B$ 的列空间维数恰好饱和填满矩阵 $A$ 的解空间：$R(B) = N(A)$；

(2) 矩阵 $B$ 的列向量组的任意极大线性无关组，都是齐次线性方程组 $Ax = 0$ 的一个基础解系！

2.3 幂零矩阵与幂等矩阵的方程组解构

模型[5]:$A^2 = 0$ 的空间退化模型

若 $A_{n \times n}$ 满足 $A^2 = 0$：

(1) 令 $B = A$，立即由 $r(A) + r(A) \le n$ 得到：
$$r(A) \le \frac{n}{2}$$

(2) 方程组 $Ax = 0$ 的基础解系至少含有 $n - r(A) \ge n/2$ 个线性无关解向量。

模型[6]:$A^2 = A$ (幂等投影矩阵) 的空间直和分解

若 $A_{n \times n}$ 满足 $A^2 = A$：

(1) 方程改写为 $A(A - I) = 0$，根据秩不等式：
$$r(A) + r(A - I) \le n$$

(2) 又由秩的次可加性：
$$r(A) + r(I - A) \ge r(A + I - A) = r(I) = n$$

(3) 夹逼必有 $r(A) + r(I - A) = n$。全空间 $\mathbb{R}^n$ 实现保真直和分解：
$$\mathbb{R}^n = N(A) \oplus R(A)$$
任何向量 $x \in \mathbb{R}^n$ 均可唯一正交分解为 $x = (x - Ax) + Ax$，其中 $(x - Ax) \in N(A)$, $Ax \in R(A)$。

3. 伴随矩阵方程 $A^*x=0$ 的全景解构与秩准则

3.1 伴随矩阵的秩三大定理

定理[4]:伴随矩阵的秩与原矩阵秩的完备映射

设 $A$ 为 $n$ 阶方阵（$n \ge 2$）：
$$r(A^*) = \begin{cases} n, & r(A) = n \\ 1, & r(A) = n - 1 \\ 0, & r(A) < n - 1 \end{cases}$$

严格推导：

(1) 当 $r(A) = n$ 时，$|A| \ne 0$。由 $A^* = |A|A^{-1}$ 知 $A^*$ 亦可逆，故 $r(A^*) = n$；

(2) 当 $r(A) = n - 1$ 时，矩阵 $A$ 至少存在一个 $(n-1)$ 阶代数余子式非零，故 $A^* \ne O \implies r(A^*) \ge 1$。
另由矩阵恒等式 $A A^* = |A| I = 0$，套用 Sylvester 秩不等式：
$$r(A) + r(A^*) \le n \implies (n - 1) + r(A^*) \le n \implies r(A^*) \le 1$$
夹逼必得 $r(A^*) = 1$；

(3) 当 $r(A) < n - 1$ 时，矩阵 $A$ 的所有 $(n-1)$ 阶子式全部为 0，伴随矩阵全为零元素：$A^* = O \implies r(A^*) = 0$。

3.2 伴随齐次方程 $A^*x=0$ 的解空间与基础解系构造

定理[5]:伴随齐次方程组解空间全貌

考察方程组 $A^*x = 0$ 的解空间维数 $\dim N(A^*) = n - r(A^*)$：

(1) 若 $r(A) = n$，则 $r(A^*) = n$，方程组 $A^*x = 0$ 只有零解；

(2) 若 $r(A) = n - 1$，则 $r(A^*) = 1$，解空间维数为：
$$\dim N(A^*) = n - 1$$
基础解系构造绝技：由 $A A^* = 0$ 转置得 $(A^*)^T A^T = 0$。$A$ 的行满秩极大无关组经转置后即为 $A^*x = 0$ 的基础解系！

(3) 若 $r(A) < n - 1$，则 $A^* = O$，方程组退化为 $Ox = 0$，解空间为整个 $\mathbb{R}^n$，维数为 $n$，任意 $n$ 个线性无关向量（如标准基）均构成其基础解系。

4. 正规方程组 $A^TAx=A^Tb$ 与最小二乘几何投影

4.1 最小二乘法 (Least Squares) 的代数背景

在工程与科研实践中，当超定线性方程组 $Ax = b$（方程数 $m >$ 未知量数 $n$）不相容（即无精确解）时：
残差向量 $r(x) = Ax - b \ne 0$。

目标：寻找一个最佳逼近解 $\hat{x} \in \mathbb{R}^n$，使得残差向量的欧氏范数（二范数平方）达到全局最小值：
$$\min_{x \in \mathbb{R}^n} f(x) = \|Ax - b\|^2 = (Ax - b)^T(Ax - b)$$

4.2 几何投影正交性与正规方程推导

模型[7]:最小二乘投影几何模型

向量 $Ax$ 属于矩阵 $A$ 的列空间 $R(A) = \operatorname{span}\{\alpha_1, \dots, \alpha_n\}$。

几何极值原理：从点 $b$ 到子空间 $R(A)$ 的最短距离垂线段，必与子空间 $R(A)$ 内的任意向量正交！

即残差向量 $\hat{r} = b - A\hat{x}$ 必须垂直于 $A$ 的每一个列向量 $\alpha_j$：
$$\alpha_j^T (b - A\hat{x}) = 0 \quad (j = 1, 2, \dots, n)$$
写成矩阵形式：
$$A^T (b - A\hat{x}) = 0 \implies A^TA\hat{x} = A^Tb$$
这一经典方程组即称为正规方程组（Normal Equations，又称法方程组）。

4.3 正规方程组的相容性与正交投影算子

定理[6]:正规方程组永恒相容定理

对任意实矩阵 $A_{m \times n}$ 与常数项列向量 $b \in \mathbb{R}^m$：

(1) 正规方程组 $A^TAx = A^Tb$ 恒有解，无解概率为 0。

(2) 当且仅当矩阵 $A$ 列满秩（$r(A) = n$）时，$n$ 阶实对称矩阵 $A^TA$ 严格正定可逆，最小二乘解具有唯一显式闭式解：
$$\hat{x} = (A^TA)^{-1}A^Tb$$

(3) 正交投影矩阵与空间投影：
向量 $b$ 在列空间 $R(A)$ 上的唯一正交投影为：
$$p = A\hat{x} = A(A^TA)^{-1}A^T b$$
称矩阵 $P = A(A^TA)^{-1}A^T$ 为正交投影矩阵（Projection Matrix）。
满足两大优美代数性质：

对称性：$P^T = P$；

幂等性：$P^2 = P$。
