1.二次型的基本概念与矩阵表示

概念[1]:二次型的定义与对称矩阵表示

[1]二次型的数学定义：

含有 $n$ 个变量 $x_1, x_2, \dots, x_n$ 的二次齐次多项式称为 $n$ 元二次型，一般形式为：

$$f(x_1, \dots, x_n) = \sum_{i=1}^n \sum_{j=1}^n a_{ij} x_i x_j = \sum_{i=1}^n a_{ii}x_i^2 + 2\sum_{1 \le i < j \le n} a_{ij} x_i x_j$$

[2]二次型的对称矩阵表示：

任一二次型均可唯一表示为向量与实对称矩阵的二次齐次积：

$$f(x) = x^T A x$$

其中列向量 $x = [x_1, \dots, x_n]^T$，系数矩阵 $A = (a_{ij})_{n \times n}$ 必须为实对称矩阵（$A^T = A$）。

(1) 主对角线元素 $a_{ii}$ 严格等于纯平方项 $x_i^2$ 的系数；

(2) 非对角线元素 $a_{ij} = a_{ji}$ 严格平分交叉项 $x_i x_j$ 的系数，即 $a_{ij} = \frac{1}{2} \text{coeff}(x_i x_j)$；

(3) 实二次型与实对称矩阵之间存在 一一对应 关系。

[3]二次型的秩：

二次型对应矩阵 $A$ 的秩 $r(A)$ 称为该二次型的秩，记作 $r(f) = r(A)$。

2.线性变换与矩阵合同

概念[1]:非退化线性坐标变换

[1]坐标变换模型：

设 $x_1, \dots, x_n$ 与新变量 $y_1, \dots, y_n$ 之间存在线性代换：

$$x = C y \quad (|C| \ne 0)$$

代入原二次型 $f(x) = x^T A x$，可得关于新变量 $y$ 的二次型：

$$g(y) = (Cy)^T A (Cy) = y^T (C^T A C) y = y^T B y$$

新二次型的矩阵为 $B = C^T A C$。

定理[1]:矩阵合同的定义与基本性质

[1]矩阵合同定义：

设 $A, B$ 是数域上的两个 $n$ 阶方阵，若存在可逆矩阵 $C$（$|C| \ne 0$），使得：

$$B = C^T A C$$

则称矩阵 $A$ 与 $B$ 合同，记作 $A \simeq B$。

[2]矩阵合同的核心性质：

(1) 等价关系：满足反身性（$A \simeq A$）、对称性（$A \simeq B \implies B \simeq A$）与传递性（$A \simeq B, B \simeq D \implies A \simeq D$）。

(2) 保持对称性：若 $A$ 是对称矩阵，则与其合同的 $B = C^TAC$ 必为对称矩阵。

(3) 保持矩阵秩：$r(B) = r(C^T A C) = r(A)$。

(4) 保持行列式符号：$|B| = |C|^2 |A|$。由于实可逆矩阵满足 $|C|^2 > 0$，故 $|A|$ 与 $|B|$ 同号。

3.标准型、规范形与惯性定理

概念[1]:二次型的标准型与规范形

[1]标准型：

只含有变量平方项而没有任何交叉乘积项的二次型称为 标准型：

$$f = d_1 y_1^2 + d_2 y_2^2 + \dots + d_n y_n^2$$

其对应的矩阵为对角矩阵 $\Lambda = \text{diag}(d_1, d_2, \dots, d_n)$。

[2]实二次型的规范形：

在实数域内，平方项系数仅取 $+1, -1, 0$ 的标准型称为实二次型的 规范形：

$$f = z_1^2 + \dots + z_p^2 - z_{p+1}^2 - \dots - z_r^2$$

(1) 系数为 $+1$ 的项数 $p$ 称为 正惯性指数；

(2) 系数为 $-1$ 的项数 $q = r - p$ 称为 负惯性指数；

(3) 符号差为 $s = p - q$；

(4) 规范形矩阵为准对角形：$J = \text{diag}(E_p, -E_q, O_{n-r})$。

定理[1]:惯性定理与实对称矩阵合同充要条件

[1]实二次型惯性定理：

任一实二次型 $f(x) = x^T A x$，经过任何可逆实线性变换化为标准型时，其正项项数 $p$ 和负项项数 $q$ 是由实对称矩阵 $A$ 本身唯一确定的，与所采用的可逆线性变换方法完全无关。

[2]实对称矩阵合同充要条件：

两个同阶实对称矩阵 $A$ 与 $B$ 合同（$A \simeq B$）的充分必要条件是：

$$A \text{ 与 } B \text{ 具有完全相同的正惯性指数 } p \text{ 和负惯性指数 } q$$

【考研深度辨析】 秩相同是合同的必要条件（$r = p + q$），但非充分条件。例如 $\text{diag}(1, 1)$ 与 $\text{diag}(1, -1)$ 秩相同但正惯性指数不同，故绝不合同。

4.化二次型为标准型的两大经典方法

方法[1]:正交变换法化二次型为标准型

[1]正交变换化标准型定理：

对于任一实对称矩阵 $A$，必存在正交矩阵 $Q$（满足 $Q^T Q = E$），使得：

$$Q^T A Q = Q^{-1} A Q = \text{diag}(\lambda_1, \lambda_2, \dots, \lambda_n)$$

其中 $\lambda_i$ 为 $A$ 的特征值。作正交变换 $x = Qy$，原二次型化为标准型：

$$f = \lambda_1 y_1^2 + \lambda_2 y_2^2 + \dots + \lambda_n y_n^2$$

[2]正交变换法标准操作流程：

(1) 写出二次型的实对称矩阵 $A$；

(2) 求特征多项式 $|\lambda E - A| = 0$ 的全部特征值 $\lambda_1, \dots, \lambda_n$；

(3) 对各特征值解齐次方程 $(\lambda_i E - A)x = 0$ 求特征向量。重根特征值对应的线性无关特征向量必须用施密特正交化并单位化；

(4) 将求得的两两正交单位特征向量按列构成正交矩阵 $Q$；

(5) 写出正交变换 $x = Qy$，标准型系数 严格等于矩阵 A 的特征值。

方法[2]:拉格朗日配方法分步准则

[1]情形一（含有平方项）：

(1) 将含某元（如 $x_1$）的项集中，提出平方项系数配成完全平方式：

$$f = a_{11} \left( x_1 + \frac{a_{12}}{a_{11}}x_2 + \dots + \frac{a_{1n}}{a_{11}}x_n \right)^2 + f_1(x_2, \dots, x_n)$$

(2) 对剩余不含 $x_1$ 的部分重复上述配方，逐次降元；

(3) 令各平方括号内部分分别为 $y_1, \dots, y_n$，求出可逆代换矩阵 $C$。

[2]情形二（无平方项，仅有交叉项）：

(1) 先作非退化和差代换：令 $x_1 = y_1 + y_2, x_2 = y_1 - y_2, x_k = y_k$ ($k \ge 3$)；

(2) 代入后展开 $x_1 x_2 = y_1^2 - y_2^2$，构造出平方项；

(3) 随后转入情形一继续配方。

5.正定二次型与正定矩阵

概念[1]:正定与各类定态二次型定义

[1]正定二次型与正定矩阵定义：

设二次型 $f(x) = x^T A x$，其中 $A$ 为实对称矩阵：

(1) 正定：若对任意非零向量 $x \ne 0$，恒有 $x^T A x > 0$，则称 $f(x)$ 为正定二次型，$A$ 为正定矩阵（$A > 0$）。

(2) 负定：若对任意非零向量 $x \ne 0$，恒有 $x^T A x < 0$，则称 $f(x)$ 为负定二次型，$A$ 为负定矩阵（$A < 0$）。

(3) 半正定：对任意 $x$，恒有 $x^T A x \ge 0$，且存在非零 $x_0$ 使得 $x_0^T A x_0 = 0$。

(4) 半负定：对任意 $x$，恒有 $x^T A x \le 0$，且存在非零 $x_0$ 使得 $x_0^T A x_0 = 0$。

(5) 不定：$x^T A x$ 既可取正值又可取负值。

[2]正定几何直观意义：

二次曲面方程 $x^T A x = 1$ 中，若 $A$ 正定，所有特征值 $\lambda_i > 0$，标准方程为椭球面，包围原点且有界闭合。

定理[1]:正定二次型与正定矩阵充要判据全集

[1]五大等价充要判据：

设 $A$ 是 $n$ 阶实对称矩阵，以下命题完全等价：

(1) $A$ 是正定矩阵（$\forall x \ne 0, x^T A x > 0$）；

(2) $A$ 的正惯性指数 $p = n$（规范形为 $f = z_1^2 + \dots + z_n^2$）；

(3) $A \simeq E$（合同于单位矩阵）；

(4) 存在可逆矩阵 $D$（$|D| \ne 0$），使得 $A = D^T D$；

(5) $A$ 的所有特征值严格全为正数：$\lambda_i > 0$ ($i = 1, 2, \dots, n$)；

(6) $A$ 的各阶顺序主子式全大于零：$\Delta_k > 0$ ($k = 1, 2, \dots, n$)（Sylvester 准则）。

定理[2]:正定矩阵的三大快速排除必要条件

[1]三大必要条件：

若实对称矩阵 $A = (a_{ij})_{n \times n}$ 正定，则必有：

(1) 主对角线元素全为正数：$a_{ii} > 0$；

(2) 行列式为正数：$|A| = \prod_{i=1}^n \lambda_i > 0$；

(3) 全矩阵绝对值最大元素必在主对角线上：$\max |a_{ij}| = \max a_{ii}$。

[2]考研避坑警示：

上述条件仅为必要条件，满足 $a_{ii} > 0$ 且 $|A| > 0$ 的矩阵不一定正定！常用于选择题快速排除错误选项。

定理[3]:正定矩阵的核心代数运算性质

[1]代数性质：

若 $A, B$ 为同阶正定矩阵，$k > 0$：

(1) $A^{-1}$ 与伴随矩阵 $A^*$ 均是正定矩阵；

(2) $k A$ 与 $A + B$ 均是正定矩阵；

(3) 对任一可逆矩阵 $C$，$C^T A C$ 必为正定矩阵；

(4) 对任意正整数 $m$，$A^m$ 是正定矩阵。
