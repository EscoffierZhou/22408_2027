# 22408 考研数学(二) 全局复习规划 (302 数学二)

> **目标定位:** 120+ / 150 分 | 冲击中国科学院大学 (UCAS) 计算机与人工智能学科  
> **试卷结构:** 高等数学约 116 分 (78%) + 线性代数约 34 分 (22%)  
> **核心原则:** 严禁被动阅读，强制闭卷手推；剥离营销口诀，深挖前件假设与崩溃边界。

## 1.三阶段作战战略与时间沙盘

依据考研倒计时节奏，制定严谨的三阶段推进路线图：

###### **阶段[1]:核心体系建立与线代闪电战 (第1-3周 / 约20天)**
>核心目标：一周拿下《线性代数》全套 17 章基础与强化笔记；同步每日闭卷默写高数 15 章主干骨架，彻底攻克一元积分学以来的记忆衰退。
>
>操作抓手：
>[1] 线性代数：每天推进 2~3 章，迅速贯通“行列式 $\to$ 矩阵的秩 $\to$ 向量组等价 $\to$ 方程组解的结构 $\to$ 相似对角化 $\to$ 二次型合同”六大枢纽。
>
>[2] 高等数学：每天限时 20 分钟手推 1 章的核心例题与作业题，遮住答案严格按三步法运算到底。

###### **阶段[2]:真题轰炸与强化深水区 (第4-10周 / 约50天)**
>核心目标：攻克高数 18 讲强化专题；全面刷通数学二 2005~2024 近 20 年真题套卷。
>
>操作抓手：
>[1] 真题实战：每两天一套真题，严格卡表 3 小时（上午 8:30-11:30）全真闭卷模拟，彻底暴露计算失误、定理条件遗漏与时间分配问题。
>
>[2] 错题溯源：针对做错的证明题与物理应用题，回归标准化笔记，深入追问“先验假设是什么、为什么此方法失效、换前提怎么改”。

###### **阶段[3]:冲刺模考与终极排查 (第11-14周 / 约30天至考前)**
>核心目标：模拟卷防冷门题型，错题本重刷，高频公式定理极速回溯。
>
>操作抓手：
>[1] 高质量模拟：精选李林 6+4 等权威模拟卷，训练复杂计算耐受力与抗压心态。
>[2] 终极清单：考前反复过手高数与线代无条件必背模板，杜绝一切低级丢分。

## 2.各学科章节复习细化对照表

### [1] 高等数学模块 (Chap01 ~ Chap15，约 116 分)

| 序号 | 章节名称 | 核心考点与破题钥匙 | 避坑防炸准则 (<font color=deeppink>前件拆解</font>) |
| :--- | :--- | :--- | :--- |
| **Chap01** | 函数极限与连续 | 泰勒展开阶数匹配、等价无穷小替换、左右极限判定 | 减法拆分必须满足分母同阶；复合函数代换必先验证趋近过程 |
| **Chap02** | 数列极限 | 单调有界准则、夹逼定理、定积分定义转化为黎曼和 | 递推数列必先证明收敛性方可两边取极限，严防虚假极限根 |
| **Chap03** | 一元微分概念 | 导数定义对称差商辨析、可导与连续、绝对值函数可导性 | 谨记 $f'(x_0)$ 存在是一阶充分条件，不可对不可导点妄用洛必达 |
| **Chap04** | 一元微分计算 | 隐函数求导、参数方程二阶导、高阶莱布尼茨公式 | 参数方程二阶导 $\frac{\mathrm{d}^2 y}{\mathrm{d}x^2} = \frac{\mathrm{d}(y'_x)}{\mathrm{d}t} \big/ x'_t$，切勿对分子分母分别求二阶导 |
| **Chap05** | 微分几何应用 | 极值与最值、拐点与凹凸性、水平/垂直/斜渐近线 | 拐点是点 $(x_0, f(x_0))$ 而非单纯横坐标；求渐近线须严格按顺序排查 |
| **Chap06** | 微分中值定理 | 罗尔定理、拉格朗日、柯西定理；辅助函数构造与微分不等式 | 双中值问题切忌混用同一个 $\xi$；乘积型辅助函数首选导数对数求导法反推 |
| **Chap07** | 物理与经济应用 | 变力做功、水压力、引力微元；边际与弹性 (数二侧重物理) | 微元法必须写明区间积分形式 $\mathrm{d}W = F(x)\,\mathrm{d}x$，几何量必须带符号校准 |
| **Chap08** | 积分概念与性质 | 定积分保号性、奇偶对称性、周期性、积分中值定理 | 变上限积分可导性比原函数高一阶；积分第一中值定理要求权函数不变号 |
| **Chap09** | 一元积分学计算 | 第一/二换元法、分部积分法、有理分式积分、三角代换 | 分部积分遵循“反、对、幂、指、三”定 $u$ 原则；根式代换后勿忘反代三角形 |
| **Chap10** | 积分几何应用 | 平面图形面积、极坐标面积、旋转体体积 (切片法与柱壳法) | 绕 $y$ 轴旋转体体积柱壳公式 $V = 2\pi\int x y\,\mathrm{d}x$ 效率远高于反函数法 |
| **Chap11** | 积分等式不等式 | 积分恒等式构造、柯西-施瓦茨不等式、积分证明压轴题 | 构造辅助函数 $F(x) = \int_0^x \dots$ 转化为导数单调性是最通用通法 |
| **Chap12** | 积分物理应用 | 质心坐标、转动惯量、抽水做功与薄板侧压力 | 物理微元必须从截面薄片或微条入手，密度非均匀时积分包含坐标项 |
| **Chap13** | 多元微分学 | 极限/连续/偏导/全微分关系、多元复合链式求导、无条件/条件极值 | 偏导存在且连续是全微分充分条件；拉格朗日乘数法极值需结合物理边界定性 |
| **Chap14** | 二重积分 | 直角与极坐标转化、交换积分次序、对称性化简、区域奇偶性 | 极坐标面积微元必须乘 $r$；积分区域对称且被积函数关于对应变量奇时积分为0 |
| **Chap15** | 微分方程 | 一阶6类方程、二阶可降阶3类、高阶常系数线性方程、物理建模 | 算子法 $D$ 秒杀特解；降阶法不显含 $x$ 设 $y'=p(y)$ 时二阶导为 $p\frac{\mathrm{d}p}{\mathrm{d}y}$ |

## 3.执行铁律与防死指南 (摘自 NOTICE.md)

> [!CAUTION]
> **绝对戒除的 3 种低效假勤奋模式：**
> 
> [1] **“看懂了 = 掌握了”的评估幻觉**：凡是没有独立在草稿纸上算到最后一步数值的题目，一律视作“完全不会做”。
> 
> [2] **“盲信秒杀口诀”的套路依赖**：凡是知其然不知其所以然的营销口诀，只要出题人微调边界条件必定崩盘。必须掌握其底层微积分定义。
> 
> [3] **“只做新题不复盘”的仓鼠心态**：考研 100 天，吃透 1 道真题的 3 种变式与边界，收益远大于囫囵吞枣刷 10 道散题。
