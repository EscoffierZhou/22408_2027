例题[11.1]:推广积分第一中值定理与含参积分极限

设函数 $f(x), g(x)$ 在闭区间 $[a, b]$ 上连续，且 $g(x)$ 在 $[a, b]$ 上不变号（即恒有 $g(x) \ge 0$ 或 $g(x) \le 0$）。
(1) 证明推广的积分第一中值定理：存在 $\xi \in [a, b]$，使得
$$\int_a^b f(x)g(x)\,\mathrm{d}x = f(\xi)\int_a^b g(x)\,\mathrm{d}x$$
(2) 设 $f(x)$ 在 $[1, 2]$ 上连续，计算极限：
$$\lim_{n \to \infty} \int_1^2 f(x)\mathrm{e}^{-x^n}\,\mathrm{d}x$$

主要思路:第一问利用闭区间连续函数的极值定理与介值定理完成证明；第二问结合闭区间连续函数的有界性与指数衰减因子的局部积分放缩应用夹逼定理

[1]推广积分第一中值定理的介值性证明：

因为 $f(x)$ 在 $[a, b]$ 上连续，由闭区间连续函数的极值定理，存在最小值 $m$ 与最大值 $M$，使得对任意 $x \in [a, b]$ 均有 $m \le f(x) \le M$。

不妨设 $g(x) \ge 0$（若 $g(x) \le 0$，只需考查 $-g(x)$）。用 $g(x)$ 乘以不等式各项并在 $[a, b]$ 上逐项积分，由定积分保序性得：

$$m \int_a^b g(x)\,\mathrm{d}x \le \int_a^b f(x)g(x)\,\mathrm{d}x \le M \int_a^b g(x)\,\mathrm{d}x$$

若 $\int_a^b g(x)\,\mathrm{d}x = 0$，因 $g(x) \ge 0$ 连续必有 $g(x) \equiv 0$，等式两端恒为 $0$，对任意 $\xi \in [a, b]$ 均成立。

若 $\int_a^b g(x)\,\mathrm{d}x > 0$，同除以此积分得：

$$m \le \frac{\int_a^b f(x)g(x)\,\mathrm{d}x}{\int_a^b g(x)\,\mathrm{d}x} \le M$$

由连续函数的介值定理，必然存在 $\xi \in [a, b]$，使得 $f(\xi) = \frac{\int_a^b f(x)g(x)\,\mathrm{d}x}{\int_a^b g(x)\,\mathrm{d}x}$，即等式成立。

[2]含参变量积分极限的区间分割与夹逼估计：

因为 $f(x)$ 在 $[1, 2]$ 上连续，故存在常数 $M_0 > 0$，使得对任意 $x \in [1, 2]$ 均有 $|f(x)| \le M_0$。

因此积分绝对值满足：

$$\left| \int_1^2 f(x)\mathrm{e}^{-x^n}\,\mathrm{d}x \right| \le \int_1^2 |f(x)|\mathrm{e}^{-x^n}\,\mathrm{d}x \le M_0 \int_1^2 \mathrm{e}^{-x^n}\,\mathrm{d}x$$

对任意微小正数 $\delta \in (0, 1)$，将区间 $[1, 2]$ 拆分为 $[1, 1+\delta]$ 与 $[1+\delta, 2]$ 两段：

$$\int_1^2 \mathrm{e}^{-x^n}\,\mathrm{d}x = \int_1^{1+\delta} \mathrm{e}^{-x^n}\,\mathrm{d}x + \int_{1+\delta}^2 \mathrm{e}^{-x^n}\,\mathrm{d}x \le \delta \cdot 1 + (1 - \delta)\mathrm{e}^{-(1+\delta)^n}$$

当 $n \to \infty$ 时，后项指数趋于 $0$，从而 $\limsup\limits_{n \to \infty} \int_1^2 \mathrm{e}^{-x^n}\,\mathrm{d}x \le \delta$。

再令 $\delta \to 0^+$，得到 $\lim\limits_{n \to \infty} \int_1^2 \mathrm{e}^{-x^n}\,\mathrm{d}x = 0$。

[3]极限计算结论：

由夹逼准则，最终求得极限为：

$$\lim_{n \to \infty} \int_1^2 f(x)\mathrm{e}^{-x^n}\,\mathrm{d}x = 0$$

例题[11.2]:积分不等式与二阶导数符号判定

设函数 $f(x)$ 在闭区间 $[0, 1]$ 上二阶可导，且 $f(0) = f(1) = 0$。若积分不等式满足：
$$\int_0^1 f(x)\,\mathrm{d}x > 0$$
证明：存在 $\xi \in (0, 1)$，使得 $f''(\xi) < 0$。

主要思路:利用积分第一中值定理从积分正值中提取出内部正值点 $f(c) > 0$，再分别在 $[0, c]$ 与 $[c, 1]$ 上两次应用拉格朗日中值定理构造正负异号的一阶导数点，最后再次应用中值定理确定二阶导数的负号

[1]利用积分第一中值定理提取内部正值点：

因为 $f(x)$ 在 $[0, 1]$ 上连续，由积分第一中值定理，存在 $c \in (0, 1)$，使得：

$$\int_0^1 f(x)\,\mathrm{d}x = f(c)(1 - 0) = f(c)$$

结合已知条件 $\int_0^1 f(x)\,\mathrm{d}x > 0$，可得：

$$f(c) > 0$$

[2]两次应用拉格朗日中值定理构造一阶导数正负相异点：

在区间 $[0, c]$ 上，$f(x)$ 满足拉格朗日中值定理条件，存在 $\eta_1 \in (0, c)$，使得：

$$f'(\eta_1) = \frac{f(c) - f(0)}{c - 0} = \frac{f(c)}{c} > 0$$

在区间 $[c, 1]$ 上，同理存在 $\eta_2 \in (c, 1)$，使得：

$$f'(\eta_2) = \frac{f(1) - f(c)}{1 - c} = \frac{-f(c)}{1 - c} < 0$$

显然有 $0 < \eta_1 < c < \eta_2 < 1$。

[3]应用拉格朗日中值定理确定二阶导数符号：

对 $f'(x)$ 在区间 $[\eta_1, \eta_2]$ 上应用拉格朗日中值定理，存在 $\xi \in (\eta_1, \eta_2) \subset (0, 1)$，使得：

$$f''(\xi) = \frac{f'(\eta_2) - f'(\eta_1)}{\eta_2 - \eta_1}$$

因为 $\eta_2 > \eta_1 \implies \eta_2 - \eta_1 > 0$，且分子满足：

$$f'(\eta_2) < 0, \quad f'(\eta_1) > 0 \implies f'(\eta_2) - f'(\eta_1) < 0$$

因此必然有：

$$f''(\xi) < 0$$

命题得证。

例题[11.3]:分部积分法化简与含参积分极限

计算极限：
$$\lim_{n \to \infty} \int_0^1 (n+1) x^n \ln(1+x)\,\mathrm{d}x$$

主要思路:将 $(n+1)x^n\,\mathrm{d}x$ 凑微分改写为 $\mathrm{d}(x^{n+1})$ 执行分部积分，将高阶幂次转移至代数端点项，剩余积分通过夹逼定理严格证明极限为零

[1]凑微分并执行分部积分：

记积分项为 $I_n$。观察到 $(n+1)x^n = (x^{n+1})'$，利用分部积分法：

$$I_n = \int_0^1 \ln(1+x)\,\mathrm{d}(x^{n+1}) = \left[ x^{n+1}\ln(1+x) \right]_0^1 - \int_0^1 x^{n+1} \cdot \frac{1}{1+x}\,\mathrm{d}x$$

$$= 1^{n+1}\ln 2 - 0 - \int_0^1 \frac{x^{n+1}}{1+x}\,\mathrm{d}x = \ln 2 - \int_0^1 \frac{x^{n+1}}{1+x}\,\mathrm{d}x$$

[2]对剩余积分进行不等式夹逼估计：

考查余项积分 $J_n = \int_0^1 \frac{x^{n+1}}{1+x}\,\mathrm{d}x$。

当 $x \in [0, 1]$ 时，恒有 $1 \le 1 + x \le 2$，从而：

$$\frac{1}{2} x^{n+1} \le \frac{x^{n+1}}{1+x} \le x^{n+1}$$

在区间 $[0, 1]$ 上逐项积分得：

$$\frac{1}{2(n+2)} \le \int_0^1 \frac{x^{n+1}}{1+x}\,\mathrm{d}x \le \frac{1}{n+2}$$

[3]取极限得出最终结论：

当 $n \to \infty$ 时，两端极限显然为零：$\lim\limits_{n \to \infty} \frac{1}{n+2} = 0$。

由夹逼准则可知：$\lim\limits_{n \to \infty} J_n = 0$。

因此原式极限为：

$$\lim_{n \to \infty} I_n = \ln 2 - 0 = \ln 2$$

例题[11.4]:幂式加权积分极限的阶数衰减证明

设函数 $f(x)$ 在闭区间 $[0, 1]$ 上连续。
(1) 证明：$\lim\limits_{n \to \infty} \int_0^1 x^n f(x)\,\mathrm{d}x = 0$；
(2) 进一步已知 $f(1) = 0$ 且导数 $f'(1)$ 存在，证明：$\lim\limits_{n \to \infty} n \int_0^1 x^n f(x)\,\mathrm{d}x = 0$。

主要思路:第一问利用连续函数有界性直接放缩；第二问在端点 $x=1$ 附近利用导数定义建立局部线性上界，分段积分结合夹逼定理证明高阶衰减

[1]第一问有界性直接放缩证明：

因为 $f(x)$ 在 $[0, 1]$ 上连续，故存在常数 $M > 0$，使得对任意 $x \in [0, 1]$ 均有 $|f(x)| \le M$。

由定积分性质：

$$\left| \int_0^1 x^n f(x)\,\mathrm{d}x \right| \le M \int_0^1 x^n\,\mathrm{d}x = \frac{M}{n+1}$$

当 $n \to \infty$ 时，$\frac{M}{n+1} \to 0$。由夹逼准则直接得到：

$$\lim_{n \to \infty} \int_0^1 x^n f(x)\,\mathrm{d}x = 0$$

[2]第二问在端点附近的局部展开与分段放缩：

因 $f(1) = 0$ 且 $f'(1)$ 存在，由导数定义：$\lim\limits_{x \to 1^-} \frac{f(x) - f(1)}{x - 1} = \lim\limits_{x \to 1^-} \frac{f(x)}{x - 1} = f'(1)$。

故存在 $\delta > 0$，使得当 $x \in [1-\delta, 1]$ 时，有 $|f(x)| \le (|f'(1)| + 1)(1 - x)$。

将积分拆分为两段：

$$n \int_0^1 x^n f(x)\,\mathrm{d}x = n \int_0^{1-\delta} x^n f(x)\,\mathrm{d}x + n \int_{1-\delta}^1 x^n f(x)\,\mathrm{d}x$$

[3]分别估计两段积分并取极限：

对第一段，因 $x \le 1-\delta$：

$$\left| n \int_0^{1-\delta} x^n f(x)\,\mathrm{d}x \right| \le n M \int_0^{1-\delta} x^n\,\mathrm{d}x = \frac{n}{n+1} M (1 - \delta)^{n+1} \to 0 \quad (n \to \infty)$$

对第二段，利用分部积分法：

$$\left| n \int_{1-\delta}^1 x^n f(x)\,\mathrm{d}x \right| \le n(|f'(1)|+1) \int_{1-\delta}^1 x^n(1 - x)\,\mathrm{d}x = n(|f'(1)|+1)\left[ \frac{1}{n+1} - \frac{1}{n+2} \right] \sim \frac{|f'(1)|+1}{n} \to 0$$

综合两段极限可知：

$$\lim_{n \to \infty} n \int_0^1 x^n f(x)\,\mathrm{d}x = 0$$

例题[11.5]:锯齿波函数均值积分渐近极限计算

设锯齿波函数 $f(x) = x - [x]$，其中 $[x]$ 表示不超过 $x$ 的最大整数。计算极限：
$$\lim_{x \to +\infty} \frac{1}{x} \int_0^x f(t)\,\mathrm{d}t$$

主要思路:识别被积函数是以 $T=1$ 为周期的周期锯齿波，将长区间 $[0, x]$ 分解为整数个完整周期与不足一个周期的残余部分，利用夹逼定理求均值极限

[1]计算单周期积分值：

对任意非负整数 $k$，当 $t \in [k, k+1)$ 时，$[t] = k$，故 $f(t) = t - k$。

在每个长度为 $1$ 的单位周期上，其定积分值恒定为：

$$\int_k^{k+1} f(t)\,\mathrm{d}t = \int_k^{k+1} (t - k)\,\mathrm{d}t = \int_0^1 u\,\mathrm{d}u = \frac{1}{2}$$

[2]区间拆分与不等式夹逼：

设 $n = [x]$，则 $n \le x < n+1$。将区间 $[0, x]$ 分解为 $[0, n]$ 与 $[n, x]$：

$$\int_0^x f(t)\,\mathrm{d}t = \int_0^n f(t)\,\mathrm{d}t + \int_n^x f(t)\,\mathrm{d}t = \frac{n}{2} + \int_n^x f(t)\,\mathrm{d}t$$

因为在区间 $[n, x]$ 上恒有 $0 \le f(t) < 1$，所以余项积分满足 $0 \le \int_n^x f(t)\,\mathrm{d}t \le x - n < 1$。

因此得到严格的不等式链：

$$\frac{n}{2} \le \int_0^x f(t)\,\mathrm{d}t < \frac{n}{2} + 1$$

两端同除以 $x$（注意 $n \le x < n+1$）：

$$\frac{n}{2(n+1)} < \frac{1}{x} \int_0^x f(t)\,\mathrm{d}t < \frac{n+2}{2n}$$

[3]应用夹逼准则得出最终结论：

当 $x \to +\infty$ 时，$n = [x] \to +\infty$。

左侧极限 $\lim\limits_{n \to \infty} \frac{n}{2(n+1)} = \frac{1}{2}$，右侧极限 $\lim\limits_{n \to \infty} \frac{n+2}{2n} = \frac{1}{2}$。

由夹逼定理（Squeeze Theorem），最终极限为：

$$\lim_{x \to +\infty} \frac{1}{x} \int_0^x f(t)\,\mathrm{d}t = \frac{1}{2}$$

例题[11.6]:二阶对称核分部积分不等式证明

设函数 $f(x)$ 在闭区间 $[0, 1]$ 上具有连续的二阶导数，且满足端点值 $f(0) = f(1) = 0$。记 $M = \max_{x \in [0, 1]} |f''(x)|$。证明：
$$\left| \int_0^1 f(x)\,\mathrm{d}x \right| \le \frac{1}{12} M$$

主要思路:构造满足 $P(0)=P(1)=0$ 且 $P''(x)=1$ 的二次多项式核函数 $P(x) = \frac{1}{2}x(x-1)$，两次分部积分将原积分转化为二阶导数的积分，由绝对值不等式放缩求得最优常数 $1/12$

[1]构造二次核函数并执行两次分部积分：

取辅助多项式核函数 $P(x) = \frac{1}{2}x(x - 1) = \frac{1}{2}(x^2 - x)$，满足 $P''(x) = 1$ 且 $P(0) = P(1) = 0$。

将被积函数改写为 $f(x) = P''(x)f(x)$ 并执行分部积分：

$$\int_0^1 f(x)\,\mathrm{d}x = \int_0^1 f(x)\,\mathrm{d}(P'(x)) = \left[ P'(x)f(x) \right]_0^1 - \int_0^1 P'(x)f'(x)\,\mathrm{d}x$$

[2]消除端点项建立等式：

因为 $f(0) = f(1) = 0$，所以第一项端点值恒为零：$\left[ P'(x)f(x) \right]_0^1 = 0$。

对剩余项再次进行分部积分：

$$-\int_0^1 f'(x)\,\mathrm{d}(P(x)) = -\left[ P(x)f'(x) \right]_0^1 + \int_0^1 P(x)f''(x)\,\mathrm{d}x$$

因为 $P(0) = P(1) = 0$，所以端点项再次恒为零：$\left[ P(x)f'(x) \right]_0^1 = 0$。

由此导出精确恒等式：

$$\int_0^1 f(x)\,\mathrm{d}x = \frac{1}{2}\int_0^1 x(x-1)f''(x)\,\mathrm{d}x$$

[3]绝对值积分放缩得出界限：

由积分的绝对值不等式：

$$\left| \int_0^1 f(x)\,\mathrm{d}x \right| \le \frac{1}{2}\int_0^1 |x(x-1)| \cdot |f''(x)|\,\mathrm{d}x \le \frac{M}{2}\int_0^1 (x - x^2)\,\mathrm{d}x$$

计算多项式定积分：

$$\int_0^1 (x - x^2)\,\mathrm{d}x = \left[ \frac{x^2}{2} - \frac{x^3}{3} \right]_0^1 = \frac{1}{2} - \frac{1}{3} = \frac{1}{6}$$

代入直接得证：

$$\left| \int_0^1 f(x)\,\mathrm{d}x \right| \le \frac{M}{2} \cdot \frac{1}{6} = \frac{1}{12} M$$

例题[11.7]:变限积分求导法证明单调加权不等式

设函数 $f(x)$ 在闭区间 $[0, 1]$ 上单调递增，证明：
$$\int_0^1 x f(x)\,\mathrm{d}x \ge \frac{1}{2}\int_0^1 f(x)\,\mathrm{d}x$$

主要思路:将右端点 $1$ 替换为自变量 $t \in [0, 1]$ 构造变上限辅助函数 $F(t)$，通过求导与积分中值定理证明 $F'(t) \ge 0$，由 $F(0)=0$ 导出 $F(1) \ge 0$

[1]构造变上限积分辅助函数：

考虑辅助函数 $F(t) = \int_0^t x f(x)\,\mathrm{d}x - \frac{t}{2}\int_0^t f(x)\,\mathrm{d}x$ ($t \in [0, 1]$)。

显然 $F(0) = 0$。欲证原不等式，只需证明 $F(1) \ge 0$。

[2]求导分析单调性：

对 $F(t)$ 关于 $t$ 求导：

$$F'(t) = t f(t) - \left( \frac{1}{2}\int_0^t f(x)\,\mathrm{d}x + \frac{t}{2}f(t) \right) = \frac{t}{2}f(t) - \frac{1}{2}\int_0^t f(x)\,\mathrm{d}x$$

将上式改写为单一定积分：

$$F'(t) = \frac{1}{2}\int_0^t [f(t) - f(x)]\,\mathrm{d}x$$

[3]利用单调性判定非负并得出结论：

因为 $f(x)$ 在 $[0, 1]$ 上单调递增，当 $x \in [0, t]$ 时，恒有 $f(t) \ge f(x) \implies f(t) - f(x) \ge 0$。

由定积分保号性，恒有 $F'(t) \ge 0$。

这说明 $F(t)$ 在 $[0, 1]$ 上单调递增。结合初值 $F(0) = 0$，必有：

$$F(1) \ge F(0) = 0$$

即：

$$\int_0^1 x f(x)\,\mathrm{d}x \ge \frac{1}{2}\int_0^1 f(x)\,\mathrm{d}x$$

命题得证。

例题[11.8]:双端点微分中值定理与最优积分界估计

设函数 $f(x)$ 在闭区间 $[0, 1]$ 上可导，满足端点 $f(0) = f(1) = 0$，且导数满足 $|f'(x)| \le M$。证明：
$$\left| \int_0^1 f(x)\,\mathrm{d}x \right| \le \frac{1}{4} M$$

主要思路:分别从左端点 $0$ 与右端点 $1$ 应用拉格朗日中值定理建立 $|f(x)| \le Mx$ 与 $|f(x)| \le M(1-x)$ 的双侧控制，在对称中点 $x=1/2$ 处分段积分得出最优界 $\frac{1}{4}M$

[1]双端点中值定理建立对称控制界：

对任意 $x \in (0, 1)$：

在区间 $[0, x]$ 上应用拉格朗日中值定理：$f(x) - f(0) = f'(\xi_1)x \implies |f(x)| = |f'(\xi_1)|x \le M x$；

在区间 $[x, 1]$ 上应用拉格朗日中值定理：$f(1) - f(x) = f'(\xi_2)(1 - x) \implies |f(x)| = |f'(\xi_2)|(1 - x) \le M(1 - x)$。

[2]取较小值确定分段上界函数：

综合上述两式，对任意 $x \in [0, 1]$，恒有：

$$|f(x)| \le M \min\{x, 1 - x\} = \begin{cases} M x, & 0 \le x \le \frac{1}{2} \\ \\ M(1 - x), & \frac{1}{2} < x \le 1 \end{cases}$$

[3]分段定积分计算得出界限：

由积分模长不等式：

$$\left| \int_0^1 f(x)\,\mathrm{d}x \right| \le \int_0^1 |f(x)|\,\mathrm{d}x \le M \int_0^1 \min\{x, 1-x\}\,\mathrm{d}x$$

$$= M \left( \int_0^{1/2} x\,\mathrm{d}x + \int_{1/2}^1 (1-x)\,\mathrm{d}x \right) = M \left( \frac{1}{8} + \frac{1}{8} \right) = \frac{1}{4} M$$

命题得证。

例题[11.9]:二阶对称中点泰勒展开积分不等式

设函数 $f(x)$ 在闭区间 $[0, 2]$ 上二阶可导，且中心点满足 $f(1) = 0, f'(1) = 0$。若对一切 $x \in [0, 2]$ 均有 $|f''(x)| \le M$，证明：
$$\left| \int_0^2 f(x)\,\mathrm{d}x \right| \le \frac{1}{3} M$$

主要思路:以中心点 $x_0 = 1$ 为基准作带拉格朗日余项的二阶泰勒展开，利用中心处函数值与一阶导数均为零消除低阶项，逐项积分得出上界 $\frac{1}{3}M$

[1]在中心点 $x_0 = 1$ 处作泰勒展开：

对任意 $x \in [0, 2]$，将 $f(x)$ 在 $x_0 = 1$ 处展开至一阶并带有拉格朗日余项：

$$f(x) = f(1) + f'(1)(x - 1) + \frac{f''(\xi)}{2}(x - 1)^2 \quad (\xi \text{ 介于 } 1 \text{ 与 } x \text{ 之间})$$

[2]代入已知条件建立二次抛物线上界：

代入 $f(1) = 0, f'(1) = 0$，得到：

$$f(x) = \frac{f''(\xi)}{2}(x - 1)^2$$

取绝对值并由 $|f''(x)| \le M$ 放缩：

$$|f(x)| = \frac{|f''(\xi)|}{2}(x - 1)^2 \le \frac{M}{2}(x - 1)^2$$

[3]积分放缩计算定积分：

由定积分性质：

$$\left| \int_0^2 f(x)\,\mathrm{d}x \right| \le \int_0^2 |f(x)|\,\mathrm{d}x \le \frac{M}{2}\int_0^2 (x - 1)^2\,\mathrm{d}x$$

计算定积分：

$$\int_0^2 (x - 1)^2\,\mathrm{d}x = \left[ \frac{(x - 1)^3}{3} \right]_0^2 = \frac{1}{3} - \left(-\frac{1}{3}\right) = \frac{2}{3}$$

因此：

$$\left| \int_0^2 f(x)\,\mathrm{d}x \right| \le \frac{M}{2} \cdot \frac{2}{3} = \frac{1}{3} M$$

命题得证。

例题[11.10]:高频振荡积分的黎曼-勒贝格衰减界估计

设函数 $f(x)$ 在闭区间 $[0, 2\pi]$ 上单调且具有一阶导数。证明对任意正整数 $n$，均有：
$$\left| \int_0^{2\pi} f(x)\sin nx\,\mathrm{d}x \right| \le \frac{2}{n} |f(2\pi) - f(0)|$$

主要思路:将 $\sin nx\,\mathrm{d}x$ 凑微分写为 $-\frac{1}{n}\mathrm{d}(\cos nx)$ 执行分部积分，利用余弦函数的有界性与被积导函数的不变号性进行绝对值积分放缩

[1]凑微分执行分部积分：

$$\int_0^{2\pi} f(x)\sin nx\,\mathrm{d}x = -\frac{1}{n}\int_0^{2\pi} f(x)\,\mathrm{d}(\cos nx)$$

$$= -\frac{1}{n}\left[ f(x)\cos nx \right]_0^{2\pi} + \frac{1}{n}\int_0^{2\pi} f'(x)\cos nx\,\mathrm{d}x$$

[2]分离端点代数项并合并：

因为 $\cos(2n\pi) = \cos 0 = 1$，端点项为：

$$-\frac{1}{n}[f(2\pi) \cdot 1 - f(0) \cdot 1] = -\frac{1}{n}[f(2\pi) - f(0)]$$

因此原积分等于：

$$\int_0^{2\pi} f(x)\sin nx\,\mathrm{d}x = -\frac{1}{n}[f(2\pi) - f(0)] + \frac{1}{n}\int_0^{2\pi} f'(x)\cos nx\,\mathrm{d}x$$

[3]利用单调性（导数不变号）绝对值放缩：

由三角不等式：

$$\left| \int_0^{2\pi} f(x)\sin nx\,\mathrm{d}x \right| \le \frac{1}{n}|f(2\pi) - f(0)| + \frac{1}{n}\int_0^{2\pi} |f'(x)| \cdot |\cos nx|\,\mathrm{d}x$$

因 $|\cos nx| \le 1$，且 $f(x)$ 单调导致 $f'(x)$ 不变号，故 $\int_0^{2\pi} |f'(x)|\,\mathrm{d}x = |\int_0^{2\pi} f'(x)\,\mathrm{d}x| = |f(2\pi) - f(0)|$。

代入即得：

$$\left| \int_0^{2\pi} f(x)\sin nx\,\mathrm{d}x \right| \le \frac{1}{n}|f(2\pi) - f(0)| + \frac{1}{n}|f(2\pi) - f(0)| = \frac{2}{n}|f(2\pi) - f(0)|$$

命题得证。

例题[11.11]:双端点零值积分模长估计

设函数 $f(x)$ 在闭区间 $[a, b]$ 上具有一阶连续导数，且满足端点值 $f(a) = f(b) = 0$。证明对任意 $x \in [a, b]$，均有：
$$|f(x)| \le \frac{1}{2}\int_a^b |f'(t)|\,\mathrm{d}t$$

主要思路:分别利用左端点与右端点的微积分基本定理表达 $f(x)$，取绝对值不等式后两式相加除以 $2$，将两个子区间的导数模长积分无缝拼合成全区间积分

[1]由两端点利用微积分基本定理表达函数值：

对任意给定的 $x \in [a, b]$：

从左端点 $a$ 出发，因 $f(a) = 0$：

$$f(x) = f(a) + \int_a^x f'(t)\,\mathrm{d}t = \int_a^x f'(t)\,\mathrm{d}t$$

从右端点 $b$ 出发，因 $f(b) = 0$：

$$f(x) = f(b) - \int_x^b f'(t)\,\mathrm{d}t = -\int_x^b f'(t)\,\mathrm{d}t$$

[2]取绝对值不等式：

由定积分模长不等式：

$$|f(x)| = \left| \int_a^x f'(t)\,\mathrm{d}t \right| \le \int_a^x |f'(t)|\,\mathrm{d}t$$

$$|f(x)| = \left| -\int_x^b f'(t)\,\mathrm{d}t \right| \le \int_x^b |f'(t)|\,\mathrm{d}t$$

[3]两式相加除以 2 拼接全区间：

将两不等式相加：

$$2|f(x)| \le \int_a^x |f'(t)|\,\mathrm{d}t + \int_x^b |f'(t)|\,\mathrm{d}t = \int_a^b |f'(t)|\,\mathrm{d}t$$

两端同除以 $2$，直接得到：

$$|f(x)| \le \frac{1}{2}\int_a^b |f'(t)|\,\mathrm{d}t$$

命题得证。
