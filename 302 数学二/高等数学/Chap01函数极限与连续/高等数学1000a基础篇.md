**(简单)题目[8]**

设$$\lim\limits_{x \to 0}\frac{\sin 2x + xf(x)}{x^3} = 1$$，则$$\lim\limits_{x \to 0}\frac{2\cos x + f(x)}{x^2} = (\quad)$$

(A) $$0$$  

(B) $$-\frac{2}{3}$$  

(C) $$\frac{4}{3}$$  

(D) $$\infty$$  

解:[首先比阶结果为1,等价无穷小],$$\sin 2x + xf(x)\sim x^3+o(x^3)$$

   对于$$\sin x = x - \frac{x^3}{6} + \frac{x^5}{120} + o(x^5)$$,所以对于$$\sin 2x = 2x - \frac{(2x)^3}{6} + \frac{(2x)^5}{120} + o(x^5)= 2x - \frac{4}{3}x^3+o(x^3)$$

   对于$$cos x = 1 - \frac{x^2}{2} + \frac{x^4}{24} + o(x^5)$$,所以对于$$2cos x = 2 - x^2 + \frac{x^4}{12} + o(x^4)$$

   所以$$\sin 2x + xf(x) = 2x - \frac{4}{3}x^3+xf(x)+o(x^3) $$ $$= x^3+o(x^3)$$

   反解:$$f(x)=-2+\frac{7}{3}x^2+o(x^2)$$

   代入:$$\lim\limits_{x \to 0}\frac{2\cos x + f(x)}{x^2} = \lim\limits_{x \to 0}\frac{2-x^2 + -2+\frac{7}{3}x^2}{x^2} = \frac{\frac{4}{3}x^2+o(x^2)}{x^2} = \frac{4}{3}$$

**(简单)<font color=green>题目[14]:高阶泰勒(反复)</font>**

$$\lim\limits_{x \to 0} \frac{\sqrt{1+\tan x} - \sqrt{1+\sin x}}{x^2 - x\ln(1+x)} =$$ ______

解:[看到根号直接开]\[对于 $(1+u)^{1/2} = 1 + \frac{1}{2}u - \frac{1}{8}u^2 + \frac{1}{16}u^3 + o(u^3)$]

对于$\ln(1+x) = x - \frac{x^2}{2} + o(x^2)$	所以$$x^2 - x\ln(1+x) = x^2 - \left(x^2 - \frac{x^3}{2} + o(x^3)\right) = \frac{1}{2}x^3 + o(x^3)$$

对于$\tan x = x + \frac{x^3}{3} + o(x^3)$	   所以$$\begin{aligned} \sqrt{1+\tan x} &= 1 + \frac{1}{2}\tan x - \frac{1}{8}\tan^2 x + \frac{1}{16}\tan^3 x + o(x^3)= 1 + \frac{1}{2}x - \frac{1}{8}x^2 + \frac{11}{48}x^3 + o(x^3) \end{aligned}$$

对于$\sin x = x - \frac{x^3}{6} + o(x^3)$	   所以$$\begin{aligned} \sqrt{1+\sin x} &= 1 + \frac{1}{2}\sin x - \frac{1}{8}\sin^2 x + \frac{1}{16}\sin^3 x + o(x^3) = 1 + \frac{1}{2}x - \frac{1}{8}x^2 - \frac{1}{48}x^3 + o(x^3) \end{aligned}$$

$$\begin{aligned} \sqrt{1+\tan x} - \sqrt{1+\sin x} &= \left(\frac{11}{48} - \left(-\frac{1}{48}\right)\right)x^3 + o(x^3) = \frac{1}{4}x^3 + o(x^3) \end{aligned}$$

$$\lim_{x \to 0} \frac{\sqrt{1+\tan x} - \sqrt{1+\sin x}}{x^2 - x\ln(1+x)} = \lim_{x \to 0} \frac{\frac{1}{4}x^3 + o(x^3)}{\frac{1}{2}x^3 + o(x^3)} = \frac{\frac{1}{4}}{\frac{1}{2}} = \frac{1}{2}$$

**(中等)<font color=deeppink>题目[20]:破题求连续性(端点极限)</font>**

设$$f(x) = \frac{1 - x \cdot 2^{1-x}}{(2-x)(1-x)}\ (x \neq 1, 2)$$，若$$f(x)$$在$$[1, 2]$$上连续，则$$f(1)f(2) =$$ ______

答案: $$(1 - \ln 2)\left(\ln 2 - \frac{1}{2}\right)$$

解:[函数在闭区间连续,在端点处函数值等于单侧极限]

[1]求$$f(1) = \lim\limits_{x \to 1} f(x)$$：分母中 $2-x \to 1$，提取非零因子，得：
$$
f(1) = \frac{1}{2-1} \cdot \lim_{x \to 1} \frac{1 - x \cdot 2^{1-x}}{1-x} [\frac{0}{0}洛]{=} \lim_{x \to 1} \frac{-(2^{1-x} - x \cdot 2^{1-x} \ln 2)}{-1} = 2^0 - 1 \cdot 2^0 \ln 2 = 1 - \ln 2
$$
[2] 求 $$f(2) = \lim\limits_{x \to 2} f(x)$$：分母中 $1-x \to -1$，提取非零因子，得：
$$
f(2) = \frac{1}{1-2} \cdot \lim_{x \to 2} \frac{1 - x \cdot 2^{1-x}}{2-x} = \lim_{x \to 2} \frac{1 - x \cdot 2^{1-x}}{x-2} [\frac{0}{0}洛]{=} \lim_{x \to 2} \frac{-(2^{1-x} - x \cdot 2^{1-x} \ln 2)}{1}  = \ln 2 - \frac{1}{2}
$$
[3] 整合求解：$$f(1)f(2) = (1 - \ln 2)\left(\ln 2 - \frac{1}{2}\right) = \frac{3}{2}\ln 2 - (\ln 2)^2 - \frac{1}{2}$$

解:[可去间断点要求该点处极限存在且为有限值，但无定义或值不相等]

[1]找候选点:无定义点为:$$x = 0, \quad x = 1, \quad x = -1$$

[2]逐点检验极限：[$u \to 0$,$e^u - 1 \sim u$]

当$$x \to 0$$时:[可去]\[$$|x|^x - 1 = e^{x \ln|x|} - 1 \sim x \ln|x|$$],所以有:$$\lim_{x \to 0} f(x) = \lim_{x \to 0} \frac{x \ln|x|}{x(x+1)\ln|x|} = \lim_{x \to 0} \frac{1}{x+1} = 1$$

当$$x \to 1$$时:[可去]\[$$|x|^x - 1 = e^{x \ln|x|} - 1 \sim x \ln|x|$$],所以有$$\lim_{x \to 1} f(x) = \lim_{x \to 1} \frac{x \ln|x|}{x(x+1)\ln|x|} = \lim_{x \to 1} \frac{1}{x+1} = \frac{1}{2}$$

​		[建议写法:$$\lim_{x \to 1}\frac{e^{x\ln x}-1}{x(x+1)\ln x} = \lim_{x \to 1}\frac{x\ln x}{x(x+1)\ln x} = \frac{1}{2}$$(避免仅分子代换)]

当$$x \to -1$$时:[无穷]分子:$$h(x) = \vert{}x\vert{}^x - 1    $$       $$\sim$$   $$x\ln\vert{}x\vert{}$$ $$\sim$$  $$(-1) \cdot [-(x+1)] = (x+1)$$

​		[注:令$x+1 \to 0$,有$\ln\vert{}x\vert{} = \ln(1-(x+1)) \sim -(x+1)$]

​		 分母:$$g(x) = x(x+1)\ln\vert{}x\vert{} $$   $$\sim$$   $$ (-1) \cdot (x+1) \cdot [-(x+1)] = (x+1)^2$$

$$\lim_{x \to -1} \frac{\vert{}x\vert{}^x - 1}{x(x+1)\ln\vert{}x\vert{}} = \lim_{x \to -1} \frac{x+1}{(x+1)^2} = \lim_{x \to -1} \frac{1}{x+1} = \infty$$

**(简单)<font color=green>题目[22]:第二类间断点判定</font>**

函数$$f(x) = \frac{\ln|1-x|}{(e^x - 1)(x+2)}$$的第二类间断点的个数为(C)

(A) 0  

(B) 1  

(C) 2  

(D) 3  

解:[第二类间断点是指左极限或右极限至少有一个不存在且非有限值(如无穷大)]

[1]找间断点候选点:$$x = 1, \quad x = 0, \quad x = -2$$

[2]逐点检验极限:

当$$x \to 1$$时:[无穷]分子$$\ln|1-x| \to -\infty$$,$$\lim_{x \to 1} f(x) = \infty$$

当$$x \to 0$$时:[可去]分子$$\ln(1-x) \sim -x$$,分母 $$e^x - 1 \sim x$$，且 $$x+2 \to 2$$,$$\lim_{x \to 0} f(x) = \lim_{x \to 0} \frac{-x}{x \cdot 2} = -\frac{1}{2}$$

当$$x \to -2$$时:[无穷]分母$$x+2 \to 0$$,$$\lim_{x \to -2} f(x) = \infty$$

**(中等)<font color=deeppink>题目[23]:极限定义函数间断点</font>**

设$$f(x) = \lim\limits_{t \to +\infty} \frac{x + e^{tx}}{1 + e^{tx}}$$，则$$x=0$$是$$f(x)$$的(B)

(A) 可去间断点  

(B) 跳跃间断点  

(C) 振荡间断点  

(D) 无穷间断点  

解:[先求出分段函数表达式，再计算左右极限判断间断点类型]

当$$x > 0$$时，$$tx \to +\infty \implies e^{tx} \to +\infty$$:   $$f(x) = \lim_{t \to +\infty} \frac{x e^{-tx} + 1}{e^{-tx} + 1} = \frac{0 + 1}{0 + 1} = 1$$[分子分母同除以 $$e^{tx}$$]

当$$x < 0$$时，$$tx \to -\infty \implies e^{tx} \to 0$$：     $$f(x) = \lim_{t \to +\infty} \frac{x + 0}{1 + 0} = x$$

当$$x = 0$$时，直接代入$x=0$:	     $f(0) = \lim_{t \to +\infty} \frac{0 + e^0}{1 + e^0} = \frac{1}{2}$

综上，函数的分段表达式为：$$f(x) = \begin{cases} 1, & x > 0 \\ \\ \frac{1}{2}, & x = 0 \\ \\ x, & x < 0 \end{cases}$$

右极限：$$f(0^+) = \lim_{x \to 0^+} 1 = 1$$

左极限：$$f(0^-) = \lim_{x \to 0^-} x = 0$$

因为 $$f(0^+) \neq f(0^-)$$，且左右极限均存在且为有限值，

$$x=0$$ 是 $$f(x)$$ 的跳跃间断点
