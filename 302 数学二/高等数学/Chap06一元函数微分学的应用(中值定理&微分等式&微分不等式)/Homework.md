**习题[1]:单峰函数极值保号性与零点个数**

设常数$k > 0$，函数$f(x) = \ln x - \frac{x}{e} + k$在$(0, +\infty)$内的零点个数为( )

(A) 3 $\qquad$ (B) 2 $\qquad$ (C) 1 $\qquad$ (D) 0

主要思路:通过求导确定唯一驻点$x = e$，分析两侧单调性判定$x = e$为全局极大值$k > 0$，再结合两端极限趋向于$-\infty$，由零点定理确定两侧各有一个零点

>[1]求导与驻点判定：
>
>$$f'(x) = \frac{1}{x} - \frac{1}{e}$$
>
>令$f'(x) = 0$，解得定义域$(0, +\infty)$内的唯一驻点$x = e$。
>
>[2]单调性与极值确定：
>
>- 当$x \in (0, e)$时，$f'(x) > 0$，$f(x)$严格单调增加；
>- 当$x \in (e, +\infty)$时，$f'(x) < 0$，$f(x)$严格单调减少。
>
>故$x = e$为全局唯一极大值点，极大值为：
>
>$$f(e) = \ln e - \frac{e}{e} + k = 1 - 1 + k = k > 0$$
>
>[3]边界与无穷远极限分析：
>
>- 当$x \to 0^+$时，对数项主导：$\lim_{x \to 0^+} f(x) = \lim_{x \to 0^+} \left(\ln x - \frac{x}{e} + k\right) = -\infty < 0$；
>- 当$x \to +\infty$时，线性减项主导：$\lim_{x \to +\infty} f(x) = \lim_{x \to +\infty} \left(\ln x - \frac{x}{e} + k\right) = -\infty < 0$。
>
>[4]零点存在与唯一性判定：
>
>- 在开区间$(0, e)$上，函数由$-\infty$严格单调增加至$k > 0$，由零点定理存在且仅存在1个零点$x_1 \in (0, e)$；
>- 在开区间$(e, +\infty)$上，函数由$k > 0$严格单调减少至$-\infty$，由零点定理存在且仅存在1个零点$x_2 \in (e, +\infty)$。
>
>综上，$f(x)$在全定义域$(0, +\infty)$内共有2个零点。
>
>[5]故正确选项为 **(B)**。

**习题[2]:分母无零点与连续性参数范围**

若函数$f(x) = \frac{1}{xe^{-x} - a}$在$(-\infty, +\infty)$内处处连续，则常数$a$的取值范围为( )

(A) $a < 0$ $\qquad$ (B) $a > e^{-1}$ $\qquad$ (C) $a < e^{-1}$ $\qquad$ (D) $0 < a < e^{-1}$

主要思路:函数处处连续等价于分母恒不为零，即方程$xe^{-x} = a$无实根；求出$g(x) = xe^{-x}$的最大值与值域，常数$a$超出值域范围即可

>[1]问题等价转化：
>
>函数$f(x)$在$\mathbb{R}$上处处连续 $\iff$ 分母在$\mathbb{R}$上恒不为零，即方程$xe^{-x} - a = 0$在$\mathbb{R}$内无实根
>
>​		    $\iff$ 水平直线$y = a$与曲线$y = g(x) = xe^{-x}$无交点。
>
>[2]求函数$g(x) = xe^{-x}$的极值与单调性：
>
>$$g'(x) = e^{-x} - x e^{-x} = e^{-x}(1 - x)$$
>
>令$g'(x) = 0$，因$e^{-x} > 0$，解得唯一驻点$x = 1$。
>
>- 当$x < 1$时，$g'(x) > 0$，$g(x)$单调增加；
>- 当$x > 1$时，$g'(x) < 0$，$g(x)$单调减少。
>
>故$x = 1$处取得全局最大值：
>
>$$g_{\max} = g(1) = 1 \cdot e^{-1} = e^{-1}$$
>
>[3]考察边界与无穷远极限：
>
>- 当$x \to -\infty$时，$\lim_{x \to -\infty} xe^{-x} = -\infty$；
>- 当$x \to +\infty$时，由指数增长快于幂函数知$\lim_{x \to +\infty} xe^{-x} = 0$。
>
>故函数$g(x)$的连续值域为$(-\infty, e^{-1}]$。
>
>[4]确定参数范围：
>
>若方程$g(x) = a$无实数解，常数$a$必须严格大于值域上限，即$a > e^{-1}$。
>
>[5]故正确选项为 **(B)**。

**习题[3]:积分构造多项式辅助函数与罗尔定理**

设实数$a_0, a_1, a_2, \dots, a_n$满足等式：

$$a_0 + \frac{a_1}{2} + \frac{a_2}{3} + \dots + \frac{a_n}{n+1} = 0$$

证明：方程$a_0 + a_1 x + a_2 x^2 + \dots + a_n x^n = 0$在$(0, 1)$内至少有一个实根。

主要思路:待证多项式方程左侧恰为辅助函数$F(x) = \int_0^x (a_0 + a_1 t + \dots + a_n t^n)\mathrm{d}t$的导数，由已知条件验证端点$F(0) = F(1) = 0$后应用罗尔定理

>[1]构造辅助函数：
>
>观察待证方程左侧多项式，构造其原函数作为辅助函数：
>
>$$F(x) = a_0 x + \frac{a_1}{2}x^2 + \frac{a_2}{3}x^3 + \dots + \frac{a_n}{n+1}x^{n+1}$$
>
>[2]验证罗尔中值定理条件：
>
>- 作为多项式函数，$F(x)$在闭区间$[0, 1]$上显然连续，在开区间$(0, 1)$内处处可导；
>- 计算端点函数值：
>
> $$F(0) = 0$$
>
> $$F(1) = a_0 + \frac{a_1}{2} + \frac{a_2}{3} + \dots + \frac{a_n}{n+1}$$
>
>- 由已知条件$a_0 + \frac{a_1}{2} + \dots + \frac{a_n}{n+1} = 0$，得$F(1) = 0 = F(0)$。
>
>[3]应用罗尔定理得出结论：
>
>由罗尔中值定理，至少存在一点$\xi \in (0, 1)$，使得：
>
>$$F'(\xi) = 0$$
>
>而$F'(x) = a_0 + a_1 x + a_2 x^2 + \dots + a_n x^n$，代入即得：
>
>$$a_0 + a_1 \xi + a_2 \xi^2 + \dots + a_n \xi^n = 0$$
>
>即方程在$(0, 1)$内至少存在一个实根$\xi$。证毕。

**习题[4]:乘积导数与微分方程积分因子法**

设函数$f(x)$在$[a, b]$上连续，在$(a, b)$内可导，且$f(a) = f(b) = 0$。证明：

(1) 存在$\xi \in (a, b)$，使得$f(\xi) + \xi f'(\xi) = 0$；

(2) 存在$\eta \in (a, b)$，使得$\eta f(\eta) + f'(\eta) = 0$。

主要思路:第(1)问识别$[xf(x)]' = f(x) + xf'(x)$构造辅助函数$\varphi(x) = xf(x)$；第(2)问将$f'(x) + xf(x) = 0$视作一阶线性微分方程，求积分因子$e^{\frac{1}{2}x^2}$构造辅助函数$F(x) = e^{\frac{1}{2}x^2}f(x)$，应用罗尔定理证明

>[1]证明存在$\xi \in (a, b)$使得$f(\xi) + \xi f'(\xi) = 0$：
>
>**逆推辅助函数：** 注意到微分等式$f(x) + xf'(x) = [x f(x)]'$，构造辅助函数：
>
>  $$\varphi(x) = x f(x)$$
>
>**验证条件：** $\varphi(x)$在$[a, b]$上连续，在$(a, b)$内可导，且：
>
>  $$\varphi(a) = a f(a) = 0, \quad \varphi(b) = b f(b) = 0$$
>
>**应用罗尔定理：** 由罗尔定理，存在$\xi \in (a, b)$，使得$\varphi'(\xi) = 0$。又$\varphi'(x) = f(x) + x f'(x)$，故：
>
>  $$f(\xi) + \xi f'(\xi) = 0$$
>
>[2]证明存在$\eta \in (a, b)$使得$\eta f(\eta) + f'(\eta) = 0$：
>
>**逆推辅助函数：** 待证式为$f'(x) + x f(x) = 0$，对应一阶线性齐次微分方程$y' + xy = 0$。积分因子为$e^{\int x \mathrm{d}x} = e^{\frac{1}{2}x^2}$，两边乘积分因子得：
>
>  $$e^{\frac{1}{2}x^2}[f'(x) + x f(x)] = \left[e^{\frac{1}{2}x^2} f(x)\right]' = 0$$
>
>  故构造辅助函数：
>
>  $$F(x) = e^{\frac{1}{2}x^2} f(x)$$
>
>**验证条件：** $F(x)$在$[a, b]$上连续，在$(a, b)$内可导，端点值：
>
>  $$F(a) = e^{\frac{1}{2}a^2} f(a) = 0, \quad F(b) = e^{\frac{1}{2}b^2} f(b) = 0$$
>
>**应用罗尔定理：** 由罗尔定理，存在$\eta \in (a, b)$，使得$F'(\eta) = 0$。计算求导：
>
>  $$F'(x) = x e^{\frac{1}{2}x^2} f(x) + e^{\frac{1}{2}x^2} f'(x) = e^{\frac{1}{2}x^2}[x f(x) + f'(x)]$$
>
>  代入$\eta$得：
>
>  $$e^{\frac{1}{2}\eta^2}[\eta f(\eta) + f'(\eta)] = 0$$
>
>  因指数函数$e^{\frac{1}{2}\eta^2} \neq 0$恒成立，必有$\eta f(\eta) + f'(\eta) = 0$。证毕。

**习题[5]:幂函数因子辅助函数与拉格朗日中值定理**

设$f(x)$在$[0, 1]$上连续，在$(0, 1)$内可导。证明：至少存在一点$\xi \in (0, 1)$，使得：

$$f(1) = 3\xi^2 f(\xi) + \xi^3 f'(\xi)$$

主要思路:识别右侧结构为$[x^3 f(x)]' = 3x^2 f(x) + x^3 f'(x)$，构造辅助函数$F(x) = x^3 f(x)$，在$[0, 1]$上应用拉格朗日中值定理证得结论

>[1]识别导数结构与构造辅助函数：
>
>观察待证等式右侧$3\xi^2 f(\xi) + \xi^3 f'(\xi)$，容易识别出导数恒等式：
>
>$$\left[x^3 f(x)\right]' = 3x^2 f(x) + x^3 f'(x)$$
>
>故构造辅助函数：
>
>$$F(x) = x^3 f(x)$$
>
>[2]应用拉格朗日中值定理：
>
>因$f(x)$在$[0, 1]$上连续，在$(0, 1)$内可导，故$F(x) = x^3 f(x)$亦在$[0, 1]$上连续，在$(0, 1)$内可导。
>
>对$F(x)$在闭区间$[0, 1]$上应用拉格朗日中值定理，至少存在一点$\xi \in (0, 1)$，使得：
>
>$$F(1) - F(0) = F'(\xi)(1 - 0)$$
>
>[3]代入计算求值：
>
>- $F(1) = 1^3 \cdot f(1) = f(1)$；
>- $F(0) = 0^3 \cdot f(0) = 0$；
>- $F'(\xi) = 3\xi^2 f(\xi) + \xi^3 f'(\xi)$。
>
>代入即得：
>
>$$f(1) = 3\xi^2 f(\xi) + \xi^3 f'(\xi)$$
>
>命题得证。

**习题[6]:零点定理内部分割与双拉格朗日中值定理**

已知$f(x)$在$[0, 1]$上连续，在$(0, 1)$内可导，且满足$f(0) = 0, f(1) = 1$。证明：

(1) 存在$\xi \in (0, 1)$，使得$f(\xi) = 1 - \xi$；

(2) 存在$\eta, \tau \in (0, 1)$，$\eta \neq \tau$，使得$f'(\eta)f'(\tau) = 1$。

主要思路:第(1)问构造$F(x) = f(x) + x - 1$，由零点定理得到内点$\xi$；第(2)问以$\xi$为分界点将区间拆为$[0, \xi]$和$[\xi, 1]$，分别应用拉格朗日中值定理，利用倒数关系乘积为1

>[1]证明存在$\xi \in (0, 1)$使得$f(\xi) = 1 - \xi$：
>
>- 构造辅助函数$F(x) = f(x) + x - 1$；
>- $F(x)$在$[0, 1]$上连续，计算端点值：
>
>  $$F(0) = f(0) + 0 - 1 = -1 < 0$$
>  $$F(1) = f(1) + 1 - 1 = 1 > 0$$
>
>- 由零点存在定理，至少存在一点$\xi \in (0, 1)$，使得$F(\xi) = 0$，即：
>
>  $$f(\xi) = 1 - \xi$$
>
>[2]证明存在$\eta \neq \tau$使得$f'(\eta)f'(\tau) = 1$：
>
>- 利用第(1)问中求得的内点$\xi \in (0, 1)$，将整个区间划分为两个互不相交的子区间$[0, \xi]$与$[\xi, 1]$；
>- 在子区间$[0, \xi]$上应用拉格朗日中值定理：存在$\eta \in (0, \xi)$，使得：
>
>  $$f'(\eta) = \frac{f(\xi) - f(0)}{\xi - 0} = \frac{(1 - \xi) - 0}{\xi} = \frac{1 - \xi}{\xi}$$
>
>- 在子区间$[\xi, 1]$上应用拉格朗日中值定理：存在$\tau \in (\xi, 1)$，使得：
>
>  $$f'(\tau) = \frac{f(1) - f(\xi)}{1 - \xi} = \frac{1 - (1 - \xi)}{1 - \xi} = \frac{\xi}{1 - \xi}$$
>
>- 综合两式：因$0 < \eta < \xi < \tau < 1$，严格保证了$\eta \neq \tau$。两导数值相乘：
>
>  $$f'(\eta)f'(\tau) = \frac{1 - \xi}{\xi} \cdot \frac{\xi}{1 - \xi} = 1$$
>
>命题得证。

**习题[7]:拉格朗日与柯西中值定理联立消元**

设函数$f(x)$在$[a, b]$上连续($0 < a < b$)，在$(a, b)$内可导，且$f(a) \neq f(b)$。证明：存在$\xi, \eta \in (a, b)$，使得：$$\frac{f'(\xi)}{2\xi} = \frac{f'(\eta)}{b + a}$$

主要思路:分别对$f(x)$在$[a, b]$上应用拉格朗日中值定理，以及对$f(x)$与$g(x) = x^2$应用柯西中值定理，消去函数增量$f(b) - f(a)$得证

>[1]对$f(x)$应用拉格朗日中值定理：
>
>因$f(x)$在$[a, b]$上连续，在$(a, b)$内可导，存在$\eta \in (a, b)$，使得：
>
>$$f(b) - f(a) = f'(\eta)(b - a)$$
>
>[2]对$f(x)$与$g(x) = x^2$应用柯西中值定理：
>
>选取辅助函数$g(x) = x^2$：
>
>- $g(x)$在$[a, b]$上连续，在$(a, b)$内可导，且导数$g'(x) = 2x$；
>- 因$0 < a < b$，在$(a, b)$内恒有$g'(x) = 2x > 0 \neq 0$；
>- 满足柯西中值定理全部条件，故存在$\xi \in (a, b)$，使得： $$\frac{f(b) - f(a)}{g(b) - g(a)} = \frac{f'(\xi)}{g'(\xi)} \implies \frac{f(b) - f(a)}{b^2 - a^2} = \frac{f'(\xi)}{2\xi}$$
>
> - 整理得： $$f(b) - f(a) = \frac{f'(\xi)}{2\xi}(b^2 - a^2) = \frac{f'(\xi)}{2\xi}(b - a)(b + a)$$
>
>[3]联立消去函数增量：
>
> 将第[1]步与第[2]步等式联立：
>
>$$f'(\eta)(b - a) = \frac{f'(\xi)}{2\xi}(b - a)(b + a)$$
>
>因$a < b \implies b - a \neq 0$，两边同除以$(b - a)$得：
>
>$$f'(\eta) = \frac{f'(\xi)}{2\xi}(b + a)$$
>
>两端同除以$(b + a)$整理得：
>
>$$\frac{f'(\xi)}{2\xi} = \frac{f'(\eta)}{b + a}$$
>
>结论成立。证毕。

**习题[8]:内点泰勒公式展开与绝对值不等式放缩**

设$f(x)$在$[0, 1]$上具有二阶导数，且满足条件$\vert{}f(x)\vert{} \le a$，$\vert{}f''(x)\vert{} \le b$，其中$a, b$都是非负常数，$c$是$(0, 1)$内任意一点。

(1) 写出$f(x)$在点$x = c$处带拉格朗日型余项的一阶泰勒公式；

(2) 证明：$\vert{}f'(c)\vert{} \le 2a + \frac{b}{2}$。

主要思路:第(1)问直接写出在内点$c$处的泰勒展开；第(2)问分别代入两端点$x=0$和$x=1$，两式相减消去$f(c)$，应用三角不等式放缩，再结合二次函数极值上限完成证明

>[1]写出一阶泰勒公式：
>
>对任意$x \in [0, 1]$，$f(x)$在点$x = c$处带拉格朗日型余项的一阶泰勒公式为：
>
>$$f(x) = f(c) + f'(c)(x - c) + \frac{f''(\xi)}{2}(x - c)^2$$
>
>其中$\xi$介于$x$与$c$之间。
>
>[2]分别在两端点$x = 0$和$x = 1$处展开：
>
>- 代入$x = 0$：
>
>  $$f(0) = f(c) - f'(c)c + \frac{f''(\xi_1)}{2}c^2 \quad (\xi_1 \in (0, c)) \tag{1}$$
>
>- 代入$x = 1$：
>
>  $$f(1) = f(c) + f'(c)(1 - c) + \frac{f''(\xi_2)}{2}(1 - c)^2 \quad (\xi_2 \in (c, 1)) \tag{2}$$
>
>[3]两式相减消去未知的$f(c)$：
>
>式(2)减去式(1)得：
>
>$$f(1) - f(0) = f'(c) + \frac{1}{2}\left[ f''(\xi_2)(1 - c)^2 - f''(\xi_1)c^2 \right]$$
>
>移项解出$f'(c)$：
>
>$$f'(c) = f(1) - f(0) - \frac{1}{2}f''(\xi_2)(1 - c)^2 + \frac{1}{2}f''(\xi_1)c^2$$
>
>[4]应用三角不等式与条件放缩：
>
>$$\vert{}f'(c)\vert{} \le \vert{}f(1)\vert{} + \vert{}f(0)\vert{} + \frac{1}{2}\vert{}f''(\xi_2)\vert{}(1 - c)^2 + \frac{1}{2}\vert{}f''(\xi_1)\vert{}c^2$$
>
>已知$\vert{}f(x)\vert{} \le a$，$\vert{}f''(x)\vert{} \le b$，故：
>
>$$\vert{}f'(c)\vert{} \le a + a + \frac{b}{2}(1 - c)^2 + \frac{b}{2}c^2 = 2a + \frac{b}{2}\left[(1 - c)^2 + c^2\right]$$
>
>[5]二次函数极值分析与结论：
>
>考察二次项$h(c) = (1 - c)^2 + c^2 = 2c^2 - 2c + 1$：
>
>- $h(c)$对称轴为$c = \frac{1}{2}$，开口向上；
>- 当$c \in (0, 1)$时，$h(c) < \max\{h(0), h(1)\} = 1$。
>
>故：$$\vert{}f'(c)\vert{} \le 2a + \frac{b}{2} \cdot 1 = 2a + \frac{b}{2}$$
>
>命题得证。

**习题[9]:二阶导数凹凸性与割线不等式放缩**

证明：当$0 < x < \frac{\pi}{4}$时，恒有$\tan x < \frac{4}{\pi}x$。

主要思路:
方法一：二阶导数说明$f(x) = \tan x$在$\left[0, \frac{\pi}{4}\right]$上严格下凸，利用凸弧落在弦下方的几何性质证得；
方法二：构造商函数$g(x) = \frac{\tan x}{x}$，求导证明其在$\left(0, \frac{\pi}{4}\right]$上严格单调增加

>[1]方法一（二阶导数凹凸性几何弦弧关系法）：
>
>- 设函数$f(x) = \tan x$，在$\left[0, \frac{\pi}{4}\right]$上连续且二阶可导；
>- 计算一阶与二阶导数：
>
>  $$f'(x) = \sec^2 x$$
>  $$f''(x) = 2\sec^2 x \tan x$$
>
>- 当$x \in \left(0, \frac{\pi}{4}\right)$时，$\sec x > 0$且$\tan x > 0$，恒有$f''(x) > 0$。因此，曲线$y = \tan x$在区间$\left[0, \frac{\pi}{4}\right]$上是**严格凹函数(下凸)**；
>- 考察连接两端点$A(0, 0)$和$B\left(\frac{\pi}{4}, 1\right)$的割线（弦）：弦的斜率为$k = \frac{1 - 0}{\frac{\pi}{4} - 0} = \frac{4}{\pi}$，其割线方程为：
>
>  $$y = \frac{4}{\pi}x$$
>
>- 由严格下凸函数的几何性质，严格凹弧段恒位于连接其两端点的弦下方。故对任意$x \in \left(0, \frac{\pi}{4}\right)$，恒有：
>
>  $$\tan x < \frac{4}{\pi}x$$
>
>[2]方法二（辅助函数求导单调性法）：
>
>- 设辅助函数$g(x) = \frac{\tan x}{x} \ \left(0 < x \le \frac{\pi}{4}\right)$；
>- 求导分析分子：
>
>  $$g'(x) = \frac{x\sec^2 x - \tan x}{x^2} = \frac{x - \sin x\cos x}{x^2\cos^2 x} = \frac{2x - \sin 2x}{2x^2\cos^2 x}$$
>
>- 当$t > 0$时恒有$t > \sin t$，令$t = 2x > 0 \implies 2x - \sin 2x > 0$；
>- 故$g'(x) > 0$，$g(x)$在$\left(0, \frac{\pi}{4}\right]$上严格单调增加；
>- 故对$0 < x < \frac{\pi}{4}$，恒有：
>
>  $$g(x) < g\left(\frac{\pi}{4}\right) \implies \frac{\tan x}{x} < \frac{\tan\frac{\pi}{4}}{\frac{\pi}{4}} = \frac{4}{\pi} \implies \tan x < \frac{4}{\pi}x$$
>
>证毕。

**习题[10]:杨氏不等式的单变量极值证明**

设$p, q$是大于1的常数，并且满足$\frac{1}{p} + \frac{1}{q} = 1$。证明：对任意的$x > 0$，恒有：

$$\frac{1}{p}x^p + \frac{1}{q} \ge x$$

主要思路:移项构造辅助函数$f(x) = \frac{1}{p}x^p - x + \frac{1}{q}$，求导判定唯一驻点$x = 1$为全局绝对最小值点，计算最小值等于0完成证明

>[1]构造辅助函数：
>
>将不等式右侧移项至左侧，定义辅助函数：
>
>$$f(x) = \frac{1}{p}x^p - x + \frac{1}{q} \quad (x > 0)$$
>
>[2]求导与确定驻点：
>
>$$f'(x) = \frac{1}{p} \cdot p x^{p-1} - 1 = x^{p-1} - 1$$
>
>令$f'(x) = 0$，因$p > 1 \implies p - 1 > 0$，在$(0, +\infty)$内解得唯一驻点：
>
>$$x = 1$$
>
>[3]判定单调性与最小值：
>
>- 当$0 < x < 1$时，因$p - 1 > 0$，有$x^{p-1} < 1 \implies f'(x) < 0$，$f(x)$严格单调减少；
>- 当$x > 1$时，$x^{p-1} > 1 \implies f'(x) > 0$，$f(x)$严格单调增加；
>- 因此，$x = 1$是$f(x)$在$(0, +\infty)$上的全域唯一极小值点，即全局绝对最小值点。
>
>[4]计算最小值：
>
>$$f_{\min} = f(1) = \frac{1}{p}(1)^p - 1 + \frac{1}{q} = \frac{1}{p} + \frac{1}{q} - 1$$
>
>由已知条件$\frac{1}{p} + \frac{1}{q} = 1$，代入得：
>
>$$f(1) = 1 - 1 = 0$$
>
>[5]得出不等式结论：
>
>对任意$x > 0$，恒有：
>
>$$f(x) \ge f(1) = 0 \implies \frac{1}{p}x^p - x + \frac{1}{q} \ge 0 \implies \frac{1}{p}x^p + \frac{1}{q} \ge x$$
>
>等号成立当且仅当$x = 1$。证毕。
