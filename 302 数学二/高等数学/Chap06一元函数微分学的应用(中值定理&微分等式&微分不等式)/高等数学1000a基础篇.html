(罗尔定理隔离法)题目[1]:三次多项式导函数实根个数

设函数 $f(x)=x(2x-3)(4x-5)$，则方程 $f'(x)=0$ 的实根个数为 $(\quad)$。

(A) 0
(B) 1
(C) 2
(D) 3

答案: (C)

主要思路:[应用罗尔定理推论：若连续可导函数有 $n$ 个互异实零点，则其一阶导函数在各相邻零点之间至少各有 1 个实根]

[1] 求解原函数的全部互异实根：

令 $f(x) = 0$：

$$x(2x-3)(4x-5) = 0$$

解得 3 个互不相等的实数根，按升序排列为：

$$x_1 = 0, \quad x_2 = \frac{5}{4} = 1.25, \quad x_3 = \frac{3}{2} = 1.5$$

[2] 在各相邻开区间应用罗尔中值定理：

(1) $f(x)$ 是多项式函数，在实数域处处连续可导；

(2) 在闭区间 $[x_1, x_2] = [0, 5/4]$ 上：$f(0) = f(5/4) = 0$。由罗尔定理，必存在 $\xi_1 \in (0, 5/4)$，使得：

$$f'(\xi_1) = 0$$

(3) 在闭区间 $[x_2, x_3] = [5/4, 3/2]$ 上：$f(5/4) = f(3/2) = 0$。由罗尔定理，必存在 $\xi_2 \in (5/4, 3/2)$，使得：

$$f'(\xi_2) = 0$$

[3] 确定根的唯一性与总个数：

原函数 $f(x) = 8x^3 - 22x^2 + 15x$ 为 3 次多项式，其一阶导数 $f'(x) = 24x^2 - 44x + 15$ 是 2 次多项式。

由代数基本定理，二次方程在复数域上至多有 2 个根。既然已在实轴上找到了两个互异实根 $\xi_1 < \xi_2$，则方程 $f'(x)=0$ 的实根个数必恰为 2 个。

正确选项为 (C)。

[核心反思]:牢记经典定理：$n$ 次实系数多项式如果有 $n$ 个互异实根，则其 $k$ 阶导数必有恰好 $n-k$ 个互异实根，且依次在各相邻两根之间严格穿插隔离！

(最值单调性区间题)题目[2]:参变量单调性与方程有解区间

若方程 $x - e\ln x - k = 0$ 在 $(0, 1]$ 上有解，则 $k$ 的最小值为 $(\quad)$。

(A) $-1$
(B) $\frac{1}{e}$
(C) 1
(D) $e$

答案: (C)

主要思路:[分离参数得到 $k = g(x) = x - e\ln x$，求导分析函数在区间 $(0, 1]$ 上的单调性求值域]

[1] 构造函数并求一阶导数：

将原方程变形为分离参数形式：

$$k = x - e\ln x$$

定义辅助函数 $g(x) = x - e\ln x$，自变量限定在区间 $(0, 1]$。

求一阶导数：

$$g'(x) = 1 - \frac{e}{x} = \frac{x - e}{x}$$

[2] 在目标区间上判定单调性：

对于任意 $x \in (0, 1]$：

分母 $x > 0$；分子 $x - e \le 1 - e < 0$（因为 $e \approx 2.718 > 1$）。

故在区间 $(0, 1]$ 内恒有 $g'(x) < 0$。

这表明函数 $g(x)$ 在半开半闭区间 $(0, 1]$ 上是严格单调递减的。

[3] 计算值域并求解最小参数 $k$：

由单调减函数的极值特征：

最小值在区间右端点 $x = 1$ 处取得：

$$g_{\min} = g(1) = 1 - e\ln 1 = 1 - 0 = 1$$

当 $x \to 0^+$ 时：

$$\lim\limits_{x \to 0^+} g(x) = \lim\limits_{x \to 0^+} (x - e\ln x) = 0 - e(-\infty) = +\infty$$

因此，函数在 $(0, 1]$ 上的取值范围（值域）为 $[1, +\infty)$。

方程在 $(0, 1]$ 上有解充要条件为参数 $k$ 落在该值域内，即 $k \ge 1$。

故 $k$ 的最小值为 $1$，选 (C)。

[易错警示]:若不注意限定区间 $(0, 1]$，误令 $g'(x)=0$ 得 $x=e$，算得 $g(e)=e-e=0$，就会误选不存在的选项！解题切记先画出定义域的大红线。

(参数分离两零点模型)题目[3]:指数与线性函数两零点分离模型

设函数 $f(x)=ae^x-bx\ (a>0)$ 有两个零点，则 $\frac{b}{a}$ 的取值范围是 $(\quad)$。

(A) $\left(0, \frac{1}{e}\right)$
(B) $(0, e)$
(C) $\left(\frac{1}{e}, +\infty\right)$
(D) $(e, +\infty)$

答案: (D)

主要思路:[分离变量将方程转化为水平线与定曲线交点问题，分析曲线极小值点与渐近线]

[1] 分离常数与变量建模：

方程 $f(x) = 0 \iff ae^x - bx = 0$。

显然 $x = 0$ 时 $f(0) = a > 0$，故 $x=0$ 绝不是零点。

因为 $a > 0$，等式两边同除以 $ax$（注意 $x \ne 0$）：

$$\frac{b}{a} = \frac{e^x}{x}$$

问题转化为考察水平直线 $y = \frac{b}{a}$ 与曲线 $g(x) = \frac{e^x}{x}$ 的交点个数。

[2] 讨论 $g(x)$ 的图像与极值：

求导：

$$g'(x) = \frac{e^x \cdot x - e^x \cdot 1}{x^2} = \frac{e^x(x-1)}{x^2}$$

驻点为 $x = 1$。

(1) 当 $x > 0$ 时：

  • 当 $0 < x < 1$ 时，$g'(x) < 0$，$g(x)$ 单调递减；
  • 当 $x > 1$ 时，$g'(x) > 0$，$g(x)$ 单调递增；
  • 在 $x = 1$ 处取得极小值：$g(1) = \frac{e^1}{1} = e$；
  • 边界极限：$\lim\limits_{x \to 0^+} g(x) = +\infty$，$\lim\limits_{x \to +\infty} g(x) = +\infty$。

(2) 当 $x < 0$ 时：

  • 因为 $e^x > 0$ 且 $x < 0$，恒有 $g(x) = \frac{e^x}{x} < 0$；
  • 且 $g'(x) = \frac{e^x(x-1)}{x^2} < 0$（因为 $x-1 < 0$），在 $(-\infty, 0)$ 上单调递减，取值范围为 $(-\infty, 0)$。

[3] 确定两个交点的参数条件：

若直线 $y = \frac{b}{a}$ 与 $g(x)$ 有两个不同交点：

  • 若 $\frac{b}{a} \le 0$：由于在 $x<0$ 侧单调减，只有 1 个交点，在 $x>0$ 侧无交点，总计只有 1 个交点，不符；
  • 若 $0 < \frac{b}{a} < e$：在 $x<0$ 侧无交点，在 $x>0$ 侧因低于极小值 $e$ 也无交点，总计 0 个交点；
  • 若 $\frac{b}{a} = e$：在 $x=1$ 处只有 1 个相切交点；
  • 若 $\frac{b}{a} > e$：在 $(0, 1)$ 与 $(1, +\infty)$ 两侧各有 1 个交点，总计 2 个交点！

综上，必有 $\frac{b}{a} \in (e, +\infty)$，选 (D)。

[秒杀技巧]:分离变量法是解含参多零点问题的屠龙刀！直接将动参固定为一条水平线，把复杂的超越函数化为极值点 $g(1)=e$ 的开口向上双分支曲线，一眼秒看 (D)！

(最大值横截题)题目[4]:对数线性差值函数零点双向分布

已知函数 $f(x)=\ln x - \frac{x}{e} + a\ (x>0)$ 有两个零点，则 $a$ 的取值范围是 $(\quad)$。

(A) $(-1, 0)$
(B) $(0, 1)$
(C) $(-\infty, 0)$
(D) $(0, +\infty)$

答案: (D)

主要思路:[设不含参的函数 $g(x) = \ln x - x/e$，求导判定其最大值为 0，水平割线 $-a$ 必须严格低于最大值]

[1] 变形式子分离参数：

原方程 $f(x) = 0 \iff \ln x - \frac{x}{e} = -a$。

令基本母函数 $g(x) = \ln x - \frac{x}{e}\ (x > 0)$。

[2] 求导分析母函数 $g(x)$ 的最大值：

求一阶导数：

$$g'(x) = \frac{1}{x} - \frac{1}{e} = \frac{e - x}{ex}$$

驻点为 $x = e$。

(1) 当 $0 < x < e$ 时，$g'(x) > 0$，$g(x)$ 严格单调递增；

(2) 当 $x > e$ 时，$g'(x) < 0$，$g(x)$ 严格单调递减。

因此，函数在 $x = e$ 处取得全局唯一最大值：

$$g_{\max} = g(e) = \ln e - \frac{e}{e} = 1 - 1 = 0$$

[3] 分析两端渐近极限：

(1) 当 $x \to 0^+$ 时，$\ln x \to -\infty$，$\frac{x}{e} \to 0$，故 $\lim\limits_{x \to 0^+} g(x) = -\infty$；

(2) 当 $x \to +\infty$ 时，一次多项式的增长远超对数，$\lim\limits_{x \to +\infty} g(x) = -\infty$。

[4] 确定双交点的代数条件：

曲线 $y = g(x)$ 从 $-\infty$ 上升至顶点 $(e, 0)$，再下降至 $-\infty$。

要使水平直线 $y = -a$ 与曲线有两个不同交点，直线必须严格低于顶点高度：

$$-a < g_{\max} = 0 \iff a > 0$$

故 $a$ 的取值范围是 $(0, +\infty)$，选 (D)。

[核心反思]:本题最大的陷阱在于符号转换：$-a < 0$ 得到 $a > 0$！如果草率地认为“必须是负数”而错选 (C)，就彻底掉入了命题人的符号负号陷阱！

(中值定理高阶展开题)题目[5]:反正弦函数拉格朗日中值参数极限

设存在 $0<\theta<1$，使得 $\arcsin x = \frac{x}{\sqrt{1-(\theta x)^2}}$，$-1\le x\le 1$，则 $\lim\limits_{x\to 0}\theta =$ ______。

答案: $\frac{\sqrt{3}}{3}$

主要思路:[运用拉格朗日中值定理，双向展开反正弦与根式分式至 $x^3$ 项，对比系数求极限]

[1] 拉格朗日中值定理的形式对应：

设 $f(t) = \arcsin t$，在区间 $[0, x]$ 上应用拉格朗日中值定理：

$$\arcsin x - \arcsin 0 = f'(\theta x) (x - 0) = \frac{1}{\sqrt{1 - (\theta x)^2}} \cdot x$$

题设所给等式正是拉格朗日中值定理的形式化体现，其中中值点为 $\xi = \theta x$，$\theta \in (0, 1)$。

[2] 对等式左侧进行三阶泰勒展开：

利用标准麦克劳林展开式：

$$\arcsin x = x + \frac{1}{6}x^3 + o(x^3)$$

[3] 对等式右侧进行负二项式展开：

利用公式 $(1 - u)^{-1/2} = 1 + \frac{1}{2}u + o(u)$，此处 $u = (\theta x)^2 = \theta^2 x^2$：

$$\frac{x}{\sqrt{1 - (\theta x)^2}} = x \left(1 - \theta^2 x^2\right)^{-1/2} = x \left(1 + \frac{1}{2}\theta^2 x^2 + o(x^2)\right) = x + \frac{1}{2}\theta^2 x^3 + o(x^3)$$

[4] 联立对比求极限：

两边相等：

$$x + \frac{1}{6}x^3 + o(x^3) = x + \frac{1}{2}\theta^2 x^3 + o(x^3)$$

消去首项 $x$ 并两边同除以 $x^3$：

$$\frac{1}{6} + o(1) = \frac{1}{2}\theta^2 + o(1)$$

当 $x \to 0$ 时取极限：

$$\frac{1}{2}\lim\limits_{x\to 0}\theta^2 = \frac{1}{6} \implies \lim\limits_{x\to 0}\theta^2 = \frac{1}{3}$$

由于 $0 < \theta < 1$ 恒为正数：

$$\lim\limits_{x\to 0} \theta = \frac{1}{\sqrt{3}} = \frac{\sqrt{3}}{3}$$

[方法提炼]:中值 $\theta$ 在 $x\to 0$ 时的极限问题，本质就是高阶导数或泰勒展开的系数比较法！展开到两式产生首个非平凡差别的阶数，即可秒杀。

(经典不等式基础证明)题目[6]:对数基础双向不等式标准证明

设 $x>0$，证明 $\frac{x}{1+x} < \ln(1+x) < x$。

答案: 证明见步骤

主要思路:[对函数 $f(t)=\ln(1+t)$ 在闭区间 $[0, x]$ 上应用拉格朗日中值定理，利用中值点的开区间界限严格放缩]

[1] 选定函数与应用区间：

令 $f(t) = \ln(1+t)$。

因为 $x > 0$，函数 $f(t)$ 在闭区间 $[0, x]$ 上处处连续，在开区间 $(0, x)$ 内可导，一阶导数为：

$$f'(t) = \frac{1}{1+t}$$

[2] 应用拉格朗日中值定理：

由拉格朗日中值定理，必定存在 $\xi \in (0, x)$，使得：

$$f(x) - f(0) = f'(\xi)(x - 0)$$

即：

$$\ln(1+x) - \ln 1 = \frac{1}{1+\xi} \cdot x \implies \ln(1+x) = \frac{x}{1+\xi}$$

[3] 由中值点范围严格两极放缩：

因为中值点落在开区间内部：

$$0 < \xi < x$$

各边加上 1：

$$1 < 1+\xi < 1+x$$

$$\frac{1}{1+x} < \frac{1}{1+\xi} < 1$$

因为 $x > 0$，令：

(3) 左边项：$\frac{1}{1+x} = \frac{1}{1+\frac{1}{t}} = \frac{1}{\frac{t+1}{t}} = \frac{t}{1+t}$。

$$\frac{t}{1+t} < \ln(1+t) < t$$

这正是题目[6]已完全证实的标准结论。

(导数界限约束原函数)题目[8]:导数绝对值有界约束原函数增长

设函数 $f(x)$ 可导，且 $|f'(x)|\le 1$，$f(0)=1$，证明 $|f(x)|\le 1+x,\ 0

答案: 证明见步骤

主要思路:[对 $f(x)$ 在 $[0, x]$ 应用拉格朗日中值定理，结合绝对值三角不等式放缩]

[1] 应用拉格朗日中值定理：

对于任意固定的 $x \in (0, 1)$，函数 $f(t)$ 在闭区间 $[0, x]$ 上可导连续。

由拉格朗日中值定理，存在 $\xi \in (0, x)$，使得：

$$f(x) - f(0) = f'(\xi)(x - 0) = f'(\xi) x$$

代入 $f(0) = 1$：

$$f(x) = 1 + f'(\xi) x$$

[2] 应用绝对值三角不等式放缩：

两边取绝对值：

$$|f(x)| = |1 + f'(\xi) x| \le |1| + |f'(\xi) x| = 1 + |f'(\xi)| \cdot |x|$$

因为 $0 < x < 1$，故 $|x| = x$。

又已知 $|f'(x)| \le 1$ 对一切点成立，故 $|f'(\xi)| \le 1$。代入上式：

$$|f(x)| \le 1 + 1 \cdot x = 1 + x$$

命题得证。

[核心反思]:导数控制了函数的最大可能爬升速率（斜率绝对值不超过 1），从 $(0, 1)$ 出发，经过距离 $x$，函数值偏离不会超过 $1 \times x$，极其朴素的物理直观！

(无穷跨度差极限辨析)题目[9]:导函数无穷远处趋零推导跨度差极限

设函数 $f(x)$ 在 $[a, +\infty)\ (a>0)$ 上一阶导数连续，$\lim\limits_{x\to +\infty}f'(x)=0$，则 $(\quad)$。

(A) $\lim\limits_{x\to +\infty}\left[f(2x)+f(x)\right]=0$
(B) $\lim\limits_{x\to +\infty}\left[f(2x)-f(x)\right]=0$
(C) $\lim\limits_{x\to +\infty}\left[f(x+1)-f(x)\right]=0$
(D) $\lim\limits_{x\to +\infty}\left[f(x+1)+f(x)\right]=0$

答案: (C)

主要思路:[在区间 $[x, x+1]$ 上应用拉格朗日中值定理，固定跨度为 1 使得中值定理因子不发散]

[1] 严格证明 (C) 项：

在区间 $[x, x+1]$ 上对 $f(t)$ 应用拉格朗日中值定理：

$$f(x+1) - f(x) = f'(\xi) \cdot [(x+1) - x] = f'(\xi) \cdot 1$$

其中中值点满足：

$$x < \xi < x+1$$

当 $x \to +\infty$ 时，由夹逼准则，显然有 $\xi \to +\infty$。

因为已知 $\lim\limits_{t \to +\infty} f'(t) = 0$，所以：

$$\lim\limits_{x \to +\infty} [f(x+1) - f(x)] = \lim\limits_{\xi \to +\infty} f'(\xi) = 0$$

故 (C) 正确。

[2] 反例排除其他选项：

取反例函数：$f(x) = \ln x$。

(1) 检验题设：$f'(x) = \frac{1}{x}$，当 $x \to +\infty$ 时 $\lim f'(x) = 0$，完全符合全部前提；

(2) 检验 (B) 项：

$$f(2x) - f(x) = \ln(2x) - \ln x = \ln\left(\frac{2x}{x}\right) = \ln 2 \ne 0$$

故 (B) 错误！(其本质在于拉格朗日展开后为 $f'(\xi) \cdot x$，虽然 $f' \to 0$ 但 $x \to \infty$，形成 $0 \cdot \infty$ 不定式，并不为 0)；

(3) 检验 (A) 与 (D) 项：取 $f(x) = C \ne 0$（常数函数），导数恒为 0，但 $f(x+1)+f(x) = 2C \ne 0$。故 (A)(D) 均错误。

综上，唯一正确选项为 (C)。

(导数连续性对极限的影响)题目[10]:设函数导数连续计算动点极限

设函数 $f(x)$ 在 $x=1$ 处一阶导数连续，且 $f'(1)=2$，则 $\lim\limits_{x\to 1^+}\frac{f(x)-f(1)}{\ln x} =$ ______。

答案: $2$

主要思路:[分母等价无穷小代换 $\ln x = \ln(1 + (x-1)) \sim x-1$，直接转化为导数定义式]

[1] 分母等价无穷小替换：

当 $x \to 1^+$ 时，$x - 1 \to 0^+$。

运用等价无穷小公式 $\ln(1+u) \sim u\ (u \to 0)$：

$$\ln x = \ln[1 + (x-1)] \sim x-1$$

[2] 转化为导数定义式：

$$\lim\limits_{x\to 1^+}\frac{f(x)-f(1)}{\ln x} = \lim\limits_{x\to 1^+}\frac{f(x)-f(1)}{x-1}$$

由导数在点 $x=1$ 处的定义：

$$\lim\limits_{x\to 1^+}\frac{f(x)-f(1)}{x-1} = f'(1)$$

已知 $f'(1) = 2$，故原极限值为 $2$。

(注：因为题设给出了 $f'(x)$ 在 $x=1$ 处连续，本题亦可合法使用洛必达法则：原式 $= \lim_{x\to 1^+} \frac{f'(x)}{1/x} = \frac{f'(1)}{1} = 2$)。

[规范提醒]:即使可以使用洛必达法则，考研中最稳妥、速度最快的仍然是分母等价代换后识别导数定义！

(考研灵魂辨析题)题目[11]:仅导数存在与导函数连续的区别辨析

设 $f'(1)=2$，计算 $\lim\limits_{x\to 1^+}\frac{f(x)-f(1)}{\ln x}$，并指出与第10题的区别。

答案: 极限值为 $2$；区别在于：第10题因一阶导连续可合法使用洛必达法则，而本题仅已知 $f'(1)$ 在一点存在，不能使用洛必达法则，必须严格使用导数定义与等价无穷小。

主要思路:[严格使用等价无穷小转化，禁止非法调用洛必达法则]

[1] 极限的严密求解过程：

当 $x \to 1^+$ 时，$\ln x \sim x-1$。

原极限严格写为：

$$\lim\limits_{x\to 1^+}\frac{f(x)-f(1)}{\ln x} = \lim\limits_{x\to 1^+}\left[\frac{f(x)-f(1)}{x-1} \cdot \frac{x-1}{\ln x}\right]$$

因为由导数定义：$\lim\limits_{x\to 1^+}\frac{f(x)-f(1)}{x-1} = f'(1) = 2$ 存在；

且 $\lim\limits_{x\to 1^+}\frac{x-1}{\ln x} = 1$ 存在。

由极限四则运算法则：

$$\text{原式} = f'(1) \cdot 1 = 2$$

[2] 与第10题的本质区别（命题内核剖析）：

(1) 洛必达法则的使用前提：洛必达法则 $\lim \frac{f(x)}{g(x)} = \lim \frac{f'(x)}{g'(x)}$ 要求 $f'(x)$ 在点 $x=1$ 的去心邻域内存在，且在 $x\to 1$ 时 $\frac{f'(x)}{g'(x)}$ 的极限必须存在（即本质依赖于导函数的连续性或极限定律）；

(2) 本题的条件限制：本题仅说明“$f'(1)=2$”，这意味着在 $x=1$ 的去心邻域内 $f'(x)$ 是否存在、甚至是否存在震荡都不确定！若直接洛必达写出 $\lim \frac{f'(x)}{1/x}$，将犯下严重的逻辑前提未定错误！

因此，第10题可以使用洛必达，而本题绝对不能使用洛必达法则，只能使用导数定义！

[核心反思]:这是张宇、李林等考研名师年年必讲的经典辨析！“一点可导”绝推不出“去心邻域可导”，更推不出“导函数连续”，洛必达法则必须慎用！

(泰勒余项放缩证明题)题目[12]:正弦函数一阶泰勒带余项及比值不等式

[1] 将 $\sin x$ 在 $x=0$ 处展开成一阶带拉格朗日余项的泰勒公式；
[2] 证明 $\left|\frac{\sin x}{x}-1\right| \le \frac{1}{2}|x|,\ x\ne 0$。

答案: [1] $\sin x = x - \frac{\sin\xi}{2}x^2$（$\xi$ 介于 $0$ 与 $x$ 之间）；[2] 证明见步骤。

主要思路:[写出 $n=1$ 阶麦克劳林公式，两边同除以 $x$ 移项取绝对值放缩]

[1] 写出一阶带拉格朗日余项的泰勒公式：

设 $f(x) = \sin x$，求一阶与二阶导数：

$$f'(x) = \cos x \implies f'(0) = 1$$

$$f''(x) = -\sin x$$

由一阶带拉格朗日余项的泰勒展开公式：

$$f(x) = f(0) + f'(0)x + \frac{f''(\xi)}{2!}x^2$$

代入各项数据，即得：

$$\sin x = x - \frac{\sin\xi}{2}x^2$$

其中 $\xi$ 位于 $0$ 与 $x$ 之间。

[2] 证明目标不等式：

由 [1] 的结论，两边同时减去 $x$：

$$\sin x - x = -\frac{\sin\xi}{2}x^2$$

因为 $x \ne 0$，两边同除以 $x$：

$$\frac{\sin x}{x} - 1 = -\frac{\sin\xi}{2} x$$

两边取绝对值：

$$\left|\frac{\sin x}{x} - 1\right| = \left|-\frac{\sin\xi}{2} x\right| = \frac{|\sin\xi|}{2} \cdot |x|$$

因为对任意实数 $\xi$，恒有正弦有界性 $|\sin\xi| \le 1$：

$$\frac{|\sin\xi|}{2} \cdot |x| \le \frac{1}{2} |x|$$

故不等式证毕：

$$\left|\frac{\sin x}{x} - 1\right| \le \frac{1}{2}|x| \quad (x \ne 0)$$

[核心反思]:带拉格朗日余项的泰勒公式是不等式证明的王牌武器。通过将余项中的三角或指数因子直接用最大有界常数放缩，往往能瞬间达成目标。

(曲线交点个数隔离题)题目[13]:指数与三次多项式曲线交点个数

(2) 当 $x \to +\infty$ 时，指数增长远快于三次多项式，$\lim\limits_{x\to +\infty} g(x) = +\infty$。

[2] 精确代入特殊整数点寻找变号区间：

(1) 代入 $x = -2$：

$$g(-2) = e^{-1} - (-8) - 6 = \frac{1}{e} + 2 > 0$$

(2) 代入 $x = -1$：

$$g(-1) = e^{-1/2} - (-1) - 3 = \frac{1}{\sqrt{e}} - 2 < 0 \quad (\text{因为 } \sqrt{e} > 1 \implies 1/\sqrt{e} < 1)$$

在 $(-\infty, -1)$ 内，$g(x)$ 从正变负，必有第 1 个零点 $x_1 \in (-2, -1)$；

(3) 代入 $x = 0$：

$$g(0) = e^0 - 0 + 0 = 1 > 0$$

在 $(-1, 0)$ 内，$g(x)$ 从负变正，必有第 2 个零点 $x_2 \in (-1, 0)$；

(4) 代入 $x = 2$：

$$g(2) = e^1 - 8 + 6 = e - 2 \approx 2.718 - 2 = 0.718 > 0$$

(5) 代入 $x = 3$：

$$g(3) = e^{1.5} - 27 + 9 = e\sqrt{e} - 18 < 2.8 \times 1.7 - 18 < 0$$

在 $(2, 3)$ 内，$g(x)$ 从正变负，必有第 3 个零点 $x_3 \in (2, 3)$；

(6) 当 $x \to +\infty$ 时，$g(x) \to +\infty$：

在 $(3, +\infty)$ 内，$g(x)$ 从负变正，必有第 4 个零点 $x_4 \in (3, +\infty)$。

[3] 确定根的上限排除更多交点：

求二阶导数：$g''(x) = \frac{1}{4}e^{x/2} - 6x$。易知 $g''(x)=0$ 至多有 2 个实根，根据罗尔定理推论，$g(x)=0$ 至多有 4 个实根。

既然已严格隔离开 4 个互异变号区间，故实根个数（即曲线交点个数）恰好为 4 个。

(商导数单调性判别题)题目[14]:商导数保号性判定函数大小关系

设 $f(x)$ 是连续可导函数，当 $0

(B) $bf(x) > xf(b)$
(C) $xf(x) > bf(b)$
(D) $xf(x) < af(a)$

[1] 构造商辅助函数并求导：

由已知条件，分子 $x f'(x) - f(x) < 0$，而分母 $x^2 > 0$。

故在区间 $(a, b)$ 上恒有：

$$F'(x) < 0$$

这证明函数 $F(x) = \frac{f(x)}{x}$ 在区间 $[a, b]$ 上是严格单调递减的。

$$\frac{f(x)}{x} > \frac{f(b)}{b} \implies b f(x) > x f(b)$$

这正是选项 (B)！

(双函数商单调性题)题目[17]:两函数商的导数正负推导不等式

(A) $f(a)g(x) > f(x)g(b)$
(B) $f(x)g(a) > f(b)g(x)$
(C) $f(a)g(b) > f(b)g(x)$
(D) $f(x)g(b) > f(b)g(x)$

答案: (D)

主要思路:[移项构造比值函数 $H(x) = \frac{f(x)}{g(x)}$，由导数小于零推导单调减少，去分母化简]

[1] 识别商导数模型：

已知不等式：

$$f'(x)g(x) - f(x)g'(x) < 0$$

因为已知 $g(x) > 0$，两边同除以 $g^2(x) > 0$：

$$\frac{f'(x)g(x) - f(x)g'(x)}{g^2(x)} < 0 \iff \left(\frac{f(x)}{g(x)}\right)' < 0$$

[2] 构造单调函数：

设辅助函数 $H(x) = \frac{f(x)}{g(x)}$，则 $H(x)$ 在区间 $[a, b]$ 上严格单调递减。

[3] 提取区间不等式并去分母：

由于 $a < x < b$，由单调递减性必有：

$$H(x) > H(b)$$

代入 $H$ 的表达式：

$$\frac{f(x)}{g(x)} > \frac{f(b)}{g(b)}$$

因为 $g(x) > 0$ 且 $g(b) > 0$，两边同乘正数 $g(x)g(b)$：

$$f(x)g(b) > f(b)g(x)$$

对照选项，完全匹配 (D)。

(1) $f'g + fg' = (fg)'$
(2) $f'g - fg' = g^2 (f/g)'$
(3) $f' + f = (f e^x)' e^{-x}$
(4) $f' - f = (f e^{-x})' e^x$

(对称最值不等式证明)题目[18]:对称区间参数幂和极值最值不等式

设 $0\le x\le 1,\ p>1$，证明 $\frac{1}{2^{p-1}} \le x^p + (1-x)^p \le 1$。

答案: 证明见步骤

主要思路:[构造对称函数 $g(x) = x^p + (1-x)^p$，求导确定极小值点 $x=1/2$ 与端点最大值]

[1] 构造函数并求导：

定义闭区间 $[0, 1]$ 上的函数：

$$g(x) = x^p + (1-x)^p \quad (p > 1)$$

对 $x$ 求一阶导数：

$$g'(x) = p x^{p-1} + p (1-x)^{p-1} (-1) = p \left[x^{p-1} - (1-x)^{p-1}\right]$$

[2] 寻找驻点并分析单调性：

令 $g'(x) = 0$：

$$x^{p-1} = (1-x)^{p-1}$$

因为 $p > 1 \implies p-1 > 0$，幂函数严格单调递增，故必有：

$$x = 1-x \iff 2x = 1 \iff x = \frac{1}{2}$$

(1) 当 $0 \le x < \frac{1}{2}$ 时，$x < 1-x \implies x^{p-1} < (1-x)^{p-1} \implies g'(x) < 0$，$g(x)$ 单调递减；

(2) 当 $\frac{1}{2} < x \le 1$ 时，$x > 1-x \implies x^{p-1} > (1-x)^{p-1} \implies g'(x) > 0$，$g(x)$ 单调递增。

[3] 计算极小值与端点最大值：

(1) 最小值在唯一极小值点 $x = \frac{1}{2}$ 处取得：

$$g_{\min} = g\left(\frac{1}{2}\right) = \left(\frac{1}{2}\right)^p + \left(1 - \frac{1}{2}\right)^p = 2 \cdot \left(\frac{1}{2}\right)^p = \frac{2}{2^p} = \frac{1}{2^{p-1}}$$

(2) 最大值在区间两端点处取得：

$$g(0) = 0^p + 1^p = 1, \quad g(1) = 1^p + 0^p = 1 \implies g_{\max} = 1$$

因此对任意 $x \in [0, 1]$，恒有：

$$\frac{1}{2^{p-1}} \le x^p + (1-x)^p \le 1$$

命题得证。

[琴生不等式秒杀]:凸函数 $f(t)=t^p\ (p>1)$ 满足 $\frac{x^p+(1-x)^p}{2} \ge \left(\frac{x+1-x}{2}\right)^p = \left(\frac{1}{2}\right)^p \implies x^p+(1-x)^p \ge 2 \cdot \frac{1}{2^p} = \frac{1}{2^{p-1}}$，两行直接封顶！

(三次多项式全景讨论题)题目[19]:对于常数实根个数分类讨论标准大题

对于 $k$ 的不同取值情况，确定方程 $x^3-3x+k=0$ 实根的个数，并证明你的结论。

答案:
当 $k < -2$ 或 $k > 2$ 时，方程有 1 个实根；
当 $k = -2$ 或 $k = 2$ 时，方程有 2 个实根（其中 1 个为二重根）；
当 $-2 < k < 2$ 时，方程有 3 个互不相等的实根。

主要思路:[分离变量为 $-k = x^3 - 3x$，求导确定极大值与极小值，根据水平直线穿行的 5 种状态严谨论证]

[1] 分离参数与极值求导：

原方程可改写为：

$$x^3 - 3x = -k$$

令母函数 $g(x) = x^3 - 3x$。

求导：

$$g'(x) = 3x^2 - 3 = 3(x+1)(x-1)$$

令 $g'(x) = 0$，驻点为 $x_1 = -1,\ x_2 = 1$。

[2] 单调性与极值计算：

(1) 当 $x \in (-\infty, -1)$ 时，$g'(x) > 0$，$g(x)$ 严格单调递增；

(2) 在 $x = -1$ 处取得极大值：$g(-1) = (-1)^3 - 3(-1) = 2$；

(3) 当 $x \in (-1, 1)$ 时，$g'(x) < 0$，$g(x)$ 严格单调递减；

(4) 在 $x = 1$ 处取得极小值：$g(1) = 1^3 - 3(1) = -2$；

(5) 当 $x \in (1, +\infty)$ 时，$g'(x) > 0$，$g(x)$ 严格单调递增。

且两端极限为：$\lim\limits_{x\to -\infty} g(x) = -\infty$，$\lim\limits_{x\to +\infty} g(x) = +\infty$。

[3] 分类讨论水平割线 $y = -k$ 的位置：

(1) 当 $-k > 2$（即 $k < -2$）时：水平线高于极大值，仅在 $(1, +\infty)$ 侧有 1 个交点，方程有 1 个实根；

(2) 当 $-k = 2$（即 $k = -2$）时：水平线切于极大值点，在 $x=-1$ 处有 1 个二重实根，在 $(1, +\infty)$ 侧有 1 个单实根，方程共 2 个实根；

(3) 当 $-2 < -k < 2$（即 $-2 < k < 2$）时：水平线穿行于极小值与极大值之间，分别在 $(-\infty, -1)$、$(-1, 1)$、$(1, +\infty)$ 内各截得 1 个交点，方程有 3 个互异实根；

(4) 当 $-k = -2$（即 $k = 2$）时：水平线切于极小值点，在 $x=1$ 处有 1 个二重实根，在 $(-\infty, -1)$ 侧有 1 个单实根，方程共 2 个实根；

(5) 当 $-k < -2$（即 $k > 2$）时：水平线低于极小值，仅在 $(-\infty, -1)$ 侧有 1 个交点，方程有 1 个实根。

结论获证。

(柯西中值定理构造题)题目[20]:柯西中值定理构造辅助函数证明等式

设 $f(x)$ 在 $[a, b]$ 上连续，在 $(a, b)$ 内可导 $(a>0)$，证明：在 $(a, b)$ 内 $2x[f(b)-f(a)] = (b^2-a^2)f'(x)$ 至少有一个实根。

答案: 证明见步骤

主要思路:[将待证等式变形为比值形式，识别为柯西中值定理 $\frac{f'(\xi)}{g'(\xi)} = \frac{f(b)-f(a)}{g(b)-g(a)}$]

[1] 将待证等式化为比值商结构：

待证等式：

$$2x [f(b) - f(a)] = (b^2 - a^2) f'(x)$$

因为已知 $a > 0$，故在开区间 $(a, b)$ 内 $x > 0$，因此 $2x \ne 0$；且 $b > a > 0 \implies b^2 - a^2 \ne 0$。

两边同除以 $2x (b^2 - a^2)$：

$$\frac{f'(x)}{2x} = \frac{f(b) - f(a)}{b^2 - a^2}$$

[2] 构造双函数并检验柯西中值定理条件：

观察两端结构：

  • 分子是函数 $f(x)$ 在端点的差值，对应导数为 $f'(x)$；
  • 分母是函数 $g(x) = x^2$ 在端点的差值 $g(b) - g(a) = b^2 - a^2$，对应导数为 $g'(x) = 2x$。

设 $F(x) = f(x)$，$G(x) = x^2$。

检验柯西中值定理的三大条件：

(1) $F(x)$ 与 $G(x)$ 在闭区间 $[a, b]$ 上均连续；

(2) $F(x)$ 与 $G(x)$ 在开区间 $(a, b)$ 内均可导；

(3) 对任意 $x \in (a, b)$，因为 $a > 0$，恒有 $G'(x) = 2x \ne 0$。

[3] 应用定理完成证明：

由柯西中值定理，必存在 $\xi \in (a, b)$，使得：

$$\frac{F(b) - F(a)}{G(b) - G(a)} = \frac{F'(\xi)}{G'(\xi)}$$

代入解析式：

$$\frac{f(b) - f(a)}{b^2 - a^2} = \frac{f'(\xi)}{2\xi}$$

两边交叉相乘，即得：

$$2\xi [f(b) - f(a)] = (b^2 - a^2) f'(\xi)$$

即方程在 $(a, b)$ 内至少存在一个实根 $x = \xi$。

[破题钥匙]:证明含单中值 $\xi$ 且带有非一阶项（如 $2\xi$、$3\xi^2$、$e^\xi$）的等式，90% 都是柯西中值定理！只要将中值项与端点项分别移到等号两侧，分母一目了然。

(多项式积分原函数罗尔题)题目[21]:积分原函数构造与罗尔定理应用

设 $a_0+\frac{a_1}{2}+\cdots+\frac{a_n}{n+1}=0\ (a_i\text{ 为实数},\ i=0, 1, 2, \dots, n)$，则在区间 $(0, 1)$ 内，方程 $a_0+a_1x+\cdots+a_nx^n=0\ (\quad)$。

(A) 没有实根
(B) 至少有一个实根
(C) 仅有一个实根
(D) 是否有实根不能判定

答案: (B)

主要思路:[构造以待证多项式为导数的原函数积分式，验证端点函数值相等，应用罗尔定理]

[1] 积分构造辅助原函数：

待证方程为：

$$f(x) = a_0 + a_1 x + a_2 x^2 + \cdots + a_n x^n = 0$$

对其逐项求不定积分，构造辅助函数：

$$F(x) = a_0 x + \frac{a_1}{2}x^2 + \frac{a_2}{3}x^3 + \cdots + \frac{a_n}{n+1}x^{n+1}$$

[2] 检验闭区间连续与端点相等条件：

(1) $F(x)$ 为多项式函数，在闭区间 $[0, 1]$ 上处处连续，在开区间 $(0, 1)$ 内处处可导；

(2) 左端点函数值：

$$F(0) = 0$$

(3) 右端点函数值：

$$F(1) = a_0(1) + \frac{a_1}{2}(1)^2 + \cdots + \frac{a_n}{n+1}(1)^{n+1} = a_0 + \frac{a_1}{2} + \cdots + \frac{a_n}{n+1}$$

由题设已知条件：$F(1) = 0$。

因此，端点值相等：

$$F(0) = F(1) = 0$$

[3] 应用罗尔中值定理：

由罗尔中值定理，在开区间 $(0, 1)$ 内至少存在一点 $\xi \in (0, 1)$，使得：

$$F'(\xi) = 0$$

对 $F(x)$ 求导还原：

$$F'(x) = a_0 + a_1 x + a_2 x^2 + \cdots + a_n x^n$$

故存在 $\xi \in (0, 1)$ 满足：

$$a_0 + a_1 \xi + \cdots + a_n \xi^n = 0$$

即方程在区间 $(0, 1)$ 内至少有一个实根，选 (B)。

[核心反思]:题设中一旦出现分母递增的系数求和式 $\sum \frac{a_k}{k+1} = 0$，100% 对应原函数的定积分 $\int_0^1 f(x)\,\mathrm{d}x = 0$ 或端点值 $F(1)=0$，这是考研无懈可击的第一反射弧！

(双中值区间分割排序大题)题目[22]:双中值严格排序综合证明

设函数 $f(x)$ 在 $[a, b]$ 上可导，$c\in(a, b)$，证明：
[1] 存在一点 $\xi\in(a, c)$，使得 $f(c)-f(a)=f'(\xi)(c-a)$；
[2] 存在一点 $\eta\in(a, b)$，使得 $f(b)-f(a)=f'(\eta)(b-a)$ 且 $\eta>\xi$。

答案: 证明见步骤

主要思路:[第[1]问直接在子区间 $[a, c]$ 应用拉格朗日；第[2]问将全区间差值拆分为两子区间差值和，利用介值性或区间划分构造严格大于 $\xi$ 的中值]

[1] 证明第 [1] 问：

因为 $f(x)$ 在 $[a, b]$ 上可导，故在其子闭区间 $[a, c]$ 上连续，在子开区间 $(a, c)$ 内可导。

由拉格朗日中值定理，必定存在一点 $\xi \in (a, c)$，使得：

$$f(c) - f(a) = f'(\xi)(c - a)$$

第 [1] 问得证。

[2] 证明第 [2] 问：

同理，在子区间 $[c, b]$ 上对 $f(x)$ 应用拉格朗日中值定理，必存在一点 $\xi_2 \in (c, b)$，使得：

$$f(b) - f(c) = f'(\xi_2)(b - c)$$

因为 $\xi \in (a, c)$ 而 $\xi_2 \in (c, b)$，显然有：

$$\xi < c < \xi_2$$

将全区间的增量拆解为两段增量之和：

$$f(b) - f(a) = [f(b) - f(c)] + [f(c) - f(a)] = f'(\xi_2)(b - c) + f'(\xi)(c - a)$$

两边同除以全区间长度 $(b - a)$：

$$\frac{f(b) - f(a)}{b - a} = \frac{c - a}{b - a} f'(\xi) + \frac{b - c}{b - a} f'(\xi_2)$$

令权数 $\lambda = \frac{c - a}{b - a} \in (0, 1)$，则 $1 - \lambda = \frac{b - c}{b - a} \in (0, 1)$。上式表明：

$$\frac{f(b) - f(a)}{b - a} = \lambda f'(\xi) + (1 - \lambda) f'(\xi_2)$$

这说明全区间平均变化率是两个子区间中值导数值 $f'(\xi)$ 与 $f'(\xi_2)$ 的凸线性组合（加权平均值）。

(1) 若 $f'(\xi) = f'(\xi_2)$，则加权平均等于 $f'(\xi_2)$，直接取 $\eta = \xi_2 \in (c, b)$，显然 $\eta = \xi_2 > c > \xi$，命题成立；

(2) 若 $f'(\xi) \ne f'(\xi_2)$，则加权平均值严格介于 $f'(\xi)$ 与 $f'(\xi_2)$ 之间：

$$\min\{f'(\xi), f'(\xi_2)\} < \frac{f(b) - f(a)}{b - a} < \max\{f'(\xi), f'(\xi_2)\}$$

由于导函数满足达布定理（导数介值性：导函数虽然不一定连续，但必然能取到任何两个导数值之间的任何介值），故在 $\xi$ 与 $\xi_2$ 之间必定存在一点 $\eta$（即 $\eta \in (\xi, \xi_2)$），使得：

$$f'(\eta) = \frac{f(b) - f(a)}{b - a} \iff f(b) - f(a) = f'(\eta)(b - a)$$

因为 $\eta \in (\xi, \xi_2)$，显然有：

$$\eta > \xi$$

且 $\eta < \xi_2 < b$，$\eta > \xi > a$，故 $\eta \in (a, b)$。

第 [2] 问获证。

[压轴思维]:本题展现了考研中值定理的最高境界——区间拆解加权平均法 + 达布定理！无论导函数是否连续，通过构造两段独立中值并由介值性锁定 $\eta \in (\xi, \xi_2)$，逻辑无懈可击！
