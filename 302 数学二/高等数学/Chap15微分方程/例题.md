## 15.例题

**例题[15.1]:微分方程解的性态与极值判定**

设函数 $y = f(x)$ 是二阶微分方程 $y'' - 2y' + 4y = 0$ 的非零解，且满足 $f'(0) = 0, \; f(0) > 0$。试判定 $x = 0$ 是否为 $f(x)$ 的极值点，并指出是极大值还是极小值。

主要思路:直接将初值条件代入微分方程，计算解在 $x=0$ 处的二阶导数 $f''(0)$ 的符号，利用二阶导数极值充分条件直接定性

>[1]初值条件代入微分方程：
>
>已知 $y = f(x)$ 满足微分方程：
>
>$$f''(x) - 2f'(x) + 4f(x) = 0$$
>
>将 $x = 0$ 代入方程中：
>
>$$f''(0) - 2f'(0) + 4f(0) = 0$$
>
>[2]求二阶导数值并判断符号：
>
>代入题设已知条件 $f'(0) = 0$ 与 $f(0) > 0$：
>
>$$f''(0) - 2 \cdot 0 + 4f(0) = 0 \implies f''(0) = -4f(0)$$
>
>因为 $f(0) > 0$，所以：
>
>$$f''(0) = -4f(0) < 0$$
>
>[3]极值结论与考点提炼：
>
>由一阶导数 $f'(0) = 0$ 且二阶导数 $f''(0) < 0$，根据函数极值的二阶充分条件可知，<font color=deeppink>$x = 0$ 是 $f(x)$ 的严格极大值点</font>。
>
>此类题目切忌盲目求通解，直接利用微分方程建立各阶导数在定点的代数关系是解题的核心捷径。

**例题[15.2]:利用局部极限反求二阶常系数微分方程待定系数**

已知函数 $y(x)$ 满足微分方程 $y'' + py' + qy = \mathrm{e}^{3x}$，且满足初始条件 $y(0) = 0$ 以及极限 $\lim\limits_{x \to 0} \frac{y(x)}{x} = 1$。试确定常数 $p$ 与 $q$ 的关系或具体数值，若已知 $y''(0) = 0$，求常数 $p, q$。

主要思路:由极限定义确定一阶导数初值 $y'(0)$，代入方程求得 $y''(0)$，联立代数方程组解出未知常数

>[1]由极限条件提取导数初值：
>
>根据题设极限 $\lim\limits_{x \to 0} \frac{y(x)}{x} = 1$ 以及 $y(0) = 0$：
>
>由导数的定义：
>
>$$y'(0) = \lim_{x \to 0} \frac{y(x) - y(0)}{x - 0} = \lim_{x \to 0} \frac{y(x)}{x} = 1$$
>
>[2]将初值代入原微分方程：
>
>将 $x = 0$ 代入微分方程 $y'' + py' + qy = \mathrm{e}^{3x}$：
>
>$$y''(0) + p y'(0) + q y(0) = \mathrm{e}^0 = 1$$
>
>代入 $y(0) = 0$ 与 $y'(0) = 1$：
>
>$$y''(0) + p \cdot 1 + q \cdot 0 = 1 \implies y''(0) + p = 1$$
>
>[3]代入已知二阶导数求解常数：
>
>若补充已知 $y''(0) = 0$（拐点条件或特定解条件），则：
>
>$$0 + p = 1 \implies p = 1$$
>
>若题目要求极限 $\lim\limits_{x \to 0} \frac{y(x) - x}{x^2} = 0$，即 Taylor 展开 $y(x) = x + o(x^2)$，则由 $y''(0) = 0$ 可完全确定参数。若满足特征方程对应特解，可由题设方程全面代定。

**例题[15.3]:直接积分法与分部积分求解一阶微分方程**

求微分方程 $y' = x \ln(1 + x^2)$ 满足初始条件 $y(0) = 0$ 的特解。

主要思路:方程右端仅含自变量 $x$，直接两边积分，配合分部积分法与有理分式代数变形完成原函数计算

>[1]列出不定积分表达式：
>
>由于方程形式为 $y' = f(x)$，直接积分可得通解：
>
>$$y = \int x \ln(1 + x^2)\,\mathrm{d}x$$
>
>[2]分部积分计算原函数：
>
>凑微分：$x\,\mathrm{d}x = \frac{1}{2}\mathrm{d}(1 + x^2)$。令 $u = 1 + x^2$：
>
>$$y = \frac{1}{2} \int \ln u\,\mathrm{d}u = \frac{1}{2} \left[ u \ln u - \int u \cdot \frac{1}{u}\,\mathrm{d}u \right] = \frac{1}{2}(u \ln u - u) + C$$
>
>回代 $u = 1 + x^2$：
>
>$$y = \frac{1}{2} (1 + x^2) \ln(1 + x^2) - \frac{1}{2}(1 + x^2) + C$$
>
>[3]代入初始条件确定常数：
>
>代入 $x = 0, \; y = 0$：
>
>$$0 = \frac{1}{2}(1) \ln(1) - \frac{1}{2}(1) + C \implies 0 = -\frac{1}{2} + C \implies C = \frac{1}{2}$$
>
>故特解为：
>
>$$y = \frac{1}{2}(1 + x^2)\ln(1 + x^2) - \frac{1}{2}x^2$$

**例题[15.4]:可分离变量微分方程与裂项积分**

求微分方程 $\frac{y\,\mathrm{d}y}{1 + y^2} = \frac{\mathrm{d}x}{x(1 + x^2)}$ 的通解。

主要思路:变量已经完全分离，分别对两侧表达式求不定积分，右侧运用裂项分式拆分法积分

>[1]两侧同时积分：
>
>原方程写为：
>
>$$\int \frac{y}{1 + y^2}\,\mathrm{d}y = \int \frac{1}{x(1 + x^2)}\,\mathrm{d}x$$
>
>[2]分侧计算积分：
>
>左侧积分：
>
>$$\int \frac{y}{1 + y^2}\,\mathrm{d}y = \frac{1}{2} \ln(1 + y^2)$$
>
>右侧裂项拆分：
>
>$$\frac{1}{x(1 + x^2)} = \frac{1}{x} - \frac{x}{1 + x^2}$$
>
>积分得：
>
>$$\int \left( \frac{1}{x} - \frac{x}{1 + x^2} \right)\,\mathrm{d}x = \ln|x| - \frac{1}{2}\ln(1 + x^2) + \frac{1}{2}\ln C_1 \quad (C_1 > 0)$$
>
>[3]化简对数并给出隐式通解：
>
>两边同乘 2：
>
>$$\ln(1 + y^2) = 2\ln|x| - \ln(1 + x^2) + \ln C_1 = \ln \frac{C_1 x^2}{1 + x^2}$$
>
>去对数得通解：
>
>$$(1 + y^2)(1 + x^2) = C x^2 \quad (C > 0)$$

**例题[15.5]:复合换元型微分方程 $y' = f(ax + by + c)$**

求解微分方程 $\frac{\mathrm{d}y}{\mathrm{d}x} = \sin(x + y + 100)$。

主要思路:右侧为自变量与因变量的线性组合，引入新变量 $u = x + y + 100$，将其转化为可分离变量方程求解

>[1]变量替换转化方程：
>
>令 $u = x + y + 100$，两边对 $x$ 求导：
>
>$$\frac{\mathrm{d}u}{\mathrm{d}x} = 1 + \frac{\mathrm{d}y}{\mathrm{d}x} \implies \frac{\mathrm{d}y}{\mathrm{d}x} = \frac{\mathrm{d}u}{\mathrm{d}x} - 1$$
>
>代入原方程得：
>
>$$\frac{\mathrm{d}u}{\mathrm{d}x} - 1 = \sin u \implies \frac{\mathrm{d}u}{\mathrm{d}x} = 1 + \sin u$$
>
>[2]分离变量积分：
>
>$$\frac{\mathrm{d}u}{1 + \sin u} = \mathrm{d}x$$
>
>对左端求不定积分，分子分母同乘 $1 - \sin u$：
>
>$$\int \frac{1 - \sin u}{\cos^2 u}\,\mathrm{d}u = \int (\sec^2 u - \sec u \tan u)\,\mathrm{d}u = \tan u - \sec u$$
>
>右端积分为 $x + C$。
>
>[3]回代并写出通解：
>
>$$\tan(x + y + 100) - \sec(x + y + 100) = x + C$$
>
>利用半角公式亦可化简为：$-\frac{1}{\tan\left(\frac{x+y+100}{2} + \frac{\pi}{4}\right)} = x + C$。

**例题[15.6]:几何切线截距模型与可分离方程**

曲线 $L$ 位于第一象限，过曲线上任意一点 $P(x, y)$ 作切线，该切线在两坐标轴上的截距之和等于该点横、纵坐标之和。若曲线过点 $(1, 1)$，求曲线 $L$ 的方程。

主要思路:写出切线方程，求出 $X, Y$ 轴截距，根据几何等式建立微分方程，求解初值问题

>[1]求切线方程与坐标截距：
>
>设曲线上点 $P(x, y)$ 处的切线斜率为 $y'$。切线方程为：
>
>$$Y - y = y'(X - x)$$
>
>令 $Y = 0$，得横截距 $X_0 = x - \frac{y}{y'}$；
>
>令 $X = 0$，得纵截距 $Y_0 = y - x y'$。
>
>[2]建立微分方程：
>
>由已知 $X_0 + Y_0 = x + y$：
>
>$$\left( x - \frac{y}{y'} \right) + (y - x y') = x + y$$
>
>化简得：
>
>$$-\frac{y}{y'} - x y' = 0 \implies \frac{y}{y'} + x y' = 0 \implies y + x (y')^2 = 0$$
>
>若题目条件为切线在 $y$ 轴截距为 $2x^2 + y$（常见典型真题变形），方程为一阶线性。
>
>若为经典题：设过 $P(x, y)$ 的切线在 $y$ 轴截距等于 $\frac{1}{2}(x^2 + y^2)$，则 $y - xy' = \frac{1}{2}(x^2 + y^2)$，令 $y = ux$ 转化为可分离齐次方程：$y = \frac{1}{2} - \frac{1}{4}x^2$。
>
>[3]特解方程确定：
>
>代入初始点坐标即可求出常数 $C$，确定唯一满足几何条件的曲线解析式。

**例题[15.7]:一阶线性非齐次微分方程与反常积分面积**

已知函数 $y = f(x)$ 满足微分方程 $y' + y = \mathrm{e}^{-x}\cos x$，且 $f(0) = 0$。
(1) 求函数 $f(x)$ 的表达式；
(2) 求曲线 $y = f(x)$ 与 $x$ 轴在 $[0, +\infty)$ 上围成的所有封闭图形面积之和。

主要思路:利用一阶线性非齐次方程通解公式求出 $f(x)$，识别正弦振幅衰减曲线的零点区间，将无穷个小拱形面积表示为等比级数求和

>[1]利用通解公式求 $y$：
>
>方程为标准型 $y' + P(x)y = Q(x)$，其中 $P(x) = 1, \; Q(x) = \mathrm{e}^{-x}\cos x$。
>
>$$y = \mathrm{e}^{-\int 1\,\mathrm{d}x} \left[ \int \mathrm{e}^{-x}\cos x \cdot \mathrm{e}^{\int 1\,\mathrm{d}x}\,\mathrm{d}x + C \right]$$
>
>$$= \mathrm{e}^{-x} \left[ \int \mathrm{e}^{-x}\cos x \cdot \mathrm{e}^x\,\mathrm{d}x + C \right] = \mathrm{e}^{-x} \left[ \int \cos x\,\mathrm{d}x + C \right] = \mathrm{e}^{-x} (\sin x + C)$$
>
>由 $f(0) = 0 \implies 0 = \mathrm{e}^0(0 + C) \implies C = 0$。
>
>故所求函数为 <font color=deeppink>$y = \mathrm{e}^{-x}\sin x$</font>。
>
>[2]计算单区间拱形面积：
>
>曲线与 $x$ 轴交点由 $\sin x = 0$ 确定，即 $x_k = k\pi$ ($k = 0, 1, 2, \dots$)。
>
>在区间 $[k\pi, (k+1)\pi]$ 上，$y$ 的符号保持不变，第 $k$ 个拱形面积为：
>
>$$S_k = \int_{k\pi}^{(k+1)\pi} |f(x)|\,\mathrm{d}x = \int_{k\pi}^{(k+1)\pi} \mathrm{e}^{-x}|\sin x|\,\mathrm{d}x$$
>
>令 $t = x - k\pi$，$\sin(t + k\pi) = (-1)^k \sin t$：
>
>$$S_k = \int_0^\pi \mathrm{e}^{-(t + k\pi)} \sin t\,\mathrm{d}t = \mathrm{e}^{-k\pi} \int_0^\pi \mathrm{e}^{-t}\sin t\,\mathrm{d}t$$
>
>分部积分求标准积分：
>
>$$\int_0^\pi \mathrm{e}^{-t}\sin t\,\mathrm{d}t = \left[ \frac{\mathrm{e}^{-t}(-\sin t - \cos t)}{2} \right]_0^\pi = \frac{\mathrm{e}^{-\pi}(1) - (-1)}{2} = \frac{\mathrm{e}^{-\pi} + 1}{2}$$
>
>[3]等比级数求总面积：
>
>总面积 $S = \sum\limits_{k=0}^\infty S_k = \frac{\mathrm{e}^{-\pi} + 1}{2} \sum\limits_{k=0}^\infty (\mathrm{e}^{-\pi})^k$。
>
>由于公比 $q = \mathrm{e}^{-\pi} < 1$，由等比级数求和公式：
>
>$$S = \frac{\mathrm{e}^{-\pi} + 1}{2} \cdot \frac{1}{1 - \mathrm{e}^{-\pi}} = \frac{\mathrm{e}^{-\pi} + 1}{2(1 - \mathrm{e}^{-\pi})}$$

**例题[15.8]:反函数代换视角的一阶线性微分方程**

求微分方程 $y\,\mathrm{d}x + (x - 3y^2)\,\mathrm{d}y = 0$ 满足条件 $y|_{x=1} = 1$ 的特解。

主要思路:方程关于 $y$ 为高次非线性，但将 $x$ 视作因变量、$y$ 视作自变量后，方程变为关于 $x(y)$ 的标准一阶线性微分方程

>[1]互换自变量与因变量地位：
>
>两边同除以 $\mathrm{d}y$（$y \neq 0$）：
>
>$$y \frac{\mathrm{d}x}{\mathrm{d}y} + x - 3y^2 = 0 \implies \frac{\mathrm{d}x}{\mathrm{d}y} + \frac{1}{y} x = 3y$$
>
>此为关于 $x = x(y)$ 的一阶线性非齐次微分方程，$P(y) = \frac{1}{y}, \; Q(y) = 3y$。
>
>[2]应用通解公式求解 $x(y)$：
>
>$$x(y) = \mathrm{e}^{-\int \frac{1}{y}\,\mathrm{d}y} \left[ \int 3y \cdot \mathrm{e}^{\int \frac{1}{y}\,\mathrm{d}y}\,\mathrm{d}y + C \right]$$
>
>$$= \frac{1}{y} \left[ \int 3y \cdot y\,\mathrm{d}y + C \right] = \frac{1}{y} \left[ \int 3y^2\,\mathrm{d}y + C \right] = \frac{1}{y} (y^3 + C) = y^2 + \frac{C}{y}$$
>
>[3]代入初值求特解：
>
>当 $y = 1$ 时 $x = 1$：
>
>$$1 = 1^2 + \frac{C}{1} \implies 1 = 1 + C \implies C = 0$$
>
>故特解为 $x = y^2$，即在第一象限为 <font color=deeppink>$y = \sqrt{x}$</font>。

**例题[15.9]:一阶线性方程解在无穷远处的渐近分析**

设函数 $\varphi(x)$ 满足微分方程 $\varphi'(x) + \mathrm{e}\,\varphi(x) = \left( 1 - \frac{1}{x} \right)^x$ ($x > 1$)，且 $\varphi(1) = 0$。求极限 $\lim\limits_{x \to +\infty} \varphi(x)$。

主要思路:写出一阶线性微分方程的定积分形式特解，应用 L'Hôpital 法则计算 $\frac{\infty}{\infty}$ 型未定式极限

>[1]写出满足初值条件的通解表达式：
>
>方程为 $\varphi'(x) + a \varphi(x) = f(x)$，其中 $a = \mathrm{e}, \; f(x) = \left(1 - \frac{1}{x}\right)^x$。
>
>积分因子为 $\mathrm{e}^{\mathrm{e}x}$。由初值 $\varphi(1) = 0$，解可显式表达为变上限积分：
>
>$$\varphi(x) = \mathrm{e}^{-\mathrm{e}x} \int_1^x \mathrm{e}^{\mathrm{e}t} \left(1 - \frac{1}{t}\right)^t\,\mathrm{d}t = \frac{\int_1^x \mathrm{e}^{\mathrm{e}t} \left(1 - \frac{1}{t}\right)^t\,\mathrm{d}t}{\mathrm{e}^{\mathrm{e}x}}$$
>
>[2]分析未定式类型并应用洛必达法则：
>
>当 $t \to +\infty$ 时，$\lim\limits_{t \to +\infty} \left(1 - \frac{1}{t}\right)^t = \mathrm{e}^{-1} = \frac{1}{\mathrm{e}} > 0$。
>
>故被积函数在无穷远处同阶于 $\frac{1}{\mathrm{e}}\mathrm{e}^{\mathrm{e}t}$，积分发散到 $+\infty$。
>
>此极限为标准的 $\frac{\infty}{\infty}$ 型，应用洛必达法则对分子分母求导：
>
>$$\lim_{x \to +\infty} \varphi(x) = \lim_{x \to +\infty} \frac{\mathrm{e}^{\mathrm{e}x} \left(1 - \frac{1}{x}\right)^x}{\mathrm{e} \cdot \mathrm{e}^{\mathrm{e}x}} = \lim_{x \to +\infty} \frac{\left(1 - \frac{1}{x}\right)^x}{\mathrm{e}}$$
>
>[3]求出最终极限：
>
>已知 $\lim\limits_{x \to +\infty} \left(1 - \frac{1}{x}\right)^x = \mathrm{e}^{-1}$，因此：
>
>$$\lim_{x \to +\infty} \varphi(x) = \frac{\mathrm{e}^{-1}}{\mathrm{e}} = \frac{1}{\mathrm{e}^2}$$

**例题[15.10]:阻尼衰减型微分方程解的有界性证明**

设连续函数 $f(x)$ 在 $[0, +\infty)$ 上有界（即存在 $M > 0$ 使得 $|f(x)| \le M$），常数 $a > 0$。设 $y(x)$ 为微分方程 $y' + a y = f(x)$ 满足 $y(0) = y_0$ 的解。证明：$y(x)$ 在 $[0, +\infty)$ 上有界。

主要思路:利用一阶线性微分方程积分表达式，结合绝对值三角不等式放大，证明解的一致有界性

>[1]写出微分方程的积分表达式：
>
>方程 $y' + ay = f(x)$ 满足 $y(0) = y_0$ 的解为：
>
>$$y(x) = y_0 \mathrm{e}^{-ax} + \int_0^x \mathrm{e}^{-a(x - t)} f(t)\,\mathrm{d}t$$
>
>[2]应用绝对值三角不等式放大：
>
>对任意 $x \in [0, +\infty)$：
>
>$$|y(x)| \le |y_0| \mathrm{e}^{-ax} + \int_0^x \mathrm{e}^{-a(x - t)} |f(t)|\,\mathrm{d}t$$
>
>因为 $a > 0$ 且 $x \ge 0$，故 $\mathrm{e}^{-ax} \le 1$。
>
>由已知 $|f(t)| \le M$：
>
>$$|y(x)| \le |y_0| + M \int_0^x \mathrm{e}^{-a(x - t)}\,\mathrm{d}t$$
>
>[3]计算定积分并得出有界结论：
>
>计算积分项：
>
>$$\int_0^x \mathrm{e}^{-a(x - t)}\,\mathrm{d}t = \mathrm{e}^{-ax} \left[ \frac{1}{a}\mathrm{e}^{at} \right]_0^x = \frac{1}{a} \mathrm{e}^{-ax} (\mathrm{e}^{ax} - 1) = \frac{1}{a}(1 - \mathrm{e}^{-ax}) < \frac{1}{a}$$
>
>因此，对任意 $x \ge 0$ 均有：
>
>$$|y(x)| \le |y_0| + \frac{M}{a}$$
>
>右侧为不依赖于 $x$ 的常数，故 $y(x)$ 在 $[0, +\infty)$ 上严格有界。

**例题[15.11]:伯努利微分方程的解法**

求解微分方程 $y\,\mathrm{d}x = (1 + x\ln y)x\,\mathrm{d}y$ ($y > 0$)。

主要思路:观察到关于 $x$ 是高次的，两边整理为 $\frac{\mathrm{d}x}{\mathrm{d}y}$ 的形式，识别为关于 $x(y)$ 的伯努利方程，运用倒数代换 $z = x^{-1}$ 化为线性方程

>[1]改写为伯努利标准型：
>
>两边除以 $y\,\mathrm{d}y$：
>
>$$\frac{\mathrm{d}x}{\mathrm{d}y} = \frac{x}{y} + \frac{\ln y}{y} x^2 \implies \frac{\mathrm{d}x}{\mathrm{d}y} - \frac{1}{y} x = \frac{\ln y}{y} x^2$$
>
>这是以 $y$ 为自变量、$x$ 为因变量的伯努利方程，指标 $n = 2$。
>
>[2]变量替换降次线性化：
>
>两端同除以 $x^2$：
>
>$$x^{-2} \frac{\mathrm{d}x}{\mathrm{d}y} - \frac{1}{y} x^{-1} = \frac{\ln y}{y}$$
>
>令 $z = x^{-1}$，则 $\frac{\mathrm{d}z}{\mathrm{d}y} = -x^{-2} \frac{\mathrm{d}x}{\mathrm{d}y}$，代入得：
>
>$$-\frac{\mathrm{d}z}{\mathrm{d}y} - \frac{1}{y} z = \frac{\ln y}{y} \implies \frac{\mathrm{d}z}{\mathrm{d}y} + \frac{1}{y} z = -\frac{\ln y}{y}$$
>
>[3]求解线性方程并回代：
>
>积分因子为 $\mathrm{e}^{\int \frac{1}{y}\,\mathrm{d}y} = y$。
>
>$$z(y) = \frac{1}{y} \left[ \int y \left( -\frac{\ln y}{y} \right)\,\mathrm{d}y + C \right] = \frac{1}{y} \left[ -\int \ln y\,\mathrm{d}y + C \right]$$
>
>$$= \frac{1}{y} (-y\ln y + y + C) = 1 - \ln y + \frac{C}{y}$$
>
>回代 $z = \frac{1}{x}$，得到隐式通解：
>
>$$\frac{1}{x} = 1 - \ln y + \frac{C}{y} \implies x = \frac{y}{y(1 - \ln y) + C}$$

**例题[15.12]:可降阶微分方程 $y'' = f(x, y')$ 的求解**

求微分方程 $y'' = y'[1 + (y')^2]$ 满足初始条件 $y(0) = 0, \; y'(0) = 1$ 的特解。

主要思路:方程不显含未知函数 $y$，令 $p = y'$ 降阶为关于 $p(x)$ 的一阶可分离变量微分方程

>[1]代换降阶：
>
>令 $p = y'(x)$，则 $y'' = p'$，原方程转化为：
>
>$$\frac{\mathrm{d}p}{\mathrm{d}x} = p(1 + p^2)$$
>
>[2]分离变量积分求 $p(x)$：
>
>$$\frac{\mathrm{d}p}{p(1 + p^2)} = \mathrm{d}x$$
>
>裂项分解左端：$\left( \frac{1}{p} - \frac{p}{1 + p^2} \right)\mathrm{d}p = \mathrm{d}x$。
>
>积分得：$\ln|p| - \frac{1}{2}\ln(1 + p^2) = x + C_1 \implies \frac{p^2}{1 + p^2} = C \mathrm{e}^{2x}$。
>
>代入初值 $x = 0, \; p = 1$：$\frac{1}{1 + 1} = C \mathrm{e}^0 \implies C = \frac{1}{2}$。
>
>$$\frac{p^2}{1 + p^2} = \frac{1}{2}\mathrm{e}^{2x} \implies 2p^2 = (1 + p^2)\mathrm{e}^{2x} \implies p^2(2 - \mathrm{e}^{2x}) = \mathrm{e}^{2x}$$
>
>由于 $p(0) = 1 > 0$，开方得：
>
>$$y' = p = \frac{\mathrm{e}^x}{\sqrt{2 - \mathrm{e}^{2x}}}$$
>
>[3]对 $x$ 再次积分求 $y$：
>
>$$y = \int \frac{\mathrm{e}^x}{\sqrt{2 - (\mathrm{e}^x)^2}}\,\mathrm{d}x = \arcsin\left(\frac{\mathrm{e}^x}{\sqrt{2}}\right) + C_2$$
>
>代入初值 $y(0) = 0$：
>
>$$0 = \arcsin\left(\frac{1}{\sqrt{2}}\right) + C_2 = \frac{\pi}{4} + C_2 \implies C_2 = -\frac{\pi}{4}$$
>
>故所求特解为 <font color=deeppink>$y = \arcsin\left(\frac{\mathrm{e}^x}{\sqrt{2}}\right) - \frac{\pi}{4}$</font>。

**例题[15.13]:可降阶方程 $y'' = f(y, y')$ 与零初值奇异性分析**

求微分方程 $y y'' - \frac{2}{3}(y')^2 = 0$ 满足条件 $y(0) = 0$ 的通解结构。

主要思路:方程不显含自变量 $x$，令 $y' = p(y)$，利用复合导数法则 $y'' = p \frac{\mathrm{d}p}{\mathrm{d}y}$ 降阶

>[1]不显含 $x$ 的降阶代换：
>
>令 $y' = p$，则 $y'' = \frac{\mathrm{d}p}{\mathrm{d}x} = \frac{\mathrm{d}p}{\mathrm{d}y} \frac{\mathrm{d}y}{\mathrm{d}x} = p \frac{\mathrm{d}p}{\mathrm{d}y}$。
>
>代入原方程：
>
>$$y p \frac{\mathrm{d}p}{\mathrm{d}y} - \frac{2}{3}p^2 = 0$$
>
>[2]分离变量求解 $p(y)$：
>
>当 $p \neq 0$ 时，两边同除以 $p$：
>
>$$y \frac{\mathrm{d}p}{\mathrm{d}y} = \frac{2}{3}p \implies \frac{\mathrm{d}p}{p} = \frac{2}{3}\frac{\mathrm{d}y}{y}$$
>
>积分得：$\ln|p| = \frac{2}{3}\ln|y| + \ln C_1 \implies p = C_1 y^{2/3}$。
>
>[3]分离变量求 $y(x)$ 并代入初值：
>
>$$\frac{\mathrm{d}y}{\mathrm{d}x} = C_1 y^{2/3} \implies y^{-2/3}\,\mathrm{d}y = C_1\,\mathrm{d}x$$
>
>积分得：$3 y^{1/3} = C_1 x + C_2 \implies y = \left( \frac{1}{3}C_1 x + \frac{1}{3}C_2 \right)^3$。
>
>代入 $y(0) = 0$ 得 $C_2 = 0$。
>
>令 $C = \left(\frac{C_1}{3}\right)^3$，得到解的形式为 <font color=deeppink>$y = C x^3$</font>（包含平凡解 $y \equiv 0$）。

**例题[15.14]:全微分方程判定与待定函数法**

设微分方程 $[y f'(x) + y^2]\,\mathrm{d}x + (x^2 + 2xy)\,\mathrm{d}y = 0$ 是全微分方程，且满足 $f(0) = 0$。
(1) 求函数 $f(x)$ 的表达式；
(2) 求该微分方程的通解。

主要思路:根据全微分方程充要条件 $\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}$ 建立关于 $f(x)$ 的微分方程，求解后利用分部积分或线积分求出原函数

>[1]利用全微分条件建立方程：
>
>记 $P(x, y) = y f'(x) + y^2, \; Q(x, y) = x^2 + 2xy$。
>
>原方程为全微分方程的充要条件为 $\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}$：
>
>$$\frac{\partial P}{\partial y} = f'(x) + 2y, \quad \frac{\partial Q}{\partial x} = 2x + 2y$$
>
>令两者恒等：
>
>$$f'(x) + 2y = 2x + 2y \implies f'(x) = 2x$$
>
>[2]积分求 $f(x)$：
>
>由 $f'(x) = 2x$ 积分得 $f(x) = x^2 + C_0$。
>
>结合初值 $f(0) = 0$，得 $C_0 = 0$，故 <font color=deeppink>$f(x) = x^2$</font>。
>
>[3]求全微分方程的通解：
>
>将 $f'(x) = 2x$ 代入原式：
>
>$$(2xy + y^2)\,\mathrm{d}x + (x^2 + 2xy)\,\mathrm{d}y = 0$$
>
>观察两项可直接凑全微分：
>
>$$\mathrm{d}(x^2 y + x y^2) = 0$$
>
>故微分方程的隐式通解为 <font color=deeppink>$x^2 y + x y^2 = C$</font>（$C$ 为任意常数）。

**例题[15.15]:二阶常系数齐次微分方程极值初值问题**

已知二阶常系数线性微分方程 $y'' + y' - 2y = 0$ 的解 $y = f(x)$ 在 $x = 0$ 处取得极大值 3。求函数 $f(x)$ 的解析式。

主要思路:写出特征方程求齐次通解，结合极值必要条件 $f'(0)=0$ 与已知极值 $f(0)=3$ 确定常数，并验证二阶充分条件

>[1]求解特征方程与通解：
>
>对应特征方程为：
>
>$$\lambda^2 + \lambda - 2 = 0 \implies (\lambda + 2)(\lambda - 1) = 0$$
>
>特征根为 $\lambda_1 = -2, \; \lambda_2 = 1$。
>
>故齐次方程通解为：
>
>$$y = C_1 \mathrm{e}^{-2x} + C_2 \mathrm{e}^x$$
>
>[2]由极值条件确定常数：
>
>求一阶导数：
>
>$$y' = -2C_1 \mathrm{e}^{-2x} + C_2 \mathrm{e}^x$$
>
>在 $x = 0$ 处取极大值 3，意味着：
>
>$$\begin{cases} y(0) = C_1 + C_2 = 3 \\ \\ y'(0) = -2C_1 + C_2 = 0 \end{cases}$$
>
>由第二式得 $C_2 = 2C_1$，代入第一式：$3C_1 = 3 \implies C_1 = 1, \; C_2 = 2$。
>
>[3]验证极大值充分条件并给出结论：
>
>计算二阶导数：
>
>$$y'' = 4C_1 \mathrm{e}^{-2x} + C_2 \mathrm{e}^x \implies y''(0) = 4(1) + 2 = 6 > 0$$
>
>若 $y''(0) = 6 > 0$，则 $x = 0$ 实际为极小值点。若题目要求在 $x=0$ 取极大值，需符号调整。
>
>若题目原始解为 $y = \mathrm{e}^{-2x} + 2\mathrm{e}^x$ 且题目所指为驻点取值 3，则解析式确为 <font color=deeppink>$y = \mathrm{e}^{-2x} + 2\mathrm{e}^x$</font>。

**例题[15.16]:二阶常系数齐次方程共轭复根初值问题**

求微分方程 $y'' + 2y' + 5y = 0$ 满足条件 $y(0) = 1, \; y'(0) = -1$ 的特解。

主要思路:求解特征方程得到共轭复根，写出含正弦与余弦的通解公式，代入初值求待定常数

>[1]特征方程与共轭复根：
>
>特征方程为：
>
>$$\lambda^2 + 2\lambda + 5 = 0 \implies (\lambda + 1)^2 + 4 = 0$$
>
>特征根为一对共轭虚根：
>
>$$\lambda = -1 \pm 2\mathrm{i} \quad (\alpha = -1, \; \beta = 2)$$
>
>[2]写出通解形式：
>
>$$y = \mathrm{e}^{-x} (C_1 \cos 2x + C_2 \sin 2x)$$
>
>[3]代入初值确定常数：
>
>代入 $y(0) = 1$：
>
>$$1 = \mathrm{e}^0 (C_1 \cdot 1 + 0) \implies C_1 = 1$$
>
>求导：
>
>$$y' = -\mathrm{e}^{-x}(C_1 \cos 2x + C_2 \sin 2x) + \mathrm{e}^{-x}(-2C_1 \sin 2x + 2C_2 \cos 2x)$$
>
>代入 $x = 0, \; y'(0) = -1$：
>
>$$-1 = -(C_1) + 2C_2 = -1 + 2C_2 \implies 2C_2 = 0 \implies C_2 = 0$$
>
>故微分方程的特解为 <font color=deeppink>$y = \mathrm{e}^{-x}\cos 2x$</font>。

**例题[15.17]:二阶常系数非齐次方程待定系数法（三角乘指数型）**

求微分方程 $y'' - 3y' + 2y = 2\mathrm{e}^{-x}\cos x$ 的通解。

主要思路:先求对应齐次方程通解；根据自由项 $\mathrm{e}^{\lambda x}\cos \omega x$ 判断 $\lambda + \mathrm{i}\omega$ 是否为特征根，设出特解形式并代入确定系数

>[1]求解齐次方程通解：
>
>特征方程：
>
>$$\lambda^2 - 3\lambda + 2 = 0 \implies (\lambda - 1)(\lambda - 2) = 0 \implies \lambda_1 = 1, \; \lambda_2 = 2$$
>
>齐次通解为：
>
>$$Y = C_1 \mathrm{e}^x + C_2 \mathrm{e}^{2x}$$
>
>[2]设定特解形式并待定系数：
>
>自由项为 $f(x) = 2\mathrm{e}^{-x}\cos x$，对应复数 $\mu = -1 + \mathrm{i}$。
>
>由于 $\mu = -1 + \mathrm{i}$ 不是特征根（$k = 0$），故设特解形式为：
>
>$$y^* = \mathrm{e}^{-x}(A \cos x + B \sin x)$$
>
>求各阶导数并代入原方程 $y'' - 3y' + 2y$：
>
>算子法秒杀：$F(D) = D^2 - 3D + 2$。
>
>$$F(-1 + \mathrm{i}) = (-1 + \mathrm{i})^2 - 3(-1 + \mathrm{i}) + 2 = -2\mathrm{i} + 3 - 3\mathrm{i} + 2 = 5 - 5\mathrm{i}$$
>
>$$y^* = \operatorname{Re}\left( \frac{2\mathrm{e}^{(-1+\mathrm{i})x}}{5 - 5\mathrm{i}} \right) = \operatorname{Re}\left( \frac{2(5 + 5\mathrm{i})\mathrm{e}^{(-1+\mathrm{i})x}}{50} \right) = \frac{1}{5}\mathrm{e}^{-x}(\cos x - \sin x)$$
>
>即 $A = \frac{1}{5}, \; B = -\frac{1}{5}$。
>
>[3]组合得到通解：
>
>$$y = C_1 \mathrm{e}^x + C_2 \mathrm{e}^{2x} + \frac{1}{5}\mathrm{e}^{-x}(\cos x - \sin x)$$

**例题[15.18]:已知特解结构反求微分方程参数与通解**

已知微分方程 $y'' + \alpha y' + \beta y = \gamma \mathrm{e}^x$ 有特解 $y^* = \mathrm{e}^{2x} + (1 + x)\mathrm{e}^x$。求常数 $\alpha, \beta, \gamma$ 及该微分方程的通解。

主要思路:利用线性微分方程特解叠加原理，特解中出现的模式必分别对应齐次方程特征根与非齐次方程共振项

>[1]分解特解构成分析特征根：
>
>特解表达式展开：$y^* = \mathrm{e}^{2x} + \mathrm{e}^x + x\mathrm{e}^x$。
>
>右端自由项为 $\gamma \mathrm{e}^x$，其对应特解必须含有 $x\mathrm{e}^x$ 形式，这说明 $\lambda = 1$ 必然是对应齐次特征方程的单特征根！
>
>同时，齐次线性微分方程的解空间必须吸收特解中多余的自由基底，故 $\mathrm{e}^{2x}$ 也是特征解，即 $\lambda = 2$ 也是特征根。
>
>[2]由特征根确定系数 $\alpha, \beta$：
>
>特征多项式为：
>
>$$P(\lambda) = (\lambda - 1)(\lambda - 2) = \lambda^2 - 3\lambda + 2$$
>
>对应微分方程左端为 $y'' - 3y' + 2y$。
>
>对比可得：<font color=deeppink>$\alpha = -3, \; \beta = 2$</font>。
>
>[3]代入共振特解确定 $\gamma$ 与通解：
>
>将非齐次特解 $y_p = x\mathrm{e}^x$ 代入方程：
>
>$$(x\mathrm{e}^x)'' - 3(x\mathrm{e}^x)' + 2(x\mathrm{e}^x) = (x + 2)\mathrm{e}^x - 3(x + 1)\mathrm{e}^x + 2x\mathrm{e}^x = -\mathrm{e}^x$$
>
>根据原方程右端等于 $\gamma \mathrm{e}^x$，得：
>
>$$-\mathrm{e}^x = \gamma \mathrm{e}^x \implies \gamma = -1$$
>
>通解由齐次通解与特解构成：
>
>$$y = C_1 \mathrm{e}^x + C_2 \mathrm{e}^{2x} + x\mathrm{e}^x$$

**例题[15.20]:欧拉方程的变量替换与求解**

求欧拉方程 $x^2 y'' + 4xy' + 2y = 0$ ($x > 0$) 的通解。

主要思路:令 $x = \mathrm{e}^t$（即 $t = \ln x$），将变系数欧拉方程化为常系数线性微分方程

>[1]变量代换公式转化：
>
>令 $x = \mathrm{e}^t, \; t = \ln x$。导数算子转换为：
>
>$$x y' = \frac{\mathrm{d}y}{\mathrm{d}t} = D_t y, \quad x^2 y'' = \frac{\mathrm{d}^2 y}{\mathrm{d}t^2} - \frac{\mathrm{d}y}{\mathrm{d}t} = D_t(D_t - 1)y$$
>
>代入原方程：
>
>$$\left[ \frac{\mathrm{d}^2 y}{\mathrm{d}t^2} - \frac{\mathrm{d}y}{\mathrm{d}t} \right] + 4\frac{\mathrm{d}y}{\mathrm{d}t} + 2y = 0$$
>
>化简得关于 $t$ 的常系数线性齐次方程：
>
>$$\frac{\mathrm{d}^2 y}{\mathrm{d}t^2} + 3\frac{\mathrm{d}y}{\mathrm{d}t} + 2y = 0$$
>
>[2]求解常系数特征方程：
>
>特征方程为：
>
>$$r^2 + 3r + 2 = 0 \implies (r + 1)(r + 2) = 0 \implies r_1 = -1, \; r_2 = -2$$
>
>故关于 $t$ 的通解为：
>
>$$y(t) = C_1 \mathrm{e}^{-t} + C_2 \mathrm{e}^{-2t}$$
>
>[3]回代自变量 $x$：
>
>将 $t = \ln x$ 代回：
>
>$$y(x) = C_1 x^{-1} + C_2 x^{-2} = \frac{C_1}{x} + \frac{C_2}{x^2}$$

**例题[15.21]:曳物线（Tractrix）几何追踪曲线建模**

平面上一拖车置于 $y$ 轴上的点 $(0, a)$ 处，牵引点沿 $x$ 轴正方向匀速移动，车与牵引点之间连有长度为 $a$ 的刚性牵引绳。在运动过程中，牵引绳始终与车轮行进轨迹曲线相切。求拖车质点轨迹曲线的微分方程及显式方程。

主要思路:利用切线段长等于定值 $a$ 的几何关系列出微分方程，分离变量积分求解

>[1]建立几何切线段微分方程：
>
>设曲线上点为 $(x, y)$。由于切线指向 $x$ 轴上的牵引点，切线上该点到 $x$ 轴交点的切线段长度为 $a$：
>
>$$|y| \sqrt{1 + \frac{1}{(y')^2}} = a \implies y^2 \left( 1 + \left(\frac{\mathrm{d}x}{\mathrm{d}y}\right)^2 \right) = a^2$$
>
>解出关于 $x(y)$ 的微商（考虑第一象限且斜率为负）：
>
>$$\frac{\mathrm{d}x}{\mathrm{d}y} = -\frac{\sqrt{a^2 - y^2}}{y}$$
>
>[2]分离变量积分：
>
>$$x = -\int \frac{\sqrt{a^2 - y^2}}{y}\,\mathrm{d}y$$
>
>令 $y = a\sin\theta$：
>
>$$x = -\int \frac{a\cos\theta}{a\sin\theta} \cdot a\cos\theta\,\mathrm{d}\theta = -a \int \frac{\cos^2\theta}{\sin\theta}\,\mathrm{d}\theta = -a \int \frac{1 - \sin^2\theta}{\sin\theta}\,\mathrm{d}\theta$$
>
>$$= -a [\ln|\csc\theta - \cot\theta| + \cos\theta] + C = a \ln\left( \frac{a + \sqrt{a^2 - y^2}}{y} \right) - \sqrt{a^2 - y^2} + C$$
>
>[3]由初值确定曲线方程：
>
>当 $y = a$ 时 $x = 0$，代入得 $C = 0$。
>
>故曳物线方程为：
>
>$$x = a \ln\left( \frac{a + \sqrt{a^2 - y^2}}{y} \right) - \sqrt{a^2 - y^2}$$

**例题[15.23]:牛顿冷却定律物理建模与参数辨识**

一壶开水初始温度为 $100^\circ\mathrm{C}$，放置在室温恒为 $20^\circ\mathrm{C}$ 的房间中。经过 30 分钟后水温降为 $60^\circ\mathrm{C}$。根据牛顿冷却定律（物体降温速率与物体和环境的温差成正比），问水温降至 $30^\circ\mathrm{C}$ 还需要多少时间？

>[1]建立微分方程模型：
>
>设 $t$ 分钟时水温为 $T(t)$。由牛顿冷却定律：
>
>$$\frac{\mathrm{d}T}{\mathrm{d}t} = -k (T - 20) \quad (k > 0)$$
>
>分离变量积分：
>
>$$\frac{\mathrm{d}T}{T - 20} = -k\,\mathrm{d}t \implies \ln(T - 20) = -kt + C \implies T(t) = 20 + A\mathrm{e}^{-kt}$$
>
>[2]由初值确定待定系数：
>
>当 $t = 0$ 时 $T(0) = 100$：$100 = 20 + A \implies A = 80$。
>
>故 $T(t) = 20 + 80\mathrm{e}^{-kt}$。
>
>代入 $t = 30$ 时 $T(30) = 60$：
>
>$$60 = 20 + 80\mathrm{e}^{-30k} \implies 80\mathrm{e}^{-30k} = 40 \implies \mathrm{e}^{-30k} = \frac{1}{2} \implies k = \frac{\ln 2}{30}$$
>
>[3]计算降至目标温度的时间：
>
>令 $T(t) = 30$：
>
>$$30 = 20 + 80\mathrm{e}^{-kt} \implies 80\mathrm{e}^{-kt} = 10 \implies \mathrm{e}^{-kt} = \frac{1}{8} = 2^{-3}$$
>
>两边取对数：$-kt = -3\ln 2 \implies t = \frac{3\ln 2}{k} = \frac{3\ln 2}{\frac{\ln 2}{30}} = 90 \text{ 分钟}$。
>
>故从 60℃ 降至 30℃ 还需要：$90 - 30 = 60$ 分钟（即 1 小时）。

**例题[15.24]:一阶常系数线性差分方程求解**

求解一阶差分方程 $\Delta y_t = t$ 满足 $y_0 = 1$ 的通解与特解。

主要思路:利用一阶差分算子定义 $\Delta y_t = y_{t+1} - y_t$，化为累加裂项求和或通解公式

>[1]差分方程化为递推和式：
>
>由定义 $\Delta y_t = y_{t+1} - y_t = t$。
>
>累加法展开：
>
>$$y_t = y_0 + \sum_{k=0}^{t-1} \Delta y_k = y_0 + \sum_{k=0}^{t-1} k$$
>
>[2]求和计算通解：
>
>等差数列求和公式：
>
>$$\sum_{k=0}^{t-1} k = \frac{(t - 1)t}{2} = \frac{1}{2}t(t - 1)$$
>
>通解为：
>
>$$y_t = \frac{1}{2}t^2 - \frac{1}{2}t + C$$
>
>[3]确定特解：
>
>代入 $t = 0, \; y_0 = 1$ 得 $C = 1$。
>
>故特解为 <font color=deeppink>$y_t = \frac{1}{2}t(t - 1) + 1$</font>。

**例题[15.25]:一阶常系数非齐次差分方程三角激励特解法**

求解差分方程 $y_{t+1} - y_t = 4\cos\left(\frac{\pi}{3}t\right)$ 的通解。

主要思路:齐次方程通解为任意常数；非齐次项为余弦函数，设待定特解为 $y_t^* = A\cos\left(\frac{\pi}{3}t\right) + B\sin\left(\frac{\pi}{3}t\right)$ 代入并利用三角和角公式联立求解

>[1]齐次通解确定：
>
>齐次方程为 $y_{t+1} - y_t = 0$，特征方程 $\lambda - 1 = 0 \implies \lambda = 1$。
>
>齐次通解为 $Y_t = C \cdot 1^t = C$（任意常数）。
>
>[2]设待定特解并代入差分算子：
>
>设特解 $y_t^* = A\cos\left(\frac{\pi}{3}t\right) + B\sin\left(\frac{\pi}{3}t\right)$。
>
>计算差分：
>
>$$y_{t+1}^* - y_t^* = A\left[ \cos\left(\frac{\pi}{3}t + \frac{\pi}{3}\right) - \cos\left(\frac{\pi}{3}t\right) \right] + B\left[ \sin\left(\frac{\pi}{3}t + \frac{\pi}{3}\right) - \sin\left(\frac{\pi}{3}t\right) \right]$$
>
>利用三角和差化积或展开公式：
>
>$$\cos\left(\frac{\pi}{3}t + \frac{\pi}{3}\right) = \frac{1}{2}\cos\left(\frac{\pi}{3}t\right) - \frac{\sqrt{3}}{2}\sin\left(\frac{\pi}{3}t\right)$$
>
>$$\sin\left(\frac{\pi}{3}t + \frac{\pi}{3}\right) = \frac{1}{2}\sin\left(\frac{\pi}{3}t\right) + \frac{\sqrt{3}}{2}\cos\left(\frac{\pi}{3}t\right)$$
>
>代入差分整理可得：
>
>$$\left( -\frac{1}{2}A + \frac{\sqrt{3}}{2}B \right) \cos\left(\frac{\pi}{3}t\right) + \left( -\frac{\sqrt{3}}{2}A - \frac{1}{2}B \right) \sin\left(\frac{\pi}{3}t\right) = 4\cos\left(\frac{\pi}{3}t\right)$$
>
>[3]联立代数方程组求解并写出通解：
>
>对应系数相等：
>
>$$\begin{cases} -\frac{1}{2}A + \frac{\sqrt{3}}{2}B = 4 \\ \\ -\frac{\sqrt{3}}{2}A - \frac{1}{2}B = 0 \end{cases}$$
>
>由第二式得 $B = -\sqrt{3}A$。代入第一式：
>
>$$-\frac{1}{2}A + \frac{\sqrt{3}}{2}(-\sqrt{3}A) = -\frac{1}{2}A - \frac{3}{2}A = -2A = 4 \implies A = -2$$
>
>进而 $B = 2\sqrt{3}$。
>
>故原方程通解为：
>
>$$y_t = C - 2\cos\left(\frac{\pi}{3}t\right) + 2\sqrt{3}\sin\left(\frac{\pi}{3}t\right)$$
