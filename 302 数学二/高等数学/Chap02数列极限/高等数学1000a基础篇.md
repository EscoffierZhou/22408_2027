**(中等)<font color=red>题目[1]:1的无穷大次型数列极限</font>**

$$\lim\limits_{n \to \infty}\left(\frac{4}{\pi}\arctan\frac{n}{n+1}\right)^n = (\text{A})$$

(A)$$e^{-\frac{2}{\pi}}$$ 

(B)$$e^{\frac{\pi}{2}}$$ 

(C)$$\frac{\pi}{2}$$ 

(D)$$\frac{2}{\pi}$$ 

答案: (A)

解:[判断未定式直接做]

[1]判断未定式:当$$n \to \infty$$时，$$\frac{n}{n+1} \to 1$$，$$\arctan 1 = \frac{\pi}{4}$$$$[1^\infty]$$

[2]修改为指数形式,写成x的形式:$$\lim\limits_{x \to \infty} e^{xln{\left( \frac{4}{\pi}\arctan\frac{x}{x+1}\right)}}$$

[3]看到分式型<font color=red>倒代换</font>:令$t = \frac{1}{n}$,当$n \to \infty$时,即$t \to 0$:$$ e^{\lim\limits_{x \to \infty}xln{\left( \frac{4}{\pi}\arctan\frac{x}{x+1}\right)}} =  e^{ \lim_{t \to 0^+} \frac{\ln \frac{4}{\pi} + \ln \arctan \frac{1}{1+t}}{t}}$$

[3]洛必达法则对于$$L = \lim_{t \to 0^+} \frac{\ln \frac{4}{\pi} + \ln \arctan \frac{1}{1+t}}{t}[\frac{0}{0}型]$$

   分子求导：常数项 $\ln \frac{4}{\pi}$ 导数为 $0$；对 $\ln \left(\arctan \frac{1}{1+t}\right)$ 依据由外向内链式求导：

   $$\left[\ln \left(\arctan \frac{1}{1+t}\right)\right]' = \underbrace{\frac{1}{\arctan \frac{1}{1+t}}}_{\text{对 }\ln\text{ 求导}} \cdot \underbrace{\frac{1}{1 + \left(\frac{1}{1+t}\right)^2}}_{\text{对 }\arctan\text{ 求导}} \cdot \underbrace{\left(-\frac{1}{(1+t)^2}\right)}_{\text{对 }\frac{1}{1+t}\text{ 求导}}$$

   第一项：$\lim\limits_{t \to 0^+} \frac{1}{\arctan \frac{1}{1+t}} = \frac{1}{\arctan 1} = \frac{1}{\frac{\pi}{4}} = \frac{4}{\pi}$

   第二项与第三项合并化简$$\frac{1}{1 + \left(\frac{1}{1+t}\right)^2} \cdot \left(-\frac{1}{(1+t)^2}\right) = \frac{-1}{(1+t)^2 + 1}$$,求极限$$\frac{-1}{(1+0)^2 + 1} = -\frac{1}{2}$$

   所以:$$L = \frac{4}{\pi} \cdot \left(-\frac{1}{2}\right) = -\frac{2}{\pi}$$

   故原极限为$$e^L = e^{-\frac{2}{\pi}}$$

<font color=red>[注]:$(\arctan v)' = \frac{1}{1 + v^2} \cdot v'$,$(\ln u)' = \frac{1}{u} \cdot u'$</font>

​    $\left(\frac{1}{w}\right)' = \frac{0 \cdot w - 1 \cdot w'}{w^2} = -\frac{w'}{w^2}$(商的求导法则),比如$$\left(\frac{1}{1+t}\right)' = -\frac{(1+t)'}{(1+t)^2} = -\frac{1}{(1+t)^2}$$

**(简单?再看一眼)<font color=deeppink>题目[2]:拉格朗日中值定理降次夹逼[构造上下界]</font>**

$$\lim\limits_{n \to \infty}\frac{n^{99}}{n^{100} - (n-1)^{100}} = \underline{\qquad\frac{1}{100}\qquad}$$

解:[对分母构造拉格朗日中值定理快速降次]\[不等式还原原式][夹逼定理]

[1]拉格朗日中值定理:设函数$$f(x) = x^{100}$$，在闭区间$$[n-1, n]$$上应用拉格朗日中值定理:

   $$n^{100} - (n-1)^{100} = f(n) - f(n-1) = f'(\xi) \cdot [n - (n-1)]= 100 \xi^{99}$$,其中$$\xi \in (n-1, n)$$

[2]夹逼准则还原原式:

   因为$$n-1 < \xi < n$$，两边取99次方:$$(n-1)^{99} < \xi^{99} < n^{99}$$,同乘10则分母有:$$100(n-1)^{99} < n^{100} - (n-1)^{100} < 100 n^{99}$$

   两端取倒数并同乘分子$$n^{99}$$:$$\frac{n^{99}}{100 n^{99}} < \frac{n^{99}}{n^{100} - (n-1)^{100}} < \frac{n^{99}}{100(n-1)^{99}}$$

[3]对两边求极限:当$$n \to \infty$$时，左右两侧极限均为$$\frac{1}{100}$$

[4]得出结论:由夹逼定理得:$$\lim\limits_{n \to \infty}\frac{n^{99}}{n^{100} - (n-1)^{100}} = \frac{1}{100}$$

**(简单?再看一眼)<font color=green>题目[3]:有界数列求和与极限</font>**

设$$\{a_n\}$$非负有界，$$b_n = \sum\limits_{k=1}^n \frac{k}{a_n + n^2}$$，则$$\lim\limits_{n \to \infty}\frac{1}{b_n} = \underline{\qquad2\qquad}$$

解:[技巧1:求和符号换求和公式]\[技巧2:数列等价于有界极限]

[1]化简$$b_n$$表达式+求和公式:$$b_n = \frac{1}{a_n + n^2} \sum_{k=1}^n k = \frac{1}{a_n + n^2} \cdot \frac{n(n+1)}{2} = \frac{n(n+1)}{2(a_n + n^2)}$$

[2]求$$\frac{1}{b_n}$$的极限:$$\frac{1}{b_n} = \frac{2(a_n + n^2)}{n(n+1)} = \frac{2n^2 + 2a_n}{n^2 + n} = \frac{2n^2}{n^2 + n} + \frac{2a_n}{n^2 + n}$$

[3]对于$$\frac{2n^2}{n^2 + n}$$:抓大头,极限为2

   对于$$\frac{2a_n}{n^2 + n}$$:因为$$\{a_n\}$$有界，即存在常数$$M > 0$$满足$$0 \le a_n \le M$$，

   故当$$n \to \infty$$时，$$\lim\limits_{n \to \infty} \frac{2a_n}{n^2 + n} = 0$$（[有界量] 乘以 [无穷小量]为 [无穷小量0]）

[4]得出结论:$$\lim_{n \to \infty} \frac{1}{b_n} = \lim_{n \to \infty} \frac{2n^2}{n^2 + n} + 0 = 2$$

**(中等)<font color=deeppink>题目[4]:均值不等式与单调有界准则</font>**

设$$x_0 > 0$$，$$x_{n+1} = \frac{1}{2}\left(x_n + \frac{a}{x_n}\right)\ (n=0, 1, 2, \dots)$$，且$$a > 0$$，证明$$\lim\limits_{n \to \infty} x_n$$存在，并求此极限

解:[一眼看出不等式,有下界]\[记得递推式需要计算A=f(A)]

[1]证明数列有界性:

   由基本均值不等式，对任意$$n \ge 0$$:$$x_{n+1} = \frac{1}{2}\left(x_n + \frac{a}{x_n}\right) \ge \sqrt{x_n \cdot \frac{a}{x_n}} = \sqrt{a}$$

   故当$$n \ge 1$$时，恒有$$x_n \ge \sqrt{a} > 0$$，得出结论:下界$$\sqrt{a}$$

[2]证明数列单调性:

   对$$n \ge 1$$，作差考察:$$x_{n+1} - x_n = \frac{1}{2}\left(x_n + \frac{a}{x_n}\right) - x_n = \frac{a - x_n^2}{2x_n}$$

   因为当$$n \ge 1$$时$$x_n \ge \sqrt{a}$$，所以$$x_n^2 \ge a$$,分子恒为负数,且分母$$x_n > 0$$

   故:$$x_{n+1} - x_n \le 0 \implies x_{n+1} \le x_n \quad (n \ge 1)$$

[3]单调有界准则:

   综上，数列$$\{x_n\}_{n=1}^\infty$$单调递减且有下界，由单调有界收敛准则知:$$\lim\limits_{n \to \infty} x_n$$必定存在

[4]求解极限值:

   设$$\lim\limits_{n \to \infty} x_n = L$$由$$x_n \ge \sqrt{a}$$可知$$L \ge \sqrt{a} > 0$$

   对递推式两端取极限:$$L = \frac{1}{2}\left(L + \frac{a}{L}\right) \implies 2L^2 = L^2 + a \implies L^2 = a$$

   由于前文所述$$L > 0$$，解得:$$L = \sqrt{a}$$,故极限存在且$$\lim\limits_{n \to \infty} x_n = \sqrt{a}$$

**(简单)<font color=green>题目[5]:三角夹逼[自带上界]</font>**

当$$0 \le x \le \frac{\pi}{2}$$时，$$\lim\limits_{n \to \infty}\sqrt[n]{\sin^n x + \cos^n x} = \underline{\qquad\qquad}$$

答案:$$\max\{\sin x, \cos x\}$$（或分段写出）

解:[无法化简,并且sinx和cosx在同时动态变化,但总有上界]\[不等式还原原式]\[夹逼定理]

[1]夹逼放缩:当$$x \in [0, \frac{\pi}{2}]$$时，$$\sin x \ge 0, \cos x \ge 0$$

   设$$M = \max\{\sin x, \cos x\}$$，则显然有:$$M^n \le \sin^n x + \cos^n x \le 2 M^n$$

   两端开$$n$$次方:$$M \le \sqrt[n]{\sin^n x + \cos^n x} \le \sqrt[n]{2} M$$

[2]取极限得结论:当$$n \to \infty$$时，$$\lim\limits_{n \to \infty} \sqrt[n]{2} = 1$$

   由夹逼定理得:$$\lim_{n \to \infty}\sqrt[n]{\sin^n x + \cos^n x} = M = \max\{\sin x, \cos x\}$$

   具体分段表达式为:$$\lim_{n \to \infty}\sqrt[n]{\sin^n x + \cos^n x} = \begin{cases} \cos x, & 0 \le x \le \frac{\pi}{4} \\ \\ \sin x, & \frac{\pi}{4} < x \le \frac{\pi}{2} \end{cases}$$

**(简单)<font color=green>题目[6]:绝对值夹逼[分类讨论]</font>**

$$\lim\limits_{n \to \infty}\sqrt[n]{1 + |x|^{3n}} = \underline{\qquad\max\{1, |x|^3\}\qquad}$$

解:[按底数是否大于1分类讨论，应用夹逼准则]

[1]分类讨论基底大小:

当$$|x|^3 < 1$$，即$$|x| < 1$$时:$$1 \le 1 + |x|^{3n} \le 1 + 1 = 2 $$

   带上根号:$$ 1 \le \sqrt[n]{1 + |x|^{3n}} \le \sqrt[n]{2}$$

   由夹逼定理知:$$\lim\limits_{n \to \infty}\sqrt[n]{1 + |x|^{3n}} = 1$$

当$$|x|^3 = 1$$，即$$|x| = 1$$时:	$$\sqrt[n]{1 + 1} = \sqrt[n]{2} \to 1$$

当$$|x|^3 > 1$$，即$$|x| > 1$$时:	$$|x|^3 \le \sqrt[n]{1 + (|x|^3)^n} \le \sqrt[n]{2 (|x|^3)^n} = \sqrt[n]{2} |x|^3$$	由夹逼定理知:$$\lim\limits_{n \to \infty}\sqrt[n]{1 + |x|^{3n}} = |x|^3$$

[2]得出结论:

$$\lim_{n \to \infty}\sqrt[n]{1 + |x|^{3n}} = \max\{1, |x|^3\} = \begin{cases} 1, & |x| \le 1 \\ \\ |x|^3, & |x| > 1 \end{cases}$$

**(中等)<font color=deeppink>题目[7]:递推不等式与数列单调性</font>**

设数列$$\{x_n\}$$满足$$x_{n+1} = \ln x_n + 1$$，$$x_n > 0$$，$$n=1, 2, \dots$$，则$$\{x_n\}(\text{B})$$

(A) 单调不减  

(B) 单调不增  

(C) 严格单调递增  

(D) 严格单调递减  

解:[研究差值$x_{n+1} - x_n$]

[1]两项差值:$$x_{n+1} - x_n = \ln x_n + 1 - x_n$$,判断它的正负,求导最简单

[2]构造辅助函数:令$$g(x) = \ln x + 1 - x\ (x > 0)$$，求导得:$$g'(x) = \frac{1}{x} - 1 = \frac{1-x}{x}$$

   当$$0 < x < 1$$时，$$g'(x) > 0$$，$$g(x)$$单调递增；

   当$$x > 1$$时，$$g'(x) < 0$$，$$g(x)$$单调递减

   故$$x = 1$$为$$g(x)$$在$$(0, +\infty)$$上的全局最大值点:$$g(x) \le g(1) = \ln 1 + 1 - 1 = 0$$

即对任意$$x > 0$$，恒有$$\ln x + 1 \le x$$（仅在$$x=1$$时取等号）

[3]<font color=red>判定单调性(有坑点)</font>

若$$x_1 \neq 1$$，则为严格递减,刚刚得到$$x_{n+1} - x_n = g(x_n) \le 0 $$,即$$x_{n+1} \le x_n$$(单调递减)

若$$x_1 = 1$$，则对所有$$n$$均有$$x_n = 1$$，此时为常数列

**(简单)<font color=green>题目[8]:压缩映射原理证明数列收敛</font>**

若对于数列$$\{x_n\}$$，存在常数$$k\ (0 < k < 1)$$，使得$$|x_{n+1} - a| \le k|x_n - a|$$，$$n=1, 2, \dots$$证明$$\{x_n\}$$收敛于$$a$$

解:[递推放缩配合夹逼定理证明绝对误差趋于0]

[1]建立递推不等式:

   由已知条件，对任意$$n \ge 1$$:$$|x_{n+1} - a| \le k |x_n - a|$$

   连续递推放缩:$$|x_n - a| \le k |x_{n-1} - a| \le k^2 |x_{n-2} - a| \le \dots \le k^{n-1} |x_1 - a|$$

[2]夹逼准则证明极限:

   左侧极限:绝对值必然大于0(对任意$$n \ge 1$$，恒有:$$0 \le |x_n - a| \le k^{n-1} |x_1 - a|$$)

   右侧极限:**因为$$0 < k < 1$$**，当$$n \to \infty$$时，$$\lim\limits_{n \to \infty} k^{n-1} = 0$$,又因为$$|x_1 - a|$$为有限常数，故:$$\lim_{n \to \infty} k^{n-1} |x_1 - a| = 0$$

[3]由夹逼定理得:

   $$\lim_{n \to \infty} |x_n - a| = 0 \iff \lim_{n \to \infty} x_n = a$$,证毕，数列$$\{x_n\}$$收敛于$$a$$

**(简单)<font color=green>题目[10]:夹逼准则求极限[范围]</font>**

   由夹逼定理，直接得出:	  $$\lim_{n \to \infty} a_n = 0$$

**(简单)<font color=green>题目[11]:函数单调性</font>**

设$$c = 2\ln(1+b)$$，$$b > a > 0$$，且$$a$$是方程$$x - 2\ln(1+x) = 0$$的唯一非零解，证明$$c > a$$

解:[坑在于要把a放在一边,会发现函数一样,讨论即可]

[1]由题设,$$a$$满足方程$$a - 2\ln(1+a) = 0$$，即:$$a = 2\ln(1+a)$$

[2]考察函数$$g(x) = 2\ln(1+x)$$的单调性:

   对任意$$x > -1$$:$$g'(x) = \frac{2}{1+x} > 0$$,故$$g(x)$$在$$(-1, +\infty)$$上严格单调递增

[3]已知$$b > a > 0$$，$$g(x)$$单调递增,$$2\ln(1+b) > 2\ln(1+a)$$

   将$$c = 2\ln(1+b)$$与$$a = 2\ln(1+a)$$代入，直接得出:$$c > a$$

**(中等)<font color=deeppink>题目[12]:数学归纳法与单调有界准则证明收敛</font>**

设单调递减数列$$\{x_n\}$$满足$$x_{n+1} = 2\ln(1+x_n)$$，$$n=1, 2, \dots$$，$$x_1 > a > 0$$，且$$a$$是$$x - 2\ln(1+x) = 0$$的唯一非零解，证明$$\{x_n\}$$收敛

解:[题设已知单调递减，只需利用数学归纳法证明有下界$a$即可]

**本题核心即求导-求端点-下结论即可,下述描述是为了更严谨**

[1]数学归纳法证明下界:

   证明对所有正整数$$n \ge 1$$，恒有$$x_n > a$$:

   (1) 当$$n = 1$$时，由已知条件直接有$$x_1 > a$$，结论成立

   (2) 假设当$$n = k$$时结论成立，即$$x_k > a$$

   (3) 考察$$n = k + 1$$:

[2]根据递推关系，$$x_{k+1} = 2\ln(1+x_k)$$

   令$$g(x) = 2\ln(1+x)$$，当$$x > 0$$时$$g'(x) = \frac{2}{1+x} > 0$$，$$g(x)$$严格单调递增

   由归纳假设$$x_k > a$$，故:$$g(x_k) > g(a)$$,即:$$x_{k+1} > 2\ln(1+a)$$

   因为$$a$$是方程$$x - 2\ln(1+x) = 0$$的解，所以$$2\ln(1+a) = a$$

   从而有$$x_{k+1} > a$$，即当$$n = k+1$$时结论亦成立

   综合由数学归纳法可知，对任意正整数$$n$$，恒有$$x_n > a$$,即数列$$\{x_n\}$$有下界$$a$$

[2]单调有界收敛准则完成证明:因为数列$$\{x_n\}$$单调递减，且有下界$$a$$，由单调有界收敛准则，数列$$\{x_n\}$$必然收敛

（补充说明:设极限为$$L = \lim\limits_{n \to \infty} x_n$$，则必有$$L \ge a > 0$$在递推式两端取极限得$$L = 2\ln(1+L)$$，因为$$a$$是方程的唯一正解，所以极限值为$$\lim\limits_{n \to \infty} x_n = a$$）
