## 3.例题

**例题[1]:多项式乘积导数**

题目:设$f(x) = \prod_{n=1}^{100} \left(\tan \frac{\pi x^n}{4} - n\right)$，则$f'(1) =$______

基本思路:使用第一项进行探查,再使用$f'(1) = u'(1)g(1) + u(1)g'(1)$

>[1]记$g(x) = \prod_{n=2}^{100} \left(\tan \frac{\pi x^n}{4} - n\right)$，则$I = \left(\tan \frac{\pi x}{4} - 1\right) g(x)$
>
>[2]对$f(x)$求导得:[注意这里$\frac{\pi}{4}x$复合]
>
>$f'(x) = \sec^2\left(\frac{\pi x}{4}\right) \cdot \frac{\pi}{4} \cdot g(x) + \left(\tan \frac{\pi x}{4} - 1\right) g'(x)$
>
>$$f'(1) = \sec^2\left(\frac{\pi}{4}\right) \cdot \frac{\pi}{4} \cdot g(1) +0$$
>
>​       $$= 2 \cdot \frac{\pi}{4} \cdot g(1) = \frac{\pi}{2} g(1)$$
>
>[3]计算$g(1)$：
>
>$$g(1) = \prod_{n=2}^{100} (1 - n) = (-1) \cdot (-2) \cdot (-3) \dots (-99) = (-1)^{99} \cdot 99! = -99!$$
>
>[4]$f'(1) = -\frac{\pi \cdot 99!}{2}$

**例题[2]:复合函数求导**

设$y = \ln(x + \sqrt{x^2+a^2})\ (a \neq 0)$，求$y'\big\vert{}_{x=0}$

>   [1]$$y' = \frac{1}{x + \sqrt{x^2+a^2}} \cdot \left(x + \sqrt{x^2+a^2}\right)'$$
>
>   [2]计算内层导数:
>
>   ​	$[(x^2+a^2)^{\frac{1}{2}}]' = \frac{1}{2}(x^2+a^2)^{-\frac{1}{2}}\cdot (x^2+a^2)'= \frac{1}{2}(x^2+a^2)\cdot 2x$
>
>   ​	$$\left(x + \sqrt{x^2+a^2}\right)'  = 1 + \frac{1}{2\sqrt{x^2+a^2}} \cdot 2x = 1 + \frac{x}{\sqrt{x^2+a^2}} = \frac{\sqrt{x^2+a^2} + x}{\sqrt{x^2+a^2}}$$
>
>   [3]相乘相消：$$y' = \frac{1}{x + \sqrt{x^2+a^2}} \cdot \frac{x + \sqrt{x^2+a^2}}{\sqrt{x^2+a^2}} = \frac{1}{\sqrt{x^2+a^2}}$$
>
>   [4]代入$x=0$：$$y'\big\vert{}_{x=0} = \frac{1}{\sqrt{a^2}} = \frac{1}{\vert{}a\vert{}}$$

**例题[3]:分段+复合函数求导**

设函数$f(x) = \begin{cases} \ln\sqrt{x}, & x \ge 1 \\ 2x - 1, & x < 1 \end{cases}$，且$y = f[f(x)]$，则$\left.\frac{\mathrm{d}y}{\mathrm{d}x}\right\vert{}_{x=e} =$______

基本思路:多次分段求导即可

>计算$f(e)$：因为$e \ge 1$，代入第一段$f(e) = \ln\sqrt{e} = \frac{1}{2}$
>
>计算$f'(e)$：点$x=e$落在区间$(1, +\infty)$内部，为非分段点，直接用导数公式
>
>>   $$f'(x) = (\ln\sqrt{x})' = \left(\frac{1}{2}\ln x\right)' = \frac{1}{2x} \implies f'(e) = \frac{1}{2e}$$
>
>计算$f'[f(e)] = f'\left(\frac{1}{2}\right)$：因为$\frac{1}{2} < 1$，落在区间$(-\infty, 1)$内部，对应第二段函数：
>
>>   $$f'\left(\frac{1}{2}\right) = (2x - 1)' = 2$$
>
>综合相乘：$$\left.\frac{\mathrm{d}y}{\mathrm{d}x}\right\vert{}_{x=e} = f'\left(\frac{1}{2}\right) \cdot f'(e) = 2 \cdot \frac{1}{2e} = \frac{1}{e}$$

**例题[4]:求微分**

设$y = e^{\sin(\ln x)}$，求$\mathrm{d}y$及$\frac{\mathrm{d}y}{\mathrm{d}x}$

基本思路:一阶微分形式不变性（$\mathrm{d}[f(u)] = f'(u)\,\mathrm{d}u$）与链式法则的结合应用

>   利用微分形式不变性：$$\mathrm{d}y = \mathrm{d}\left[e^{\sin(\ln x)}\right] = e^{\sin(\ln x)} \mathrm{d}[\sin(\ln x)]$$
>
>   对内层继续凑微分：$$= e^{\sin(\ln x)} \cos(\ln x) \mathrm{d}(\ln x) = e^{\sin(\ln x)} \cos(\ln x) \cdot \frac{1}{x} \mathrm{d}x$$
>
>   整理得：$$\mathrm{d}y = \frac{e^{\sin(\ln x)} \cos(\ln x)}{x}\,\mathrm{d}x$$,$$\frac{\mathrm{d}y}{\mathrm{d}x} = \frac{e^{\sin(\ln x)} \cos(\ln x)}{x}$$

**例题[5]:绝对值求导数**

设$y = \ln\vert{}x\vert{}\ (x \neq 0)$，求$y'$

基本思路:带绝对值需要转换为分段函数处理,还要标出无定义点($x=0$)

>$$y = \begin{cases} \ln x, & x > 0\\ \\ \ln(-x), & x < 0 \end{cases}$$
>
>当$x > 0$时：$$y' = (\ln x)' = \frac{1}{x}$$
>
>当$x < 0$时：$$y' = [\ln(-x)]' = \frac{1}{-x} \cdot (-x)' = \frac{1}{-x} \cdot (-1) = \frac{1}{x}$$
>
>对任意$x \neq 0$，均有$y' = (\ln\vert{}x\vert{})' = \frac{1}{x}$

**例题[6]:绝对值求二阶导数**

设函数$y = \vert{}xe^{-x}\vert{}$，求$y''$

基本思路:通过一阶导数的定义判断可导性，若一阶不可导则二阶直接不存在

>   [1]去绝对值改写函数：
>
>   $$y = \begin{cases} -xe^{-x}, & x < 0 \\ \\xe^{-x}, & x \ge 0 \end{cases}$$
>
>   [2]非分段点求一阶导数：
>
>   当$x < 0$时，$y' = [e^{-x}(-x)]' = -e^{-x} + xe^{-x} = e^{-x}(x - 1)$
>
>   当$x > 0$时，$y' = [e^{-x}x]' = e^{-x} - xe^{-x} = e^{-x}(1 - x)$
>
>   [3]在分段点$x=0$处用定义验算左右导数：
>
>   $$y'_-(0) = \lim_{x \to 0^-} \frac{-xe^{-x} - 0}{x} = \lim_{x \to 0^-} (-e^{-x}) = -1$$
>
>   $$y'_+(0) = \lim_{x \to 0^+} \frac{xe^{-x} - 0}{x} = \lim_{x \to 0^+} e^{-x} = 1$$
>
>   由于$y'_-(0) \neq y'_+(0)$，故$y'(0)$不存在，在$x=0$处不可导
>
>   [4]对非分段点求二阶导数：
>
>   当$x < 0$时，$y'' = [e^{-x}(x - 1)]' = -e^{-x}(x - 1) + e^{-x} = e^{-x}(2 - x)$
>
>   当$x > 0$时，$y'' = [e^{-x}(1 - x)]' = -e^{-x}(1 - x) - e^{-x} = e^{-x}(x - 2)$
>
>   [5]结论：$$y'' = \begin{cases} e^{-x}(2 - x), & x < 0 \\ e^{-x}(x - 2), & x > 0 \end{cases} \quad (x=0 \text{ 处不存在})$$

**<font color=red>例题[7]:反函数求导</font>**

当$x > 0$时，设$y = f(x) = 3x^2 + e^x$有反函数$x = \varphi(y)$，则$\varphi''(3+e) =$______

主要思路:一般带入反函数二阶导数即可,切记求$x=\varphi(y)$,<font color=red>还需求真实的x</font>

>   当$y = 3+e$时，求解$3x^2 + e^x = 3+e$,由于$x>0$时函数单调递增，显然$x = 1$

对原函数分别求一阶和二阶导数,然后带入$x=1$：

>   $$f'(x) = 6x + e^x \implies f'(1) = 6 + e$$
>
>   $$f''(x) = 6 + e^x \implies f''(1) = 6 + e$$

套入反函数二阶导数公式：

>   $$\varphi''(3+e) = -\frac{f''(1)}{[f'(1)]^3} = -\frac{6+e}{(6+e)^3} = -\frac{1}{(6+e)^2}$$

**例题[8]:隐函数求导**

设函数$y = y(x)$由方程$y^3 + xy^2 + x^2y + 6 = 0$确定，且$y'(1) = 0$，求$y''(1)$的值

主要思路:方程两端对自变量$x$逐项求导，将$y$视为中间复合函数，利用代入法化简运算

操作[1]:方程两边对$x$求导:		$$3y^2y' + y^2 + 2xyy' + 2xy + x^2y' = 0$$

操作[2]:代入$x=1$ 以及 $y'(1)=0$：       $$0 + y^2 + 0 + 2y + 0 = 0 \implies y^2 + 2y = 0 \implies y = 0 \text{ 或 } y = -2$$

操作[3]检验原方程:$y^3 + xy^2 + x^2y + 6 = 0$：

>   若$y=0$：代入得$6=0$(矛盾,舍去)
>
>   若$y=-2$：$(-2)^3 + 1(-2)^2 + 1^2(-2) + 6 = -8 + 4 - 2 + 6 = 0$（符合题意）
>
>   因此当$x=1$时，$y = -2$

将一阶求导整理后的式子再次对$x$求导：     $$(3y^2 + 2xy + x^2)y'' + (6yy' + 2y + 2xy' + 2x)y' + 2yy' + 2y + 2xy' = 0$$

将$x=1, y=-2, y'=0$全部代入：	 $$\left[3(-2)^2 + 2(1)(-2) + 1^2\right] y''(1) + 0 + 0 + 2(-2) + 0 = 0$$


​				     $$(12 - 4 + 1) y''(1) - 4 = 0 \implies 9y''(1) = 4 \implies y''(1) = \frac{4}{9}$$

**例题[9]:参数方程求导**

设$y = y(x)$由参数方程$\begin{cases} x = \sin t \\ \\ y = t\sin t + \cos t \end{cases}$确定，则$\left.\frac{\mathrm{d}^2y}{\mathrm{d}x^2}\right\vert{}_{t=\frac{\pi}{4}} =$______

参数方程一阶求导公式:$$\frac{\mathrm{d}y}{\mathrm{d}x} = \frac{\mathrm{d}y}{\mathrm{d}t} \cdot \frac{\mathrm{d}t}{\mathrm{d}x} = \frac{\frac{\mathrm{d}y}{\mathrm{d}t}}{\frac{\mathrm{d}x}{\mathrm{d}t}}$$[对t的求导]

参数方程二阶求导公式:$\frac{\mathrm{d}^2y}{\mathrm{d}x^2} = \frac{\frac{\mathrm{d}}{\mathrm{d}t}\left(\frac{\mathrm{d}y}{\mathrm{d}x}\right)}{\frac{\mathrm{d}x}{\mathrm{d}t}}$     [对t的求导]<font color=red>(不能简单地用$y''(t)$除以$x''(t)$；必须将一阶导数$\frac{\mathrm{d}y}{\mathrm{d}x}$对参数$t$求导，再除以$x'(t)$)</font>

操作[1]:求关于参数$t$的一阶导数：

>   $$\frac{\mathrm{d}x}{\mathrm{d}t} = \cos t$$
>
>   $$\frac{\mathrm{d}y}{\mathrm{d}t} = \sin t + t\cos t - \sin t = t\cos t$$

操作[2]:求一阶导数：$$\frac{\mathrm{d}y}{\mathrm{d}x} = \frac{\frac{\mathrm{d}y}{\mathrm{d}t}}{\frac{\mathrm{d}x}{\mathrm{d}t}} = \frac{t\cos t}{\cos t} = t$$

操作[3]:求二阶导数：$$\frac{\mathrm{d}^2y}{\mathrm{d}x^2} = \frac{\frac{\mathrm{d}}{\mathrm{d}t}(t)}{\frac{\mathrm{d}x}{\mathrm{d}t}} = \frac{1}{\cos t}$$

操作[4]代入$t = \frac{\pi}{4}$：$$\left.\frac{\mathrm{d}^2y}{\mathrm{d}x^2}\right\vert{}_{t=\frac{\pi}{4}} = \frac{1}{\cos\frac{\pi}{4}} = \frac{1}{\frac{\sqrt{2}}{2}} = \sqrt{2}$$

**例题[10]:参数方程隐函数求导**

设函数$y = y(x)$由$\begin{cases} x = \arctan t \\\\ 2y - ty^2 + e^t = 5 \end{cases}$所确定，则$\frac{\mathrm{d}y}{\mathrm{d}x} =$______

主要思想:需要先用隐函数求导法求出$\frac{\mathrm{d}y}{\mathrm{d}t}$，再用参数方程求导公式相除

操作[1]:计算$\frac{\mathrm{d}x}{\mathrm{d}t}$：$$\frac{\mathrm{d}x}{\mathrm{d}t} = (\arctan t)' = \frac{1}{1+t^2}$$

操作[2]:对第二个方程两边关于$t$求导：$$2\frac{\mathrm{d}y}{\mathrm{d}t} - \left(y^2 + 2ty\frac{\mathrm{d}y}{\mathrm{d}t}\right) + e^t = 0$$


​				$$(2 - 2ty)\frac{\mathrm{d}y}{\mathrm{d}t} = y^2 - e^t \implies \frac{\mathrm{d}y}{\mathrm{d}t} = \frac{y^2 - e^t}{2(1 - ty)}$$

操作[3]:综合求$\frac{\mathrm{d}y}{\mathrm{d}x}$：$$\frac{\mathrm{d}y}{\mathrm{d}x} = \frac{\frac{\mathrm{d}y}{\mathrm{d}t}}{\frac{\mathrm{d}x}{\mathrm{d}t}} = \frac{\frac{y^2 - e^t}{2(1 - ty)}}{\frac{1}{1+t^2}} = \frac{(y^2 - e^t)(1+t^2)}{2(1 - ty)}$$

**例题[11]:幂函数+隐函数求导**

设函数$y = y(x)$由方程$xe^{f(y)} = e^y \ln 2$确定，其中$f$具有二阶导数，且$f' \neq 1$，则$\frac{\mathrm{d}^2y}{\mathrm{d}x^2} =$______

主要思路:方程中出现$e^{f(y)}$和$e^y$等幂次(直接求导容易产生庞大的链式项);两边先取对数可以将指数降为线性加法，大幅减少求导运算量

操作[1]两端取自然对数:$$\ln x + f(y) = y + \ln(\ln 2)$$

操作[2]两端第一次对$x$求导：$$\frac{1}{x} + f'(y)y' = y' \implies y' = \frac{1}{x[1 - f'(y)]}$$

操作[3]两端第二次对$x$求导:$$-\frac{1}{x^2} + f''(y)(y')^2 + f'(y)y'' = y''$$

​			$$y''[1 - f'(y)] = -\frac{1}{x^2} + f''(y)(y')^2$$

​			($y' = \frac{1}{x[1 - f'(y)]}$代入):$$y''[1 - f'(y)] = -\frac{1}{x^2} + \frac{f''(y)}{x^2[1 - f'(y)]^2} = -\frac{[1 - f'(y)]^2 - f''(y)}{x^2[1 - f'(y)]^2}$$

操作[4]化简:两边同除以$[1 - f'(y)]$：$$y'' = -\frac{[1 - f'(y)]^2 - f''(y)}{x^2[1 - f'(y)]^3}$$

**例题[12]:幂指函数求导**

求函数$y = x^x\ (x > 0)$的导数

操作[1]:化为复合指数:$$y = x^x = e^{\ln(x^x)} = e^{x\ln x}$$

操作[2]:按照指数函数及复合函数链式法则求导:$$y' = (e^{x\ln x})' = e^{x\ln x} \cdot (x\ln x)'$$

操作[3]:计算内层积的导数:$$(x\ln x)' = 1 \cdot \ln x + x \cdot \frac{1}{x} = \ln x + 1$$

操作[4]:还原表达式:$$y' = x^x(1 + \ln x) \quad (x > 0)$$

**例题[13]:幂指函数+复合函数求导**

求函数$y = x^{\frac{1}{x}}\ (x > 0)$的导数

主要思路:幂指函数变形与复合函数商/积的求导(改写为以$e$为底的指数函数)

操作[1]:改写为e为底:$$y = x^{\frac{1}{x}} = e^{\frac{1}{x}\ln x}$$

操作[2]求导:$$y' = \left(e^{\frac{\ln x}{x}}\right)' = e^{\frac{\ln x}{x}} \cdot \left(\frac{\ln x}{x}\right)'$$

操作[3]计算括号内的商导数：$$\left(\frac{1}{x}\ln x\right)' = -\frac{1}{x^2}\ln x + \frac{1}{x} \cdot \frac{1}{x} = \frac{1 - \ln x}{x^2}$$

操作[4]还原底数形式：$$y' = x^{\frac{1}{x}} \cdot \frac{1 - \ln x}{x^2} = x^{\frac{1}{x} - 2}(1 - \ln x) \quad (x > 0)$$
