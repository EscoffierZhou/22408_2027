# 英语(一) 高频核心词汇与熟词生义归纳

> **记词策略**: 
> 1. 结合真题语境记忆（真题中出现的单词必须 100% 认识）；
> 2. 重点攻克熟词生义（考研最爱考常见单词的不常见含义，如 `school` 学派、`plant` 工厂/间谍、`address` 解决/处理、`court` 招致/求爱、`subject` 使遭受/易受……影响的）。

## 核心专题划分

- **专题 1**: 考研英语最高频逻辑连接词库（因果、转折、让步、递进、对比、总结）
- **专题 2**: 情感态度词大汇总（积极正向 / 消极批判 / 客观中立 / 绝对极端不可选词）
- **专题 3**: 经济、科技与社会学学术阅读高频词根词缀精选
