# 英语(一) 历年真题精读与长难句剖析

> **精读核心法门**: 
> 1. 先盲做（严格计时 15~18 分钟/篇）；
> 2. 查生词、划出每个句子的主干（主谓宾/主系表）；
> 3. 翻译长难句，搞清指代（this, that, which, it）；
> 4. 错题复盘：为什么选错？属于无中生有、偷换概念、绝对化还是反向干扰？
