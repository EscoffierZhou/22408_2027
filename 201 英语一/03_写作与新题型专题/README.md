# 英语(一) 图画大作文、应用文与新题型破局

---

## 一、短文写作（大作文 20 分）：图画作文万能结构

英语一大作文几乎固定为**图画作文**（一幅或两幅寓意图画），标准黄金三段论：

1. **第一段（描述图画，引出主旨）** (~40词):
   - 简洁描述图画内容（人物、动作、对话或对比细节）；
   - 一句话点破图画寓意（What the drawing vividly depicts is not merely... but...）。
2. **第二段（深层分析，多维阐述）** (~100词):
   - 维度 1: 个人成长 / 心理素质 / 科学精神；
   - 维度 2: 社会背景 / 时代发展 / 科技双刃剑；
   - 经典论证句型与因果逻辑展开。
3. **第三段（总结归纳，提出建议）** (~40词):
   - 提出倡议或警示（From my perspective, it is imperative that...）；
   - 升华主旨（Only in this way can we...）。

---

## 二、新题型（10 分）：三大题型破题法则

1. **七选五**: 重点看空前空后的逻辑连词、同义复现与代词呼应；
2. **排序题**: 先锁定首段（通常无指代代词、无逻辑转折），再抓首尾衔接词锁死“相邻对”（如 AB, CD 绑定）；
3. **小标题匹配**: 快速扫读段落首尾句，提炼高频核心名词，直接对照匹配。
