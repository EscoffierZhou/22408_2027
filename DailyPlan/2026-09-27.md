### 【阶段一】14:00 - 16:45 多元函数极值与拉格朗日乘数法 (2.75h)
- [ ] **无条件极值**:
  - 令 $f_x = 0, f_y = 0$ 解驻点 $(x_0, y_0)$；
  - 记 $A = f_{xx}, B = f_{xy}, C = f_{yy}$，判别式 $\Delta = AC - B^2$；
  - $\Delta > 0$ 且 $A > 0 \implies$ 极小值；$\Delta > 0$ 且 $A < 0 \implies$ 极大值；$\Delta < 0 \implies$ 无极值；$\Delta = 0 \implies$ 另行讨论；
- [ ] **条件极值**:
  - 构造拉氏函数 $L(x, y, \lambda) = f(x, y) + \lambda \varphi(x, y)$；
  - 求偏导联立求解，并结合几何或实际背景判定最大最小值。
