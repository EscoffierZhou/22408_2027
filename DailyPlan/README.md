## 一、规划设计核心哲学 (对照 NOTICE.md)

> [!CAUTION]
> **警惕“第一层抽象假懂”陷阱**：
> - 题解看懂了、公式抄上了、答案选对了 $\neq$ 真正掌握。
> - 真正的掌握是：**遮住解析、闭卷手推、能讲清边界条件与前提弱化**。

日常复习中，我们坚守以下四项原则：
1. **留足复盘窗口**：每天必须预留 20%~25% 的高精力时间，专门用来闭卷重推昨天的错题与盲区（尤其是由他人或 AI 协助过的题目）。
2. **拒绝盲目赶进度**：同一阶段宁可少推一个单元，也要把核心原理吃透直到“手推关键公式 + 手写最小实现”。
3. **四段式作息结构**：
   - **晨间 (08:00 - 12:00)**：头脑最清醒时期，主攻**数学**（深度复盘 + 新题突破）；
   - **下午 (14:00 - 17:30)**：大块专注时间，主攻 **408 计算机统考专业课** 与 **代码手撕**；
   - **傍晚/晚间 (18:30 - 20:30)**：平稳输入期，推进 **204 英语二**（长难句精读 / 词汇 / 真题阅读）；
   - **夜间 (20:30 - 21:30)**：闭环期，执行**当日复盘对账与明日计划预排**。
4. **诚实面对死点**：每天在 DailyLog 中记录今天“卡壳在哪里”、“哪里的假设最脆弱”，把漏洞变成下一次突破的跳板。

## 二、每日任务文档规范

- 命名规范：`YYYY-MM-DD.md`（如 `2026-09-15.md`）。
- 模块结构：
  - **1. 今日战术目标与时间预算**（总时长、核心突破科目）
  - **2. 分时段执行清单 (Checklist)**（任务明细、耗时、执行状态）
  - **3. 晨间深度复盘专项 (Morning Revisit)**（昨日难点清单与重推验收）
  - **4. 晚间复盘对账与反思 (Daily Log & Reflection)**（对账结果、认知盲点、明日重点）
