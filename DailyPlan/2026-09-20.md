## 二、时段执行清单与核心验收标准

### 【阶段一】08:00 - 11:30 高数 Chap06 中值定理综合强化 (3.5h)
- [ ] **方程根的存在性与唯一性证明**:
  - 存在性：零点定理（端点异号）或罗尔定理（找到原函数有两相等端点值）；
  - 唯一性：反证法（假设有两个不同根，罗尔定理导致导数有零点矛盾）或导数单调性（$f'(x) > 0$ 恒单增）；
- [ ] **双中值问题突破**:
  - 证明形如 $f'(\xi) + f'(\eta) = \dots$：常在区间 $[a, c]$ 与 $[c, b]$ 上分别使用拉格朗日中值定理，再消去中间值；
  - 证明形如 $\xi \neq \eta$：利用加权平均或柯西中值定理构造；
- [ ] 刷写《李林880》一元微分学综合应用 4~5 道强化题，把辅助函数与放缩过程在草稿纸上推透！

### 【阶段二】14:00 - 17:00 408 操作系统：Chap1 破局开荒 (3.0h)
- [ ] **操作系统的两大核心特征**:
  - 并发（宏观同时，微观交替）与 共享（互斥共享 vs 同时共享），二者互为存在前提；
- [ ] **运行机制与双重模式**:
  - **用户态 (目态)**: 只能执行非特权指令；
  - **内核态 (管态)**: 拥有最高权限，可执行特权指令（如关中断、置程序状态字 PSW）；
  - 模式切换：用户态 $\to$ 内核态（**唯一途径：通过中断或异常**）；内核态 $\to$ 用户态（修改 PSW 指令）；
- [ ] **中断 (Interrupt) 与 异常 (Exception)**:
  - **内中断 (异常)**: 源于 CPU 内部，与当前指令相关（故障 fault、陷阱 trap、终止 abort）；
  - **外中断 (狭义中断)**: 源于 CPU 外部，与当前指令无关（如 I/O 完成中断、时钟定时中断）；
- [ ] **系统调用 (System Call) 执行流程**:
  - 用户程序传递参数 $\to$ 执行访管指令（陷入指令/trap 指令，在用户态执行）$\to$ 引发内中断 $\to$ CPU 切换到内核态 $\to$ 查找中断向量表 $\to$ 执行对应的系统调用处理程序 $\to$ 返回用户态；
- [ ] 完成王道操作系统第 1 章全部课后选择题。

### 【阶段三】17:15 - 18:45 408 计网：滑动窗口协议与利用率 (1.5h)
- [ ] **三大滑动窗口机制对比与窗口大小限制 (设帧序号为 $n$ 位，共 $2^n$ 个序号)**:
  - **停止-等待 (Stop-and-Wait)**: 发送窗口 $W_T = 1$，接收窗口 $W_R = 1$；
  - **后退 N 帧 (GBN)**: 采用累积确认机制，$1 \le W_T \le 2^n - 1$，$W_R = 1$；
  - **选择重传 (SR)**: 采用单独确认机制，$W_T + W_R \le 2^n$，通常 $W_T = W_R = 2^{n-1}$；
- [ ] **信道利用率计算公式**:
  $$U = \frac{W_T \cdot T_D}{T_D + \mathrm{RTT} + T_A}$$
  （$T_D$ 为发送一帧的时延，$\mathrm{RTT}$ 为往返时间，$T_A$ 为确认帧时延，若忽略 $T_A$ 则为 $\frac{W_T \cdot T_D}{T_D + \mathrm{RTT}}$）；
- [ ] 独立手算 2 道滑动窗口信道吞吐量与最大利用率计算大题。
