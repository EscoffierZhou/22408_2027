# 数据科学基础 · 核心数据结构与经典算法储备

> **核心逻辑**: 无论任何计算机或智能科学自命题，《数据结构》都是最核心的 50%~70% 分值盘面。直接复用并提炼现有的数据结构优质资产，手撕高频算法！

---

## 必背经典手撕算法清单

1. **线性表**: 单链表反转、双指针求倒数第 k 个节点、单链表找中点、有序链表合并；
2. **二叉树**: 递归先/中/后序、非递归中序（栈模拟）、层序遍历（队列模拟）、二叉树最大深度与最近公共祖先（LCA）；
3. **图论算法**: BFS 连通分量、DFS 拓扑排序、Dijkstra 单源最短路径（贪心思想）、Kruskal / Prim 最小生成树；
4. **查找与哈希**: 二分查找（手写严格边界）、二叉搜索树（BST）插入与查找、哈希冲突处理（开放定址法与拉链法）；
5. **内部排序**: 快速排序（划分核心 Partition）、归并排序（双路合并）、堆排序（大根堆调整 Heapify）、各类排序的时间/空间复杂度与稳定性全对照。
