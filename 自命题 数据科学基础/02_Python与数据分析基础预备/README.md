## 预备核心模块

1. **Python 科学计算核心库**:
   - NumPy: 矩阵运算、广播机制、维度变换 (`reshape`, `transpose`)；
   - Pandas: DataFrame 常用数据清洗、缺失值处理、分组聚合 (`groupby`)；
2. **基础统计学指标**:
   - 期望、方差、协方差、相关系数（皮尔逊与斯皮尔曼）、主成分分析（PCA）直观概念；
3. **机器学习与数据挖掘常识**:
   - 监督学习 vs 无监督学习；
   - 经典分类与聚类算法思想（K-Means、KNN、决策树、逻辑回归）。
