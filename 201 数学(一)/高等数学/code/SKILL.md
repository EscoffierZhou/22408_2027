# 考研数学笔记与例题自动化生成规范 (Math Notes Creator)

本 Skill 旨在将考研数学复习过程中的板书截图、讲义、手写笔记及习题集，高保真、体系化地转化为“甚至可以丢掉教科书”的高品质 Markdown 知识库、原生 LaTeX 出版源码与学术出版级高清 PDF 讲义。

--------------------------------------------------------------------------------

## 一、四位一体标准文档体系与双输出格式 (Markdown + TeX + PDF)

对于每一章数学知识，标准产出由四个相互呼应的 Markdown 文件、对应的原生 LaTeX 源码 (`.tex`) 及由 XeLaTeX 双遍编译生成的出版级 PDF 组成：

| Markdown 文件 | 导出 LaTeX 与 PDF | 文档定位 | 核心收录内容 |
| :--- | :--- | :--- | :--- |
| `chapX[章节名].md` | `.tex` / `.pdf` | **体系化理论精讲笔记** | 知识框架、基本公式推导、核心公式微元、方法准则、几何意义与历史背景 |
| `例题.md` | `.tex` / `.pdf` | **核心精讲大例题集** | 课堂精选大例题(例X.1~X.N)，题干定位、思路分析、分步解答(`[1]`,`[2]`)、辅助三角形回代、多解法对比 |
| `Homework.md` | `.tex` / `.pdf` | **基础/课后习题精练** | 课后精选题，题干、考点聚焦、完整推导、常数连续性拼接、极限与积分方程逆运算 |
| `[强化][章节名].md` | `.tex` / `.pdf` | **考研高阶冲刺与深水区** | 欧拉代换、配对积分法、古鲁金定理、牟合方盖相交体、托里拆利小号、高阶旋转微元 |

## 二、排版与格式五大红线 (Markdown 源码编写铁律)

为了确保文档在任何 Markdown 渲染器(如 Obsidian、Typora、GitHub、VS Code)中排版工整，且能被 TeX 转换引擎无损解析，必须严格遵守以下排版铁律：

### 铁律[1]: 全文严禁制表符 (Tab)
- 全文禁止出现任何 `\t` 字符，制表符出现次数必须严格为 0。

### 铁律[2]: 全文严禁 Markdown 默认有序列表
- 严禁使用形如 `1. `、`2. `、`3. ` 的 Markdown 默认有序列表语法(正则匹配 `^\s*\d+\.\s` 必须为 0)。
- 违规原因: 默认有序列表会自动触发首行悬挂缩进和强制空行，破坏数学公式的引用块结构并导致 TeX 解析混乱。

### 铁律[3]: 缩进体系唯一规范
- 所有缩进必须且仅能使用引用符号：
  - 一级缩进使用 `>`
  - 二级缩进使用 `>>`
  - 三级缩进使用 `>>>`
- 引用块内部的换行与公式之间，空行必须使用带前缀的空引用(如 `>` 单独占一行)。

### 铁律[4]: 标号与分项唯一规范
- **一级/大分项标号**: 统一使用方括号数字：`[1]`、`[2]`、`[3]`...
- **二级/子分项及公式序号**: 统一使用半角圆括号数字：`(1)`、`(2)`、`(3)`...
- **绝对禁止使用汉字圈号**: 全文不得出现圆圈序号(如圈1至圈13)、“圈一”、“圈二”等符号，一律替换为半角圆括号序号 `(1)`、`(2)`。
- **定理与方法标题规范**: 统一采用六级标题：`###### **定理[1]:[标题]**`、`###### **方法[1]:[标题]**`、`###### **公式[1]:[标题]**`、`###### **模型[1]:[标题]**`、`###### **辨析[1]:[标题]**`。

### 铁律[5]: 行内多行公式双换行规范
- 在行内公式 `$ ... $` 内部使用多行环境(如 `\begin{cases} ... \end{cases}` 或矩阵环境)时，两行之间**必须使用两次换行符 `\\ \\`**，获得两次换行的宽松间距效果。
- 目的: 彻底消除 LaTeX 行内分式在预览时与上下两行符号粘连重叠的视觉瑕疵。

## 三、学术出版级 TeX 视觉设计规范 (TeX / PDF 标准)

所有 PDF 必须采用底层 XeLaTeX 编译引擎（`D:\texlive\2025\bin\windows\xelatex.exe`），彻底淘汰 Web 端渲染字体瑕疵，统一遵循以下出版级标准：

[1]专业全彩讲义封面 (Cover Page)：
- **顶部几何色块**: 采用高贵深紫罗兰 (`DeepPurple #4C1D95`) 几何通栏色块，右上角融入优雅的考研年份半透明水印 (`2027`)；
- **分界装饰双线**: 采用亮粉 (`DeepPink #FF1493`, 3.5pt) 与科技金 (`GoldAccent #D97706`, 1pt) 双层精工分割线；
- **主标题体系**: `2027 考研数学(二) 核心讲义`、`全国硕士研究生招生考试 · 统考数学(二) 核心精讲全书`；
- **章节与模块副标题**: 章节大标题采用深紫罗兰 (`#581C87`, 24pt)，副标题注明模块定位（如 `—— 核心精讲大例题与题解三步法 ——`）；
- **底部备考档案卡片**: 白底深紫微阴影卡片，内嵌编著团队 (`EscoffierZhou`)、目标院校 (`中国科学院大学 (UCAS) 计算机专硕 (22408)`)、桌前备考铁律及编制时间。

[2]交互式超链接目录 (TOC)：
- 封面后紧跟自动提取的独立目录页，页码使用小写罗马数字 (`— 第 I 页 —`)；
- 目录项与正文通过 `hyperref` 建立深紫罗兰色可点击跳转超链接；
- 正文开始时页码重置为阿拉伯数字 (`— 第 1 页 —`)。

[3]双色卡片化定理与解题环境 (tcolorbox)：
- **定理与核心公式卡片 (`thmbox`)**: 左侧 3.5pt 深紫罗兰边框 (`#581C87`)，浅紫底色 (`#F8F5FF`)，顶部悬挂白字深紫小标头；
- **答题规范与推导微元卡片 (`solbox`)**: 左侧 3.5pt 亮粉边框 (`#FF1493`)，温润浅粉底色 (`#FFF5F8`)，顶部悬挂白字亮粉小标头；
- **复习目标与知识图谱卡片 (`targetbox`)**: 章节开头的复习目的自动汇聚为深紫框导读卡片。

[4]数学公式极致排版标准：
- **纯黑矢量字体**: 数学公式文字一律使用严谨的纯黑墨度，绝不呈现粉色或褪色；
- **分数上标完美比例**: 采用 XeLaTeX 原生数学字号缩放规则，彻底根除 KaTeX 中分数线加粗、分号粗黑的渲染 Bug（如 $e^{\frac{1}{x}}$、$x^{\frac{2}{3}}$ 均呈现优美修长横线）；
- **多行对齐**: 公式环境自动转换为原生 `equation*` 与 `align*`，行内公式采用精致段落内插。

[5]页眉页脚与版芯尺寸：
- **页边距**: `left=18mm, right=18mm, top=24mm, bottom=24mm`；
- **页眉**: 左侧显示 `2027 考研数学(二) · 核心讲义系列`，右侧动态显示当前章节 `\leftmark`，下衬 0.5pt 深紫分割线；
- **页脚**: 居中显示 `— 第 X 页 —`，右侧标注 `UCAS 22408`。
