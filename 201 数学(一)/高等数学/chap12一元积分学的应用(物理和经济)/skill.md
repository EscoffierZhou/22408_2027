# 考研数学笔记与例题自动化生成规范 (Math Notes Creator)

本 Skill 旨在将考研数学复习过程中的板书截图、讲义、手写笔记及习题集，高保真、体系化地转化为“甚至可以丢掉教科书”的高品质 Markdown 知识库与出版级高清 PDF 文档。

--------------------------------------------------------------------------------

## 一、四位一体标准文档与 PDF 架构

对于每一章数学知识，标准产出由四个相互呼应的 Markdown 文件及对应的高清 PDF 组成：

| Markdown 文件 | 对应导出 PDF | 文档定位 | 核心收录内容 |
| :--- | :--- | :--- | :--- |
| `chapX[章节名].md` | `chapX[章节名].pdf` | **体系化理论精讲笔记** | 知识框架、基本公式推导、核心公式微元、方法准则、几何意义与历史背景 |
| `例题.md` | `例题.pdf` | **核心精讲大例题集** | 课堂例题(例X.1~X.N)，题干定位、思路分析、分步解答(`[1]`,`[2]`)、辅助三角形回代、多解法对比 |
| `Homework.md` | `Homework.pdf` | **基础/课后习题精练** | 课后精选题，题干、考点聚焦、完整推导、常数连续性拼接、极限与积分方程逆运算 |
| `[强化][章节名].md` | `[强化][章节名].pdf` | **考研高阶冲刺与深水区** | 欧拉代换、配对积分法、古鲁金定理、牟合方盖相交体、托里拆利小号、高阶旋转微元 |

## 二、排版与格式五大红线 (严格执行)

为了确保文档在任何 Markdown 渲染器(如 Obsidian、Typora、GitHub、VS Code)及导出 PDF 中排版工整、无渲染混乱，必须严格遵守以下排版铁律：

### 铁律[1]: 全文严禁制表符 (Tab)
- 全文禁止出现任何 `\t` 字符，制表符出现次数必须严格为 0。

### 铁律[2]: 全文严禁 Markdown 默认有序列表
- 严禁使用形如 `1. `、`2. `、`3. ` 的 Markdown 默认有序列表语法(正则匹配 `^\s*\d+\.\s` 必须为 0)。
- 违规原因: 默认有序列表在不同编辑器中会自动触发首行悬挂缩进和强制空行，破坏数学公式的引用块结构。

### 铁律[3]: 缩进体系唯一规范
- 所有缩进必须且仅能使用引用符号：
  - 一级缩进使用 `>`
  - 二级缩进使用 `>>`
  - 三级缩进使用 `>>>`
- 引用块内部的换行与公式之间，空行必须使用带前缀的空引用(如 `>` 单独占一行)。

### 铁律[4]: 标号与分项唯一规范
- **一级/大分项标号**: 统一使用方括号数字：`[1]`、`[2]`、`[3]`...
- **二级/子分项及公式序号**: 统一使用半角圆括号数字：`(1)`、`(2)`、`(3)`...
- **绝对禁止使用汉字圈号**: 全文不得出现圆圈序号(如圈1至圈13)、“圈一”、“圈二”等符号，一律替换为半角圆括号序号 `(1)`、`(2)`。
- **定理与方法标题规范**: 统一采用六级标题加粗：`###### **定理[1]:[标题]**`、`###### **方法[1]:[标题]**`、`###### **模型[1]:[标题]**`。

### 铁律[5]: 行内多行公式双换行规范
- 在行内公式 `$ ... $` 内部使用多行环境(如 `\begin{cases} ... \end{cases}` 或矩阵环境)时，两行之间**必须使用两次换行符 `\\ \\` (即两次反斜杠)**，获得两次换行的宽松间距效果。
- 目的: 彻底消除 LaTeX 行内分式(如 `\frac{x^2}{2}`)在预览时与上下两行符号粘连重叠的视觉瑕疵。

## 三、出版级视觉设计规范 (PDF 样式标准)

为保证纸质打印与电子阅读舒适度，统一遵循以下视觉黄金标准：

[1]各级标题紫色系：
- 一级标题 (`h1`): 深紫罗兰色 `#581c87`，搭配浅紫底边线 `#9333ea`；
- 二级标题 (`h2`): 典雅紫晶色 `#6b21a8`，搭配极淡紫分割线 `#e9d5ff`；
- 三级/六级标题 (`h3`, `h6`): 亮紫 `#7e22ce` 与深紫 `#6b21a8`。

[2]公式块 DeepPink 醒目卡片化：
- **公式块容器（引用推导块）**: 采用 DeepPink 亮色左竖边框(`border-left: 4px solid #ff1493`)，底色为温润柔和的浅粉底(`background-color: #fff1f7`)；
- **二级嵌套块**: 边框色 `#f43f5e`，底色 `#fdf2f8`。

[3]数学公式纯黑无色差：
- **公式字符字体**: 严禁将数学公式文字渲染为粉色或浅色，所有行内公式与独立块级公式一律采用清晰纯黑 (`color: #111827`)，保证极高可读性与墨度对比。

[4]舒朗通透版面标准：
- **字体与行距**: 正文字号 `13.8px`，行高 `1.68`，段落间距适中；
- **版芯边距**: A4 纸张页面边距设为 `16mm 15mm 16mm 15mm`，排版宽松有度，绝不拥挤压抑。

## 四、图片笔记导出与生成标准流程 (SOP 六步法)

当用户提供图片文件夹(如 `camera`)时，严格执行以下标准化 6 步流程：

[1]步骤一: 生成并排序文件清单
- 遍历图片文件夹，提取所有图片名称。
- 按文件名中的数字或时间戳从小到大严格排序，保存为 `file_list.txt`。

[2]步骤二: 逐图审阅与提取
- 依照 `file_list.txt` 顺序逐张调用查看工具提取完整文本、公式、旁注与手写批注。
- 绝不遗漏任何辅助角几何三角形、费曼积分技巧、牛莱历史背景等细节。

[3]步骤三: 内容拆分归类
- 理论与核心方法论写入 `chapX[章节名].md`；
- 核心例题(例X.1~X.N)写入 `例题.md`；
- 基础习题(习题X.1~X.N)写入 `Homework.md`；
- 拔高冲刺技巧写入 `[强化][章节名].md`。

[4]步骤四: 自动化校验脚本拦截
- 写入后运行 Python 校验脚本，严格审查:
  - `\t` 计数是否为 0；
  - `^\s*\d+\.\s` 匹配是否为 0；
  - 圆圈序号(如圈1至圈13)计数是否严格为 0；
  - `$$` 是否偶数闭合；
  - 行内 cases 是否均采用 `\\ \\` 双换行。

[5]步骤五: 高保真 KaTeX PDF 编译流水线
- 解决核心痛点: Markdown 转 HTML 时，预先用安全占位符(`XYZMATHBLOCK...` 与 `XYZMATHINLINE...`)隔离所有数学块与行内公式，彻底避免下划线 `_`、竖线 `|` 等符号被 Markdown 语法误转为斜体或表格错列。
- 同步加载 KaTeX 与 auto-render，杜绝 defer 异步时序错乱。
- 无头浏览器纯净打印: 调用 Edge / Chrome 无头模式执行静默打印：
  ```bash
  msedge.exe --headless=new --disable-gpu --no-sandbox --no-pdf-header-footer --run-all-compositor-stages-before-draw --virtual-time-budget=6000 --print-to-pdf=<pdf_path> <html_path>
  ```
- 保证生成的 PDF 纯净、公式矢量清晰、无任何浏览器默认网址或页眉页脚干扰。

[6]步骤六: 双格式与双仓库同步
- 将最终的 `.md` 源码文件与 `.pdf` 高清文档，同步至主工作区与副本工作区：
  - 主目录: `F:\desktop\11408_2027\201 数学(一)\高等数学\...`
  - 副本目录: `F:\desktop\11408_2027 - 副本\201 数学(一)\高等数学\...`

## 五、批量导出 PDF 工具与命令行用法

工具统一存放在 `code` 目录下：`F:\desktop\11408_2027\201 数学(一)\高等数学\code\export_pdf.py`。

```bash
# 转换当前章节所有 Markdown 文件为 PDF 并自动同步到副本
python export_pdf.py

# 批量转换指定章节目录
python export_pdf.py "chap10一元积分学的应用(几何)"

# 批量转换全书所有章节
python export_pdf.py --all
```
