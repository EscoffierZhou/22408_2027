一行乘一列:$$\begin{bmatrix} a_1 ,a_2 \end{bmatrix}\begin{bmatrix} b_1 \\b_2 \end{bmatrix} = a_1b_1+a_2b_2$$

一行乘多列:$$\begin{bmatrix} a_1 ,a_2 \end{bmatrix}\begin{bmatrix} b_1,c_1 \\b_2,c_2 \end{bmatrix} = \begin{bmatrix}a_1b_1+a_2b_2,a_1c_1+a_2c_2\end{bmatrix}$$

多行乘一列:$$\begin{bmatrix} a_1,a_2 \\b_1,b_2 \end{bmatrix}\begin{bmatrix} c_1\\c_2 \end{bmatrix} = \begin{bmatrix}a_1c_1+a_2c_2\\b_1c_1+b_2c_2\end{bmatrix}$$

多行乘多列:$$\begin{bmatrix} a_1,a_2 \\b_1,b_2 \end{bmatrix}\begin{bmatrix} c_1,d_1\\c_2,d_2 \end{bmatrix} = \begin{bmatrix}a_1c_1+a_2c_2,a_1d_1+a_2d_2\\b_1c_1+b_2c_2,b_1d_1+b_2d_2\end{bmatrix}$$
